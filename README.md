# bilimi

bilimi 是一款面向 Bilibili 浏览、收藏整理与视频资料沉淀的 Windows 桌面应用。它将内置 B 站浏览器、右侧助手、小咪桌面伴随窗口、批阅动作、视频札记、档案库、收藏夹掌库、本地音频转写和可选的 DeepSeek 能力整合在同一个应用中。

当前正式版本：`1.0.3`。

> bilimi 不是 Bilibili 官方客户端，也不替代 B 站网页。登录、播放、点赞、投币、收藏等账号行为仍由 B 站页面和接口完成；bilimi 提供桌面容器、辅助入口、信息整理与本地资料能力。

## 下载与安装

### 系统要求

- Windows 10 或 Windows 11，x64 架构。
- 建议使用 1080p 或更高分辨率；应用会根据可用工作区自动调整窗口大小和最小尺寸。
- 需要网络连接以浏览 B 站、登录账号、调用 B 站相关功能或使用 DeepSeek。
- 本地音频转写会使用 CPU，并需要较多磁盘空间保存安装包内置工具、模型和本地档案。

### 下载

从 GitHub Release 下载正式安装包：

[下载 bilimi 1.0.3](https://github.com/diqing233/bilimi/releases/download/v1.0.3/bilimi.Setup.1.0.3.exe)

安装包文件名：

```text
bilimi.Setup.1.0.0.exe
```

只建议从本仓库的 GitHub Releases 页面下载安装包，不要运行来源不明的二次打包文件。

### 安装步骤

1. 下载 `bilimi.Setup.1.0.0.exe`。
2. 双击运行安装器。
3. 安装器会把 bilimi 安装到当前 Windows 用户环境，并创建桌面快捷方式和开始菜单快捷方式。
4. 安装完成后，从桌面、开始菜单或安装器完成页启动 bilimi。

当前安装包尚未进行 Windows 代码签名，因此 SmartScreen 可能显示“未知发布者”。如果文件确实来自本仓库 Release，可在 Windows 提示中选择“更多信息”，核对文件名后继续运行。

### 升级

安装新版本前建议先退出正在运行的 bilimi。新安装包会更新应用程序文件；本地偏好、档案和凭据保存在用户数据目录，不应因为普通覆盖安装而丢失。重要资料仍建议自行备份。

### 卸载

可在 Windows“设置 > 应用 > 已安装的应用”中卸载 bilimi。卸载应用程序不等同于主动清除所有用户数据；如果需要彻底清理本地配置和档案，请先确认不再需要这些内容，再手动处理对应用户数据目录。

## 第一次启动

### 启动前权限检查

首次运行会先进入“启动前权限检查”。该页面用于说明应用接下来需要使用的桌面能力和外部服务边界。确认后继续，设置会记录已完成首次引导，后续启动直接进入主界面。

### 启动中

主进程、偏好设置和渲染页面初始化期间会显示“启动中”。如果长时间停留在这里，可先完全退出应用再重开；仍无法进入时，参阅[启动后一直停留在启动中](#启动后一直停留在启动中)。

### 建议的首次使用顺序

1. 等待 B 站首页加载。
2. 在内置页面登录自己的 B 站账号。
3. 打开右侧助手并进入“设置”。
4. 运行“启动与功能诊断”，确认网络、本地媒体工具、存储和当前页面状态。
5. 按需设置关闭行为、小咪样式、转写线程数和收藏策略。
6. 如果需要 AI 能力，再启用并配置 DeepSeek；不配置也可以使用浏览、掌库、本地转写和基础札记。

## 整体界面

主窗口由三个长期区域组成：

1. 顶部网页标签栏：显示首页和应用内打开的视频或其他 B 站页面。
2. 中央浏览区：承载当前 B 站网页。
3. 右侧助手区：提供批阅、札记、掌库和设置。

此外，桌面上可显示独立的小咪悬浮窗口。小咪与主窗口、助手窗口共享状态，可用于唤醒主窗口、打开助手和触发快捷入口。

助手顶部还有全局提示区和三个后台状态灯：

- `DeepSeek`：显示连接、调用或错误状态，点击可跳转到设置中的 DeepSeek 区域。
- `转写音频`：显示音频下载、排队、转写和完成状态，点击跳到札记。
- `整理`：显示掌库扫描、DeepSeek 整理或归档执行状态，点击跳到掌库。

超过瞬时响应时间的操作会通过按钮文字、进度条、全局提示、小咪气泡或状态灯反馈。遇到失败时先阅读当前区域提示，它通常会指出登录、网络、页面、工具或配置方面的原因。

## 主浏览器页面

### 页面入口

应用启动并完成首次引导后，中央区域默认打开 B 站首页。页面由 Electron WebView 承载，使用的是 bilimi 自己的应用会话，不等同于系统 Chrome 的登录状态。

### 网页标签栏

顶部标签栏显示当前已打开页面：

- 首页标签始终保留，不能关闭。
- 从 B 站页面触发的新页面会尽量在 bilimi 内部新建标签，而不是跳到系统浏览器。
- 点击标签切换当前页面。
- 非首页标签右侧有关闭按钮。
- 标签数量较多时会压缩显示，避免立刻占满整个窗口。
- 右侧刷新按钮只刷新当前激活标签。

切换标签时，助手会跟随当前页面更新视频标题、作者、链接和 BV 号等上下文。网页尚未加载完成或当前不是可识别视频页时，助手可能显示“待识别”或占位说明。

### 登录 B 站

1. 在主浏览器中进入 B 站登录入口。
2. 按 B 站页面提示完成扫码或其他登录流程。
3. 登录完成后刷新当前页面，或重新进入目标视频页。

登录状态由 B 站页面会话维护。登录过期、账号风控或页面接口变化都可能导致批阅、收藏扫描、音频下载等操作失败。bilimi 不会要求你把 B 站密码写入设置。

### 打开视频页

在首页、搜索页、动态或收藏页点击视频链接即可打开视频。部分链接会在新标签中打开。进入视频页后，助手的“批阅”和“札记”才拥有完整上下文。

### 网页全屏

视频进入网页全屏时，可在设置中选择自动收起小咪，避免悬浮窗口遮挡播放画面。退出全屏后小咪恢复正常显示逻辑。

### 页面失败与降级

以下情况可能导致页面功能不可用：

- 网络连接慢或中断。
- B 站未登录或登录过期。
- 视频被删除、区域受限或账号无权限。
- B 站更新页面结构，导致自动化定位失效。
- WebView 页面仍在加载，助手过早读取上下文。

遇到问题时先刷新当前标签，确认页面本身能正常操作，再运行设置中的诊断。外部页面异常只应影响对应功能，不应阻止你继续使用其他本地页面。

## 助手工作区

### 页面入口

助手可作为主窗口右侧侧边栏显示，也可由小咪打开独立助手窗口。顶部固定提供四个页签：

- `批阅`
- `札记`
- `掌库`
- `设置`

切换页签时，小咪会给出对应提示。独立助手窗口在点击空白区域或失去焦点时可能按当前窗口模式关闭；主窗口中的侧边栏不会因为普通失焦自动消失。

### 全局提示

页签下方显示最近一次全局反馈。长文本可通过悬停查看完整内容。后台状态灯可直接跳到正在工作的功能区，因此转写或整理期间不必一直停留在原页面。

## 批阅页面

### 用途

“批阅”用于查看当前视频上下文，并对当前 B 站视频执行点赞、投币/三连、收藏和短评相关辅助动作。

### 页面组成

- 当前视频标题。
- UP 主信息。
- 小咪给出的预归类位置或当前收藏建议。
- 四个主要批阅动作按钮。
- 某些动作的临时参数或候选选择区。
- 操作进度、成功、失败与缺失目标提示。

### 轻赏：点赞

在已登录的视频页点击“轻赏”后，bilimi 会尝试触发当前视频的点赞操作。页面结构、视频状态或账号权限不满足时会显示失败原因。执行后应以 B 站页面上的点赞状态为最终依据。

### 归库：收藏

“归库”会结合掌库中的 bilimi 收藏夹规则判断适合的目标，然后执行收藏相关操作。未备册、未登录、当前页面不是视频页或没有可用收藏夹时，助手会提示先完成对应前置步骤。

日常归类可受设置中的“最多同时保存到 1/2/3 个 bilimi 收藏夹”限制。DeepSeek 批阅辅助开启后，还可根据设置选择复核全部归类或只复核“不太稳”的结果。

### 厚赏：投币或三连

“厚赏”按设置中的默认硬币数量执行：

- 默认投 1 枚；再次执行时可尝试补投 1 枚。
- 默认投 2 枚。

实际可投数量由 B 站账号状态、视频类型和已经投币数量决定。不能投币时应以页面反馈为准。

### 表：弹幕或短评

评论动作可按设置选择：

- 随机生成一条并直接发送。
- 生成 3 条候选，选择后发送，也可复制候选后自行发表为评论。

使用 DeepSeek 生成趣味评论需要在设置中启用 DeepSeek 和“趣味评论”，并保存可用 API 密钥。未配置时会提示先开启或检查连接。

### 状态与风险提示

- 操作中：按钮或全局提示显示正在执行。
- 成功：显示对应完成反馈，小咪同步切换成功状态。
- 部分完成：明确列出已完成和缺失目标。
- 失败：显示登录、网页、接口或配置错误。

点赞、投币、收藏、弹幕和评论都会影响真实 B 站账号。重要动作执行后应查看页面结果，不要只依赖助手文字。

## 札记页面

### 用途

“札记”用于把当前视频音频或已有文稿整理为本地可阅读、复制和归档的资料。

### 当前视频详情

页面顶部显示：

- 视频标题。
- UP 主。
- BV 号。
- 视频链接。

尚未识别时对应字段显示“待识别”。请确认中央浏览器正在打开目标视频页，再开始转写。

### 主操作

- `转写音频`：下载当前视频音频，通过本地 whisper.cpp 转写，并将结果自动保存到档案库。
- `档案库`：进入全局档案库，查看所有视频历史、文稿、总结、备注和版本。

在不提供音频转写能力的上下文中，主操作可能显示“整理札记”或“重新整理”，用于处理已有文本。

### 转写队列

札记页会显示当前队列状态：

- 本次启动已完成数量。
- 当前排队数量。
- 当前选中视频的状态和标题。
- 下载、准备、分段转写、归档或总结进度。
- 百分比进度条。

点击队列切换入口可以查看其他排队视频。待处理或运行中的任务可取消；失败或已取消任务可重试。

本地转写阶段 CPU 占用升高属于正常现象。可在设置中把线程数改为 1、2 或 4，以降低资源占用；“无限制”速度最快但占用最高。

### 结果页签

完成转写后可以切换：

- `无时间线文稿`：连续纯文本，适合全文复制。
- `带时间线文稿`：按时间片段显示，可用于定位视频内容。
- `DeepSeek 总结`：显示结构化标题、副标题、要点、关键词、精修文稿和内容核对清单。

结果页签再次点击可收起。无可用文稿时页面会明确提示“暂无文稿”或“该视频还在转写”。

### 复制

- 无时间线和带时间线文稿都支持复制全文。
- DeepSeek 总结支持复制全文。
- 更多复制菜单可分别复制精修文稿或总结部分。
- 复制成功会显示状态；剪贴板不可用时显示错误。

### DeepSeek 总结

启用 DeepSeek 后，可对已有文稿点击“生成总结”或“重新总结”。生成期间显示“生成中”及全局任务状态。总结完成后会归档到对应视频版本。

如果 DeepSeek 未开启、密钥不可读、连接失败或当前没有文稿，页面会分别提示需要先配置、检查连接或先完成转写。

### 重启恢复

应用在转写过程中异常退出或重启时，会优先保存能够恢复的草稿到档案库，然后清理未完成队列。重开后请到档案库检查是否已有部分文稿；未完成任务需要重新加入队列。

## 档案库页面

### 页面入口

在“札记”页点击“档案库”。档案库是独立工作视图，右上方“返回札记”可回到札记主页面。

### 历史列表

左侧/上方历史区显示所有视频档案。每条记录包括：

- 视频标题。
- UP 主或“未署名”。
- BV 号或“未识别”。
- 转写版本数量。
- 是否存在星标版本。
- 最近更新时间。

支持按关键字搜索、只看星标和只看已备注。没有匹配内容时显示“没有匹配的档案”。

### 档案详情

选中档案后可查看：

- 视频标题和来源链接。
- 作者、BV 号和版本数量。
- 历史版本选择器。
- 星标按钮。
- 本地备注。
- 无时间线文稿、带时间线文稿和 DeepSeek 总结。

点击标题或“打开视频来源”会在主浏览器中打开原视频。

### 历史版本

同一视频每次转写可以形成新版本。展开“历史版本”后可切换版本，也可删除单个旧版本。只剩一个版本时不能通过版本菜单删除最后一份；如需删除整个视频记录，使用更多菜单中的“删除视频档案”。

### 星标与备注

- 星标按具体版本保存，可用于列表筛选。
- 备注是本地文本，输入后在失焦时保存。
- “已备注”筛选只显示有备注的档案。

### 删除

删除档案或历史版本前会出现确认对话框。删除视频档案会移除其全部历史版本；此操作不可通过应用内撤销，执行前请确认。

## 掌库页面

### 用途

“掌库”管理 bilimi 专用的 B 站收藏夹体系，并提供旧收藏扫描、分类预览和确认整理流程。它尽量只操作带 bilimi 语义的收藏夹，不主动改变用户普通收藏夹中的原始成员关系。

### 备册

首次使用掌库可点击“备册”。备册会生成一组 bilimi 收藏夹草稿，用于后续日常归类和旧藏整理。收藏夹接近 B 站数量上限时，页面会提示无法继续创建。

### 收藏夹列表

收藏夹区域用于：

- 勾选哪些 bilimi 收藏夹参与下一次同步。
- 点击名称进入编辑。
- 新建自定义收藏夹。
- 保存当前编辑草稿。
- 点击“同步”把勾选状态和草稿更新到 B 站。

`保存` 和 `同步` 不是同一个动作：保存只写入本地草稿；必须勾选目标并点击同步，B 站收藏夹才会更新。取消勾选后同步可能删除对应 bilimi 收藏夹，因此执行前应核对列表。

### 收藏夹种类

- `关键词收藏夹`：通过标题、简介等文本关键词进行本地识别。
- `专属 UP 追更收藏夹`：命中指定 UP 主时优先归类。
- `标签收藏夹`：根据 B 站标签进行本地识别。
- `DeepSeek约束收藏夹`：只由 DeepSeek 根据自然语言约束辅助判断。

关键词、UP 和标签类型也可填写单独的 `DeepSeek约束`，作为 AI 辅助判断参考；该字段不参与纯本地匹配。DeepSeek 未开启时，DeepSeek 约束收藏夹不会自动命中。

默认分类可以改名和调整关键词。把非暂存默认分类的关键词全部清空会显著降低本地识别能力，更多视频可能进入暂存。

### 收藏目标数量

设置页可限制每个视频最多同时保存到 1、2 或 3 个 bilimi 收藏夹。掌库归档预览和最终执行都会遵守当前限制。如果预览选择超过限制，确认前会提示调整。

### 整理旧藏入口

点击“整理旧藏”后进入向导。流程从左到右分为：

1. 扫描概览。
2. 推荐收藏夹。
3. 归档预览。
4. 确认执行。

开始执行前可以返回前面调整；真正开始后本轮方案不可继续修改。

当前正式入口由主进程的账号工作区驱动。点击后会立即显示“扫描概览：扫描中”；切换助手页面、关闭再打开助手或重启应用后，同一账号会恢复扫描概览、来源选择、推荐、当前分段与未提交的分类历史。渲染层只显示当前分段并发送受控命令，不保存另一套旧藏权威状态。

整理完成后再次点击“整理旧藏”会启动下一轮受保护的增量扫描；“全部重新整理”则明确发起全量扫描。旁边的“收藏库”始终是独立入口，打开独立的三栏窗口，不会改变旧藏向导状态。

用户可以选择“仅保存到收藏库”，这会只提交本地仓库；也可以一次确认“保存并同步到 B 站”。后者先冻结跨分段去重和容量预检后的方案，再由主进程执行、检查点持久化并在结果未知时先对账。已开始的真实 B 站操作不属于撤销范围。

## 收藏库窗口

“收藏库”是掌库之外的独立三栏窗口。它与主窗口共享同一次 bilimi 登录、主进程收藏仓库和本地转写队列；再次点击入口只会聚焦已有窗口，不会启动第二个 bilimi。

窗口左侧列出全部收藏、待处理和扫描来源，中间显示当前页视频，右侧显示所选视频的扫描信息、来源、本地镜像、转写和档案关联摘要。窗口内的“同步”只把 B 站视频信息更新到本地镜像，不会修改 B 站收藏关系。

- 可全选当前页并批量同步或加入转写队列。
- 可打开视频，或从多个来源收藏夹中选择一个打开。
- 视频的收藏、备注、转写版本和总结与档案库使用同一份本地数据；收藏库仅显示摘要，完整文稿和编辑仍在档案库完成。
- 遇到同步失败时，收藏库保留最近一次成功镜像，并给出中文重试提示。技术错误只记录在诊断信息中。

### 扫描概览

扫描会读取选中的来源收藏夹并统计：

- 共扫描视频数。
- 进入本轮整理的视频数。
- 以前已完整整理并受到保护的视频数。
- 原归档部分缺失或状态变化的视频数。
- 候选收藏夹和待分类视频。

已完整整理的视频默认“已整理跳过”，避免重复操作。可明确选择“重新整理全部已整理视频”或只重新整理状态有变化的视频。重新整理前会再次确认，并说明用户普通收藏不会改变。

### 推荐收藏夹

系统会根据扫描内容给出专属 UP 追更和高频标签候选。可以逐项勾选或全选；推荐选择在整轮工作区内共享并持久化。需要新的整理目标时，可新增本地逻辑收藏夹并重新归类；只有选择 B 站同步时，主进程才会按容量创建或绑定对应的物理收藏夹分卷。

### 归档预览

归档预览按收藏夹分组展示每个视频的整理前位置和当前位置。你可以：

- 查看视频来源。
- 手动勾选或取消目标。
- 把无法匹配的视频放入暂存。
- 对多目标视频只取消当前收藏夹，或全部去掉不整理。
- 撤回本轮手动或 DeepSeek 调整。
- 查看改动记录。

预览中的修改尚未操作 B 站，只有最后确认整理才会执行。

### DeepSeek 辅助整理

启用 DeepSeek、保存有效密钥并打开“旧藏整理”后，可在归档预览中启动 DeepSeek 整理。可选择处理全部范围或其他可用范围。发送给服务的信息包括标题、UP、标签、简介、来源收藏夹、当前建议和 bilimi 册目信息。

运行中显示批次进度，可取消。完成后会列出已采用和未采用建议；结果只先更新预览，不会立即操作 B 站。DeepSeek 返回的关键词建议进入设置中的建议列表，只有手动采纳后才会改动本地规则。

### 确认整理

确认页会显示本轮视频数、单视频最多目标数和可能需要同步的新收藏夹。点击“开始整理”或“确认整理”后：

- 普通整理只向 bilimi 收藏夹追加归档。
- 明确重新整理受保护视频时，可能先加入新目标，再从多余的旧 bilimi 收藏夹移出。
- 用户自己创建的普通 B 站收藏夹及原始收藏关系保持不变。
- 执行中显示完成数和总数。
- 结束后会区分成功、部分完成、失败或暂停。

完成后点击确认结束本轮，再重新扫描才能开始下一轮。没有待执行任务时，确认会直接结束本轮，不发送无意义的归档请求。

## 设置页面

设置页顶部提供“恢复默认布局”和“重置设置”。下拉“设置项”可快速跳转到具体分组。

### 诊断

“启动与功能诊断”检查：

- B 站网络。
- 本地媒体工具。
- DeepSeek。
- 本地存储。
- 当前页面状态。

点击“运行诊断”后按钮显示“诊断中”。完成后可展开结果，每项会显示状态、说明和建议动作。诊断用于定位问题，不会替代真实账号操作验收。

### DeepSeek

可配置：

- 启用或停用 DeepSeek。
- 趣味评论。
- 自动总结。
- 宠物对话。
- 旧藏整理。
- 批阅辅助及“全部归类/仅不太稳”范围。
- API 密钥。
- 模型名称。
- 服务地址。

“保存并测试”会保存设置并发起连接测试。密钥保存成功后页面只显示已保存状态，不回显原密钥。读取失败、配置错误和连接错误都会给出不同反馈。`重置 DeepSeek` 只重置相关配置。

README 中出现的第三方中转服务信息只是界面现有推荐内容，不代表 bilimi 对第三方可用性、价格或安全性作保证。你也可以使用自己信任且兼容的服务地址。

### 整理策略

这里控制本地分类与学习记录，包括：

- 是否记录归档调整。
- DeepSeek 返回的关键词建议。
- 待处理和已处理建议视图。
- 采纳、忽略或删除建议。

采纳建议才会真正改动本地收藏夹关键词；忽略或删除不会自动改变规则。纠错记录用于审计和后续参考，不会未经确认直接改写分类体系。

### 宠物设置

- 选择“萌版大头”或“Q版小人”样式。
- 控制全屏视频时是否自动收起小咪。
- 控制是否显示打开小咪的入口。
- 调整与小咪相关的其他显示和交互偏好。

设置保存后会同步到主窗口和悬浮窗口。恢复默认布局只恢复窗口/布局尺寸；重置设置会恢复更广泛的偏好，请注意两者区别。

### 视频音频转写速度

- `无限制`：最快，占用最高。
- `1 线程`：更省电，速度较慢。
- `2 线程`：平衡。
- `4 线程`：较快。

线程数影响 whisper.cpp 本地转写阶段，不会提高网络下载速度。

### bilimi 收藏策略

选择每个视频最多同时保存到 1、2 或 3 个 bilimi 收藏夹。该设置影响日常批阅归类、旧藏预览和最终执行。修改后，已有预览可能需要重新计算或重新扫描。

### 批阅动作设置

- 厚赏默认投 1 枚或 2 枚硬币。
- 短评随机生成并直接发送，或生成 3 条候选再选择。

直接发送属于真实账号操作。若希望在发表前检查内容，建议使用“3 条候选”模式。

### 关闭设置

- `最小化到系统托盘`：关闭主窗口时隐藏到托盘，双击托盘图标或选择“打开 bilimi”恢复。
- `退出启动器`：关闭主窗口时结束应用。
- `退出前确认`：只在关闭行为为退出启动器时生效。

托盘菜单提供打开应用和退出入口。安装包、主窗口、任务栏和托盘统一使用当前应用图标。

## 小咪桌面伴随窗口

### 用途

小咪是始终可见或按设置显示的桌面伴随入口。它可以在主窗口隐藏时唤醒应用，并通过状态、动作和气泡反馈后台任务。

### 基本操作

- 点击或唤醒：恢复并聚焦主窗口。
- 拖动：移动小咪在屏幕上的位置。
- 打开助手：在小咪旁边打开独立助手工作区。
- 快捷菜单：触发批阅、札记、掌库等常用入口。
- 调整尺寸：通过悬浮窗口支持的尺寸步进改变显示大小。

小咪的位置和助手展开方向会根据屏幕工作区计算，尽量避免窗口超出屏幕边缘。

### 状态表现

小咪会显示空闲、工作、提示、成功和错误等状态。页面点赞等交互也可能触发轻量提示。长任务期间，小咪状态与助手全局提示共同反映进度。

### 鼠标与遮挡

悬浮窗支持在特定交互状态下切换鼠标穿透，以避免挡住底层页面。视频全屏时可按设置自动收起。若小咪位置异常，可尝试拖动、恢复默认布局或重启应用。

## 本地音频转写

Windows 安装包内置：

- `yt-dlp.exe`
- `ffmpeg.exe`
- `ffprobe.exe`
- whisper.cpp Windows 运行时
- `ggml-small.bin`

普通用户不需要另行安装 Node.js、Python、ffmpeg、yt-dlp 或语音模型。

转写流程大致为：

1. 从当前视频读取必要信息和登录会话。
2. 使用 yt-dlp 下载可用音频。
3. 使用 ffmpeg/ffprobe 检查并准备音频。
4. 使用 whisper.cpp 和本地模型分段转写。
5. 生成无时间线和带时间线文稿。
6. 自动保存到档案库。
7. 如果开启自动总结，再调用 DeepSeek 生成总结。

音频下载仍依赖 B 站页面、网络、登录状态和 yt-dlp 对当前站点规则的支持。工具失败只应让当前任务失败，不应拖死主窗口或其他助手页面。

## 数据、隐私与凭据

- 偏好、札记档案、备注、星标和整理记录保存在本机用户数据中。
- DeepSeek API 密钥由 Electron 主进程保存，不作为普通渲染层明文状态暴露。
- 密钥保存成功后设置页不回显原文。
- B 站登录状态由应用内 WebView 会话维护。
- 音频转写在本地执行；若开启 DeepSeek 总结，文稿内容会发送给配置的服务端。
- 旧藏 DeepSeek 整理会发送完成判断所需的视频和收藏夹文本信息。
- 不要把 cookie、CSRF token、账号 ID、API key、真实用户数据或完整隐私路径提交到仓库或公开 issue。

如需备份，请在退出应用后备份对应用户数据。恢复前先保留现有数据副本，避免覆盖新档案。

## 常见问题与故障排查

### Windows 阻止安装

当前安装包未签名。确认文件来自本仓库 Releases 后，在 SmartScreen 中选择“更多信息”继续。若文件名或来源不一致，请不要运行。

### 启动后一直停留在启动中

1. 完全退出 bilimi，包括系统托盘中的进程。
2. 重新启动。
3. 检查杀毒软件是否隔离 Electron 或应用资源。
4. 尝试重新安装同版本。
5. 仍无法启动时，在 issue 中提供版本、Windows 版本和可公开的错误日志，不要附带凭据。

### B 站页面空白或加载很慢

- 检查系统网络和 B 站网页是否可访问。
- 刷新当前标签。
- 关闭异常标签后重新打开。
- 确认系统时间和代理设置正常。
- B 站临时故障时稍后重试。

### 批阅按钮无效

- 确认当前是可播放的视频页。
- 确认已登录。
- 等待页面加载完成后重试。
- 查看 B 站页面是否已经处于目标状态。
- 运行设置诊断。
- 如果 B 站改版导致自动化失效，需要等待 bilimi 更新。

### 掌库提示先备册或同步

先进入掌库点击“备册”，检查收藏夹草稿，勾选需要的收藏夹并点击“同步”。保存草稿不会自动更新 B 站。

### 旧藏扫描失败

- 确认已登录 B 站。
- 确认收藏页可正常打开。
- 减少本轮扫描来源后重试。
- 检查是否接近 99 个收藏夹上限。
- DeepSeek 失败不应阻止继续使用本地预览，可关闭辅助整理后继续。

### 转写无法开始

- 确认当前视频可播放且已识别 BV 号。
- 确认网络和登录状态。
- 在设置运行诊断，检查媒体工具和模型。
- 检查磁盘空间。
- 某些视频的音频流、权限或区域限制可能阻止下载。

### 转写很慢或 CPU 占用高

这是本地语音识别的正常开销。到设置把转写速度改为 1 或 2 线程；同时运行多个重任务会进一步降低速度。

### DeepSeek 保存或测试失败

- 确认已启用 DeepSeek。
- 重新填写 API 密钥。
- 核对模型名和服务地址。
- 检查余额、服务商状态和网络代理。
- 设置页不会显示旧密钥；读取状态异常时直接重新填写并保存。

### 关闭窗口后应用还在运行

关闭行为可能设置为“最小化到系统托盘”。在系统托盘找到 bilimi 图标，双击恢复，或右键选择退出。也可在设置改为“退出启动器”。

### 小咪不见了或位置异常

- 在设置确认已启用显示小咪入口。
- 退出视频全屏。
- 使用“恢复默认布局”。
- 从托盘恢复主窗口后重试。
- 多显示器布局变化后重启应用。

## 已知限制

- Windows 安装包尚未代码签名。
- 安装包体积较大，因为内置本地媒体工具、whisper.cpp 和语音模型。
- B 站页面自动化可能随页面结构或接口策略变化而失效。

- DeepSeek 功能依赖用户自行配置的服务，可能产生费用。
- DeepSeek 输出可能有误，评论、总结和分类建议都需要用户自行判断。
- 当前不承诺每个转写任务有固定自动超时；可由用户取消并重试。
- 应用以 Windows x64 为主要发布目标，其他平台未提供正式安装包保证。
