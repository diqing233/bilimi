## 已确认展示规则

1. **已同步**：本轮同步写入已收到成功结果，或当前可识别的 B 站实际归属与收藏库目标一致。
2. **未同步**：没有成功同步结果、同步失败、当前可识别的 B 站归属与目标不一致，或历史数据无法识别。
3. 不显示“等待回读确认”“回读不一致，需核验”“同步状态待确认”“写入回执已成功”、目标名称、回执时间或任何替代同步状态的说明文字；详情“收藏归属”的`B站收藏夹`和`归属状态`也不得显示这些文字。
4. 对历史数据无法判断的情况，状态保持`未同步`，用户可点击现有`重新整理`，不新增提示、对账弹窗或自动 B 站写入。

## 讨论结论回填

- 截图中的黄色标签不是 B 站提示，而是本地提交 `5d52c022` 新增的“写入回执与扫描回读分开”展示。该设计虽然试图避免把回执伪造成扫描事实，但增加了用户不需要的中间状态，已被 `R001` 明确否决。
- 实施时应简化**用户可见状态枚举**与筛选验证为两值；内部成功记录可保留以避免重复同步，但不能再投影为第三种用户状态。
