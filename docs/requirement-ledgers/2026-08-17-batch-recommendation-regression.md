## 已确认条目（实施前复核）

1. `R001`：任一批的新/变化标签结果必须自动刷新推荐、归档预览和相应系统分类；点击`采用当前标签`不是生成推荐的前置条件。
2. `R002`：采用是安全暂停后的当前标签截止版本收束；不等待所有原待补取标签自然结束。采用完成、全范围重算完成且 DeepSeek 未运行后，整轮保存和同步可用。
3. `R003`：多批中单个已完成批只允许`保存本批到收藏库`，不开放 B 站同步。
4. `R004`：先迭代项目书，再按本账本和项目书修改；项目书只记录最终功能契约。
