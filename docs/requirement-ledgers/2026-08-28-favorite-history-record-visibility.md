## 讨论证据

- 截图中弹层确实只显示一个“当前记录”文本和“恢复初始改动”按钮，未显示可逐项选择的历史列表；这只能证明当前可见 UI 只有一个位置，不能证明 journal 中仅有一条记录。
- 项目书 §5.5 已规定：规则/勾选/分类移动应合并为一个可恢复历史条目；新建规则或推荐草稿本身不产生可见历史；勾选但没有分类移动时不应通过改动记录恢复。当前排查将分别核对这些设计边界与实际丢失情况。
- 当前开发版本地工作区的 journal 保留了 6 个 classification 事件：2 条扫描期自动分类（cursor 1、2）、`history-baseline = 2`、两次位于 cursor 3 的`honker233`重新分类及其规则快照；其间有 3 次游标移动。journal 回放按同一 cursor 保留当前分支，最后一次在 cursor 3 的操作替换了之前 redo 分支，因此当前有效历史为 3 个位置，基线之后仅 1 个可恢复位置。
- 主进程快照仅发布 `cursor > baselineCursor` 的历史。渲染器将当前 cursor 显示为普通的“当前记录”，只把其他 cursor 渲染为可点击菜单项。因此实际只有一个基线后位置时，截图会呈现为一行静态说明加“恢复初始改动”，没有第二条可点击记录。这是当前呈现和分支语义的结果，不是 journal 空了。
