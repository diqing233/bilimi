## 实施计划（按原文讨论顺序）

### P001 — 推荐实体解析与详情删除分流（覆盖 I001-I002；R001-R005）

- 允许修改：`ControlledFavoriteLedgerPanel.tsx`、`FavoriteLedgerOverview.tsx` 及其定向测试。
- 预期结果：用现有候选—规则映射解析被请求/操作的真实已保存工作夹 ID；详情删除先判断是否为当前推荐关联。未备册走现有本地规则删除，已备册/未绑定只持久化取消当前推荐选择。
- 回归风险：同名普通工作夹、未保存草稿、默认收藏夹、非当前整理草稿的工作夹不应被误归为推荐项。
- 测试方案：先为“旧候选 ID 映射真实已保存 ID”“未备册详情删除”“已备册/未绑定详情仅取消”写失败测试，再最小实现。
- 界面验收：在真实 Electron 中打开当前推荐工作夹，分别观察未备册删除与已备册/未绑定取消勾选；不点击任何 B 站删除操作。

### P002 — 删除模式批量分流与状态收敛（覆盖 I002-I003；R005-R007）

- 允许修改：`FavoriteLedgerOverview.tsx`、`ControlledFavoriteLedgerPanel.tsx` 及其定向测试。
- 预期结果：右侧批量删除将推荐关联项按实际状态拆分；只取消项不会调用本地规则/B 站/收藏库删除，未备册项继续调用本地规则删除；混合选择完成后两处勾选状态一致。
- 回归风险：现有普通自建工作夹的本地删除、未保存草稿直接删除、默认收藏夹保护和显式 B 站删除弹窗。
- 测试方案：先写混合选择、取消分支不调用删除 IPC、失败不虚假取消的失败测试；运行受保护的现有右侧删除测试。
- 界面验收：进入右侧删除模式，验证选中样式、取消/关闭后的恢复状态，以及删除后推荐勾选和顶部卡片的实际状态。
