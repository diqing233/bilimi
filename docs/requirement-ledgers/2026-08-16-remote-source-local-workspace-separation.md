## 已确认清单

1. **R003：B 站收藏夹统一按远端归属展示。** 所有 B 站收藏夹（包括名字含 `bilimi` 的夹）主显示在“用户收藏夹（B 站）”；名称、前缀或远端观察不得取得 bilimi 身份。
2. **R002、R003：bilimi 工作区是本地事实。** 它展示本地草稿、已保存规则、本地已整理/入库数据、数量和绑定/对账状态；它不是第二份远端收藏夹列表。
3. **R002：有可靠本地关系但远端未绑定时，两处关联投影。** B 站夹仍在用户收藏夹中；本地工作区显示“待重新备册/绑定/对账”，以真实规则 ID 与远端 folder ID 关联。默认不能成为扫描来源，先对账或显式处理关系。
4. **R001、R003：仅名称相似的远端夹保持普通用户夹。** 它可作为扫描来源；不得自动移动到 bilimi 区、自动绑定或在用户选择同步时隐式绑定。
5. **R001：绑定与同步分开确认。** 用户先在明确界面确认本地规则、远端收藏夹、当前账号、容量和副作用，执行“确认绑定”；成功后才可执行“同步到 B 站”。
6. **R001：标签采用可恢复但不重复处理旧结果。** 已采用批次可继续补取；只有发现尚未采用的新标签或变化标签后才重新显示并启用`采用当前标签`。再次采用只重算系统结果，保留人工分类和已勾选推荐；无变化时维持已采用状态。
7. **R004：本轮只更新项目书、需求账本和实施计划。** 不改 `src/`、`electron/`、测试、Electron 应用数据或 B 站数据。
