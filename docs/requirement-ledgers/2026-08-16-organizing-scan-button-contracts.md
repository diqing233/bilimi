## 开始后的确认清单

### 已确认

1. **R001：扫描与标签按钮状态契约。** 项目书必须逐一规范继续扫描、暂停扫描、从头重新扫描、网络/风控恢复后的继续或重扫、工作镜像重建，以及暂停/继续补取标签和重新补取失败标签的显示、禁用、结果和失败边界。
2. **R001：`采用当前标签` 的可逆循环。** 已采用后按钮消失是当前状态的结果，不是永久终点；点击 `继续补取标签` 后当前批恢复读取资格，新标签产生后允许再次采用，且每次采用都只重算系统结果、保留人工分类与已勾选推荐。
3. **R001：单批、多批和“整理收藏批次”设置的联动。** 设置选项、下一轮生效、当前草稿不重切分、多批切换器和后台补取标签的独立性均应被写成可验收规则。
4. **R002：扫描概览分区。** 用户普通收藏夹、已绑定 bilimi 工作夹、待重新备册/绑定的本地已知 bilimi 工作夹必须按身份而非名称前缀分类；工作夹不可误选为扫描来源。
5. **R002：历史对话中已定位的新问题纳入项目书。** 任一批已就绪即在本轮总览显示该批已就绪数据；其他批标签补取不得遮住它。取消未备册推荐后，推荐区、上方卡片与持久化实体必须同步，不能出现幽灵卡片或对不存在实体二次删除。
6. **R003：开始授权。** 本轮仅在隔离工作树修改项目书、账本和计划；不修改业务代码、测试、Electron 应用数据或 B 站数据。
