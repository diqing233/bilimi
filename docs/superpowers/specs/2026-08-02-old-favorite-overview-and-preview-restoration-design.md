# 整理旧藏全览与归档预览恢复设计

## 目标

在不恢复 1.0.5 大型 renderer 状态栈、不破坏现有分批持久化和 DeepSeek 流程的前提下，完成四件事：

1. 让多批整理拥有清晰的“当前批次 / 本轮总览”视角，用户可以只操作一次完成整轮整理。
2. 修正收藏库“同步、保护、整理”三种状态的事实来源和筛选语义。
3. 把 1.0.5 已有但在核心重写后丢失的归档预览转移、历史、撤销恢复和反馈契约移植到当前架构。
4. 修复卡片边框、长内容查看和“显示全部”导致卡片变高等 UI 退化，同时守住 2000 条单批和数万条整轮数据的交互响应边界。

## 不在本轮范围

- 不改变 B 站远端写入节奏、风控策略或账号数据。
- 不恢复旧版整棵大列表和 renderer 内全量草稿状态。
- 不改变 DeepSeek 提示词、分类算法、LocalData、转写、模态框和安装版。
- 不打包、不发布、不 push。
- 不以 jsdom 通过证明真实鼠标不卡；性能结论必须来自真实 Electron 输入测量。

## 已确认根因

### 收藏库状态错误

当前列表把 `pendingStates` 缺少异常状态近似为“已同步”，并把 `protected` 近似为“已整理”。这两个推导都没有使用持久化仓库中已经存在的位置事实，因此未整理或远端位置未知的视频也会显示成已同步/已整理。该问题与批次数量无关，单批和多批都可能出现。

### 归档预览功能丢失

1.0.5 的完整交互位于 `FavoriteLedgerPanel.tsx`。`afb883cc refactor: replace legacy old favorite core` 后，当前持久化工作区只部分恢复了外壳：单条转移覆盖全部目标、renderer 历史只收到压缩摘要、快捷键没有注册，卡片来源提示、目标组聚焦和最近改动反馈也未完整迁移。这是已提交的架构迁移缺口，不是当前脏工作树造成。

### 卡片视觉退化

当前卡片完整轮廓没有包住操作区，透明边框对比度不足；虚拟轨道中的卡片同时受到最小高度和百分比高度约束，“显示全部”后会随轨道拉高。长标题、标签和来源也缺少按需展示完整内容的统一入口。

## 数据事实与状态语义

收藏库列表行由主进程输出明确的三维状态，renderer 不再从一个混合 `pendingStates` 数组反向猜测：

- `syncState: 'synced' | 'unsynced'`
  - 只有远端观测事实证明视频实际位于 B 站 bilimi 工作夹时才是 `synced`。
  - 只在普通用户收藏夹、同步中、失败、结果未知、没有远端观测证据时均是 `unsynced`；详情仍可显示具体原因。
- `protectionState: 'protected' | 'unprotected'`
  - 只由保护记录决定。
- `organizationState: 'organized' | 'unorganized'`
  - 只有视频位于收藏库正式工作夹时才是 `organized`。
  - 暂存区和普通来源收藏夹不算已整理。

筛选器提供三个独立三态维度：

- 同步：全部 / 已同步 / 未同步
- 保护：全部 / 已保护 / 未保护
- 整理：全部 / 已整理 / 未整理

同一维度内部单选，跨维度使用 AND。移除混合“待处理”筛选，但保留失败、结果未知等详情说明和历史任务入口。

## 多批当前视角与本轮总览

### 显示条件与默认值

只有 `segments.length >= 2` 时显示视角切换。单批体验保持现状，不增加额外步骤。

默认视角：

- 扫描概览：本轮总览
- 推荐收藏夹：当前批次
- 归档预览：当前批次
- 确认执行：本轮总览

### 开放时机

- 第一批未完成前，总览只显示扫描进度，不可执行整理操作。
- 第一批完成后开放总览，显示“已汇总 1/N 批”。
- 后续仅在整批完成时更新总览；批内逐条标签变化不刷新总览大结构。
- 后台扫描时当前批次视角保持稳定，不因下一批进度自动切换。

### 扫描概览

当前批次显示该批次内视频来自哪些用户收藏夹及各自数量。总览显示所有已完成批次合并后的来源计数、失效视频计数、标签进度和整轮进度，不铺开全部视频 AID。

失效视频和账号已注销视频进入独立统计，不参与默认分类、推荐收藏夹、归档预览目标计数或 DeepSeek 分类。保留其来源收藏夹计数，便于用户知道问题来自哪里，不在总览展示 AID 列表。

### 推荐收藏夹

当前批次只展示当前批推荐；总览展示已完成批次的推荐合并结果和计数。推荐只在每批完成时增量合并稀疏 AID 索引，不重复扫描已完成批次。推荐收藏夹不自动勾选，由用户手动选择。

多批时显示说明：用户可以在第一批结束后使用自建收藏夹和默认分类先整理；如需完整推荐，应等待全部标签补取完成再选择推荐收藏夹。

### DeepSeek 全批

两批及以上时，DeepSeek 提供“当前批次”和“本轮所有批次（推荐）”。选择整轮后：

1. 使用同一份用户配置处理已就绪批次。
2. 尚未扫描完成的批次进入等待，不阻塞鼠标、侧栏、最小化或关闭窗口。
3. 下一批完成后自动续跑，不要求用户重新选择。
4. 每批完成后保存检查点；取消后保留已完成批次结果，再次开始只处理未完成部分。

## 归档预览

### 当前批次

保留逐视频查看、单条调整和单批执行。每组默认只渲染前 6 条，超过 50 条继续使用横向虚拟化。

### 本轮总览

总览是整轮控制页，不是视频墙。它展示：

- 目标收藏夹及启用状态
- 已完成批次 / 总批次
- 预计归档数量
- 失效、跳过和冲突数量
- 每个目标在各批次的数量入口

用户可在总览启用或取消目标收藏夹、调整整轮规则；查看具体视频时进入对应批次。整轮确认仍按批次顺序编译和执行远端计划，每批落检查点。

## 恢复 1.0.5 交互契约

### 多目标转移

- 一条视频最多保留三个目标收藏夹。
- 从当前目标组执行“转移”时，只替换当前目标，保留其他目标，不得覆盖整条 `targetLedgerIds`。
- “转为未分类”区分“只移出当前分类”和“移出全部分类”。
- 多目标视频可以同时出现在对应目标组，但每组仍遵守折叠和虚拟化限制。

### 位置与反馈

- 转移后卡片排到目标组最左侧。
- 来源组和目标组横向位置重置到最左，目标组滚动到可见区域。
- 卡片显示本轮最初分类；连续转移不得覆盖该基线。
- 最近改动卡片显示稳定标记，并给出“原分类 → 新分类”的即时短提示。

### 历史与撤销恢复

- 主进程继续持有 before/after 稀疏 changes 和 durable cursor。
- renderer 的历史菜单只接收可读摘要：标题、原目标、新目标、操作原因、影响数量和 cursor；不传输整批全部分类对象。
- 大批量操作产生一条汇总历史，详情按需加载或从已有稀疏 change 摘要生成。
- 页面按钮和 `Ctrl+Z`、`Ctrl+Shift+Z` / `Ctrl+Y` 调用同一持久化 cursor API。
- 输入框、可编辑元素或系统保留组合键中不拦截快捷键。
- 撤销恢复只重放受影响 AID，不重扫、不重分类、不重建全部列表。

## 卡片与可访问性

- 完整卡片（资料区和操作区）拥有同一可见轮廓，亮暗主题均可辨识。
- “显示全部”只扩大横向数据窗口，不改变卡片固定高度。
- 长标题、来源、标签使用省略显示；鼠标悬浮或键盘聚焦时由一个共享、按需 tooltip 展示完整信息。
- tooltip 不为每张卡常驻创建大型 DOM，不遮挡主要操作，并可由 Escape 关闭。
- 图标按钮具有 `aria-label`，焦点态可见，撤销恢复快捷键文案与真实行为一致。

## 性能约束

- renderer 永远不因切换总览而物化数万条视频。
- 总览数据使用每批完成时生成的摘要和稀疏 AID 索引。
- 单条转移、勾选、撤销、恢复只更新受影响 AID 和组索引。
- 回调和 memo 边界保持稳定，不把批内标签进度传入整个归档预览树。
- 50 条以上组继续虚拟化；折叠组不挂载完整卡片列表。
- 点击后 100ms 内显示选中、忙碌或禁用反馈；异步任务不得使用阻塞式 renderer 循环。
- 2000 条当前批次的真实 Electron 验收必须确认鼠标移动、侧栏操作、最小化和关闭窗口仍可响应。

## 兼容与迁移

- 旧草稿缺少总览摘要时，主进程按现有分段 journal 重建每批摘要，不要求重新请求 B 站数据。
- 旧列表行没有三维状态字段时，主进程在读取时从仓库位置和保护事实补齐；renderer 不自行猜测。
- 不改变已有 IPC 名称的语义时优先扩展返回结构；确需新 IPC 时保持旧调用可用并增加契约测试。

## 验收

### 自动化

- 收藏库三维状态与 AND 筛选测试。
- 单批不显示视角切换、多批显示并保持默认视角测试。
- 每批完成才刷新总览、失效视频不参与分类测试。
- DeepSeek 全批等待、取消保留检查点和续跑测试。
- 多目标转移、只移出当前目标、目标组前置、原分类基线测试。
- 历史摘要、按钮撤销恢复、快捷键及输入框保护测试。
- 卡片完整边框契约、共享 tooltip 和虚拟卡片稳定高度测试。

### 真实 Electron 开发版

- 单批和多批流程。
- 扫描概览、推荐收藏夹、归档预览的当前批次 / 本轮总览切换。
- 当前批和全批 DeepSeek；等待下一批、取消、续跑。
- 单条与多目标转移、目标组最左、原分类提示。
- 改动记录、按钮撤销恢复、键盘快捷键。
- “显示全部 / 收起”卡片高度稳定。
- 2000 条当前批操作期间鼠标、侧栏、最小化和关闭仍响应。

真实验收只说明操作路径和测得响应；没有输入时延数据时不得宣称真实卡顿已经解决。
