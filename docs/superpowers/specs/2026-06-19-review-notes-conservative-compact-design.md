# Bilimi 批阅与札记保守压缩设计

- 日期：2026-06-19
- 状态：待实现
- 范围：助手工作区中的 `批阅` 页和 `札记` 页视觉密度压缩
- 不包含：信息架构重排、抽屉化改版、图标化工具栏、全局档案库结构调整

## 1. 背景

当前助手侧栏宽度固定为 384px，`批阅` 和 `札记` 都使用青花瓷视觉系统。最近的札记改版补齐了转写、档案库、文稿、时间线、总结、批注、备注和 Markdown 导出，但界面在小侧栏里显得偏大。

用户在可视化对比中选择了 A 方案：保守压缩。该方案不改变现有操作路径，只降低块间距、按钮高度、内边距和局部文本体量，让页面看起来更轻、更紧凑。

## 2. 目标

1. `批阅` 页和 `札记` 页使用一致的紧凑密度。
2. 保留现有 DOM 结构、交互顺序和可访问角色。
3. 批阅动作仍保持两列布局，窄屏下继续一列。
4. 札记页仍按当前顺序展示视频信息、生成归档、结果入口、内容、批注、备注和导出。
5. 压缩后按钮、输入框和文本仍可读、可点击，不出现文字溢出或重叠。

## 3. 非目标

1. 不把批注、备注、Markdown 改成抽屉。
2. 不把文稿入口改成图标-only 工具栏。
3. 不改变 `VideoNotesPanel` 的状态逻辑或数据保存逻辑。
4. 不改动全局档案库列表和详情布局。
5. 不处理现有中文乱码文本问题；本次只调整布局密度。

## 4. 批阅页压缩设计

`MemorialPanel` 结构保持不变，只调整 CSS。

### 4.1 面板外壳

- `.memorial-panel__paper` padding 从 12px 收到 8px。
- 内部 gap 从 10px 收到 6px。
- 侧栏嵌入场景沿用同一套密度，不增加单独例外。

### 4.2 视频信息块

- `.memorial-panel__meta` padding 从 8px 收到 6px。
- 文本行高从 1.5 收紧到约 1.4。
- 标题仍使用单行省略，避免撑高批阅页。

### 4.3 动作按钮

- `.memorial-panel__actions` gap 从 8px 收到 6px。
- `.memorial-panel__action` min-height 从 62px 收到 52px 左右。
- 动作印章从 28px 收到 24px，网格第一列同步变窄。
- 动作说明保留，但字号和行高维持轻量，不强行隐藏。

## 5. 札记页压缩设计

`VideoNotesPanel` 结构保持不变，只调整 CSS。

### 5.1 页面密度

- `.video-notes` gap 从 10px 收到 6px。
- 源信息、主操作、进度、tabpanel、批注、备注块 padding 从 8px 收到 6px。
- 源信息内部 gap 从 6px 收到 4px，标题字号从 15px 收到 14px。

### 5.2 主操作区

- 主操作区 gap 从 8px 收到 6px。
- 主按钮 min-height 从 36px 收到 32px。
- 按钮 min-width 可小幅降低，避免在窄侧栏中产生挤压。

### 5.3 结果入口

- 三个结果入口继续三列。
- gap 从 6px 收到 4px。
- 每个入口 min-height 从 58px 收到 44px 左右。
- 说明文字保留但弱化，并限制成更紧凑的行高。

### 5.4 内容与表单

- 纯文稿区域 max-height 从 190px 降到约 160px。
- 普通 textarea min-height 从 72px 降到约 60px。
- Markdown 预览 min-height 从 180px 降到约 130px。
- 批注列表 item padding 和 gap 小幅降低。

## 6. 响应式规则

1. `max-width: 900px` 下继续让札记主操作、结果入口和档案库主体切为单列。
2. `max-width: 380px` 下批阅动作继续单列。
3. 本次不新增断点。

## 7. 测试策略

1. 更新样式测试，覆盖批阅动作按钮和札记入口的紧凑尺寸规则。
2. 保留现有 `MemorialPanel` 和 `VideoNotesPanel` 行为测试。
3. 运行相关测试和样式测试，确认布局类名与交互没有回退。

## 8. 验收标准

1. 批阅页整体视觉高度明显降低。
2. 札记页主要区块高度明显降低。
3. 两页视觉密度一致。
4. 现有批阅动作、札记生成、保存、批注、复制等测试不因布局压缩失败。
5. 完成实现后按项目要求整体提交一次 git commit。
