# Bilimi 视频札记设计规格

- 日期：2026-04-28
- 状态：已确认设计稿，等待实现计划
- 范围：当前视频的本地文稿整理、速览、时间线、笔记归档
- 设计选择：奏折面板内置页签，采用“完整文稿 + 视频速览”的本地整理方案

## 1. 背景

Bilimi 现有 MVP 已经具备 Electron 内嵌 B 站浏览、右下角印玺入口、奏折式助手面板、视频分类、评论候选、收藏与掌库相关能力。用户现在希望新增一个笔记能力，用来整理当前视频的重点和文稿。

本规格将该能力命名为 **札记**。札记不是新的独立窗口，也不是后台爬取器，而是当前奏折面板里的一个页签能力。用户正在看哪条视频，Bilimi 就基于当前 `webview` 页面提取可用信息，整理出可保存的本地笔记。

第一版强调稳定、可解释、隐私友好：整理过程完全本地完成，不调用大模型 API，不上传字幕或文稿。

## 2. 目标

1. 在助手奏折面板中新增 **札记** 入口，和现有批阅动作保持同一产品语境。
2. 从当前 B 站视频页读取视频元信息，包括标题、UP 主、简介、标签、BV 号、URL。
3. 尝试读取当前视频可用字幕或文稿，并统一成带时间点的文稿段落。
4. 如果未发现字幕，提供手动粘贴文稿入口。
5. 基于本地规则生成视频速览，包括 3 分钟看懂、时间线重点、精彩片段提示、关键词。
6. 保留完整文稿作为笔记底稿，速览只是批注和导航。
7. 支持把札记保存到本地，后续可查看、复制和继续编辑。
8. 抓取失败或字幕缺失时给出清晰兜底，不阻断用户手动整理。

## 3. 不做内容

1. 不做后台批量爬取。
2. 不扫描观看历史、浏览历史或最近打开内容。
3. 不做音频转写。
4. 不做 OCR 识别画面文字。
5. 不接入大模型 API。
6. 不上传用户字幕、文稿、笔记或账号信息。
7. 不承诺抓到所有视频的字幕。
8. 不对 B 站页面执行点赞、投币、评论、收藏以外的新平台写操作。

## 4. 核心体验

用户打开一个 B 站视频后，点击右下角印玺展开奏折。奏折中出现 **批阅** 与 **札记** 两个主要内容区。进入札记后，用户可以点击 **整理札记**。

系统开始读取当前视频页：

1. 先读取视频元信息。
2. 再尝试读取字幕列表和字幕 JSON。
3. 如果读取成功，自动清洗并生成札记。
4. 如果读取失败，显示粘贴文稿输入框。
5. 用户确认生成结果后，可以保存到本地札记库。

札记结果使用三个页签：

1. **速览**：展示 3 分钟看懂、关键词、时间线重点和精彩片段。
2. **文稿**：展示完整文稿，按时间点分段，可复制。
3. **归档**：展示来源、视频信息、生成时间、保存状态和本地备注。

## 5. 信息架构

### 5.1 奏折面板页签

现有 `MemorialPanel` 保持奏折气质。札记入口不另开全屏窗口，而是在面板内部增加页签或分段切换。

建议结构：

- 顶部：当前视频标题、分类判词、关闭按钮。
- 一级页签：`批阅`、`札记`。
- 札记内部二级页签：`速览`、`文稿`、`归档`。

### 5.2 速览页

速览页面向“快速理解视频”：

1. 一段短摘要，控制在 3 到 5 句。
2. 关键词列表，最多 8 个。
3. 时间线重点，每条包含起始时间、标题、简短说明。
4. 精彩片段候选，基于字幕密度、关键词和段落位置生成。

### 5.3 文稿页

文稿页是札记的底稿：

1. 完整展示已抓取或用户粘贴的文稿。
2. 有时间点时显示时间戳。
3. 无时间点时显示自然段。
4. 支持复制全文。
5. 支持重新粘贴并整理。

### 5.4 归档页

归档页处理保存和来源：

1. 视频标题。
2. UP 主。
3. BV 号和 URL。
4. 生成时间。
5. 字幕来源：自动字幕、UP 主字幕、用户粘贴。
6. 保存状态。
7. 用户备注。

## 6. 抓取策略

抓取发生在当前 `webview` 页面上下文中，通过 `executeJavaScript()` 执行只读脚本。

### 6.1 元信息提取

从页面 DOM、结构化数据和全局播放器状态中读取：

```ts
type VideoNoteSourceMetadata = {
  title: string
  author?: string
  description?: string
  tags: string[]
  bvid?: string
  url: string
}
```

标题和 URL 是最低可用字段。其他字段缺失时不阻断札记生成。

### 6.2 字幕提取

字幕提取按优先级执行：

1. 页面播放器状态中可用的字幕列表。
2. 页面脚本数据中暴露的字幕 JSON 地址。
3. 已渲染到页面的字幕或文稿区域。
4. 用户手动粘贴。

统一输出：

```ts
type TranscriptSegment = {
  start: number | null
  end: number | null
  text: string
}
```

有时间戳的字幕保留时间点。用户粘贴的纯文稿使用 `start = null` 和 `end = null`。

### 6.3 抓取边界

允许读取当前页面已经可见或已加载的数据。第一版不构造后台批量请求，不遍历用户空间，不抓取历史记录。

如果字幕 URL 请求失败、字幕为空、页面结构变化或视频没有字幕，系统进入手动粘贴兜底。

## 7. 本地整理策略

本地整理模块接收元信息和文稿段落，生成结构化札记。

### 7.1 文稿清洗

清洗规则：

1. 去除空白段。
2. 合并过短连续片段。
3. 去除完全重复的相邻句。
4. 保留原始时间点。
5. 保留原文，不做激进改写。

### 7.2 分段

有时间戳时，优先按时间间隔和段落长度分段。无时间戳时，按自然段和句子数量分段。

每个分段输出：

```ts
type TranscriptChapter = {
  start: number | null
  title: string
  summary: string
  segmentIndexes: number[]
}
```

### 7.3 关键词

第一版使用本地规则提取关键词：

1. 去掉常见虚词和语气词。
2. 统计中文词组、英文词、数字组合的出现频率。
3. 结合标题、标签和简介提高权重。
4. 最多输出 8 个关键词。

### 7.4 速览

速览内容由章节摘要和关键词组成：

```ts
type VideoNoteOverview = {
  shortSummary: string[]
  keywords: string[]
  timeline: VideoNoteTimelineItem[]
  highlights: VideoNoteTimelineItem[]
}

type VideoNoteTimelineItem = {
  start: number | null
  title: string
  detail: string
}
```

本地摘要不追求大模型式理解，只做可解释的提炼：优先选择章节开头、重复关键词附近、标题相关句子和信息密度较高的句子。

## 8. 本地保存

札记保存到本地 store。可以复用现有 `electron-store` 边界，也可以在主进程 store 中新增独立字段。

建议模型：

```ts
type VideoNote = {
  id: string
  source: VideoNoteSourceMetadata
  transcriptSource: 'auto' | 'manual'
  transcript: TranscriptSegment[]
  chapters: TranscriptChapter[]
  overview: VideoNoteOverview
  userMemo: string
  createdAt: string
  updatedAt: string
}
```

`id` 使用 BV 号和 URL 生成稳定标识。用户重新整理同一视频时，默认更新同一条札记，并保留 `updatedAt`。

## 9. 错误处理

1. 当前页面不是视频页：提示“尚未见到可整理的视频案卷”。
2. 读取元信息失败：提示重试，并允许用户手动粘贴文稿。
3. 未发现字幕：进入手动粘贴状态。
4. 字幕为空：提示“文稿为空，可粘贴文稿后再整理”。
5. 本地保存失败：保留当前整理结果，提示用户重试保存。

错误提示保持角色语气，但必须直接说明问题和下一步。

## 10. 安全与隐私

1. 第一版不把文稿发送到任何外部服务。
2. 不读取浏览器历史、剪贴板、账号密码或本地敏感文件。
3. 只在用户点击整理札记后读取当前 `webview` 页面。
4. 手动粘贴内容只保存在本地。
5. 删除本地札记属于删除数据操作，后续实现时需要二次确认。

## 11. 测试策略

### 11.1 单元测试

覆盖：

1. 视频元信息提取脚本生成。
2. 字幕 JSON 到 `TranscriptSegment` 的转换。
3. 文稿清洗和短句合并。
4. 章节切分。
5. 关键词提取。
6. 速览生成。
7. 本地札记保存和更新。

### 11.2 组件测试

覆盖：

1. 札记入口渲染。
2. `速览 / 文稿 / 归档` 页签切换。
3. 无字幕时显示粘贴入口。
4. 整理成功后展示完整文稿和速览。
5. 保存失败时保留结果。

### 11.3 人工验证

在 Windows Electron 应用中验证：

1. 有字幕的普通 B 站视频可以生成札记。
2. 无字幕视频进入粘贴兜底。
3. 同一视频重复整理更新本地札记。
4. 不登录状态下至少能对公开可见视频显示合理失败提示。

## 12. 实现边界

建议新增模块：

1. `videoNoteExtractor`：生成当前页面元信息和字幕读取脚本。
2. `transcriptNormalizer`：清洗字幕与手动文稿。
3. `videoNoteSummarizer`：本地章节、关键词、速览生成。
4. `videoNoteStore`：本地札记持久化。
5. `VideoNotesPanel`：奏折面板内的札记 UI。

现有模块应尽量保持职责清晰。`AssistantOverlay` 负责串联当前 `webview` 和面板状态，不承载复杂整理算法。
