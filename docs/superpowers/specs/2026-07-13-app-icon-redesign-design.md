# bilimi 应用图标重设计

## 目标

把当前高细节的小咪插画裁切图标，替换为适合 Windows 桌面、开始菜单、任务栏和窗口标题栏的小咪扁平吉祥物头像。

## 视觉方案

- 使用正面简化头像，构图裁到肩部上方，脸部约占画面 55%。
- 双眼睁开并温柔微笑，保留珊瑚红眼睛，但减少复杂高光。
- 保留蓝白短发、双环发髻、顶部呆毛和右侧白色播放发饰。
- 使用大色块和清晰轮廓，只保留一层阴影，不画细碎发丝。
- 使用深海军蓝圆角方形背景，为浅色头发提供稳定对比。
- 删除手势、花朵、珠链、流苏和复杂衣纹，不加入文字或 Bilibili 官方标志。

## 参考图职责

- `ee0cb3ac-ff05-4591-a012-46d4ba5ee6f1.png`：整体角色设定、蓝白配色、服装气质和双环发髻。
- `ig_0b8ae096f8ef09a4016a4db7d73998819593dbec41e2f44000.png`：主要头像参考，锁定脸型、红眼、短发、呆毛和播放发饰。

两张图片仅作为角色参考。最终图标重新生成，不直接裁切参考图。

## 工程接入

- 最终生成源使用方形构图，保存到 `electron/assets/bilimi-icon-source.png`。
- 图标生成脚本从完整方形源生成 `electron/assets/bilimi-avatar.png`、`electron/assets/bilimi.ico`、`build/icon.png` 和 `build/icon.ico`。
- Windows `.ico` 保留 16、24、32、48、64、128 和 256 像素尺寸。
- 重点检查 16、24、32 和 48 像素下的轮廓、眼睛和播放发饰是否仍清楚。

## 验收标准

- 512px 下角色与参考设定一致，整体为扁平吉祥物风。
- 32px 下能辨认小咪的浅色头发、红眼、呆毛和右侧播放发饰。
- 16px 下不依赖花纹或细碎装饰来建立识别度。
- 浅色和深色 Windows 界面中，深蓝背景都能提供稳定边界。
- 项目图标生成测试、完整测试和构建通过。
