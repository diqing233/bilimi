# 收藏库后续体验设计

## 目标

收藏库是掌库之外的独立三栏窗口。它与主窗口共用同一 bilimi 应用实例、登录会话、主进程收藏仓库和转写队列；窗口只渲染主进程快照并发送窄命令，绝不恢复 renderer 权威状态。

## 窗口与入口

- 点击掌库中的“收藏库”仅打开或聚焦同一个窗口；窗口关闭不影响主窗口和后台任务。
- 收藏库默认贴当前主窗口左侧、占用可用工作区全高；窗口可调整尺寸，不遮挡主窗口的正常交互。
- 窗口删除 Electron 菜单栏，使用应用图标和与主窗口一致的蓝白视觉。
- 收藏库入口使用独立的“库”图标，不复用“备册”图标。

## 三栏与批量操作

- 左栏为全部收藏、待处理和来源收藏夹。待处理是本地工作筛选，聚合未同步、同步失败、结果待确认、待续和转写未完成，不等同于 B 站 `bilimi·暂存`。
- 中栏只显示当前分页结果，支持“全选当前页”与逐条多选。未选中任何项目时，批量操作禁用并有中文提示。
- 批量按钮是“同步所选（N）”和“加入转写队列（N）”。全部已同步时前者显示“重新同步所选（N）”。
- 同步在本设计中固定为 B 站元数据到本地镜像；不创建、删除或移动 B 站收藏关系。

## 详情、来源与状态

右栏是单条视频的扫描事实面板，显示标题、UP 主、封面（存在时）、BV/aid、时长、简介、标签、分区、收藏时间、扫描时间与扫描来源。一个视频可有多个来源收藏夹。

- “打开视频”在主窗口新标签打开视频。
- “打开来源收藏夹”由用户在多个来源中明确选择后在主窗口打开。
- 镜像状态由主进程维护：未同步、同步中、已同步、发现更新、同步失败。失败保留最后成功数据和中文重试说明。
- 转写使用现有主进程队列。未同步时先获得转写所需元数据；已经完整同步时直接入队；任务保存提交时的镜像快照，不被后续更新静默改写。

## 账户、错误与档案关联

- 顶部显示“当前账号：昵称（UID：数字）”；昵称不可用时才显示 UID。
- 任何 IPC、网络或内部异常必须映射成中文可行动提示；原始错误仅进诊断日志。
- 档案关联以账号 UID 加稳定视频标识关联。收藏库详情只提供档案摘要卡：是否已入档、转写、版本数、收藏、备注摘要、最近更新时间与总结状态。
- 收藏或备注在收藏库与档案库中使用同一份主进程数据并实时广播；完整档案编辑仍在档案库。

## 安全与验收

- 主进程验证窗口来源和当前 B 站账号；renderer 不得传入视频 URL、远程目标或任意同步计划。
- 账户切换隔离快照和任务，窗口不得短暂展示另一账户数据。
- 覆盖单窗口复用、左贴布局和无菜单栏、中文错误、全选与状态化按钮、来源跳转、镜像和档案摘要桥接的自动测试。
- 本次不打包 Windows 安装包；若后续打包，必须执行 `docs/release-checklist.md` 的 dev、preview、安装包验收。
