# 收藏夹绑定、删除与说明悬浮交互设计

## 目标

在不破坏现有收藏库、档案库、备册和整理收藏流程的前提下，统一 bilimi 收藏夹的绑定状态、改名处理、删除确认，以及“收藏夹/整理收藏”说明的悬浮交互。

## 已有能力与本轮边界

- 现有本地收藏夹配置、B 站远端收藏夹 ID、`已备册/未备册/未绑定` 状态和重新绑定候选流程继续复用。
- 现有收藏库、档案库、转写、设置和工作区迁移数据继续复用；本轮只调整迁移后绑定恢复策略。
- 不新增“小咪备注”字段或编辑入口。
- 不把 B 站技术 ID 暴露给用户。

## 绑定与改名规则

1. 绑定身份永远是 B 站收藏夹 ID，名称只用于展示和发现新草稿。
2. 已绑定收藏夹在任一侧改名都不会解除绑定，也不会产生重复草稿。
3. bilimi 本地改名并保存后，先更新本地分类规则，标记为“名称待备册更新”；点击备册时才把名称写回 B 站。
4. B 站直接改名后保留原绑定和本地规则，显示“册名不同步”；再次备册以 bilimi 本地名称为准。
5. 已绑定收藏夹即使被 B 站改成不含 `bilimi` 前缀的名称，也仍按 ID 维持绑定；没有本地绑定记录的新电脑扫描不能安全认领这种普通名称收藏夹。
6. B 站同名收藏夹按 ID 独立保存；界面只有在确实重名时显示“同名收藏夹①/②”和视频数，不增加备注功能，也不按名称自动合并或绑定。

## 迁移规则

- 迁移继续携带收藏库、档案库、转写、设置、工作区、分类关系和 bilimi 逻辑收藏夹配置。
- 导入后重新读取当前 B 站账号的收藏夹清单；若原绑定目标仍存在且能与导出记录安全核对，则恢复绑定和“已备册”状态。
- 无法核对的项目进入“未绑定/待重新绑定”，不得自动按同名绑定。
- DeepSeek 密钥、登录会话、转写模型文件等机器相关内容不迁移。

### 迁移数据的证据边界

- 导出文件中的 `remoteFolderId` 只作为同一 B 站账号的**待核验身份**；导入后必须用当前 B 站清单按 ID 核验，不能仅按名称、视频数量或 `bilimi` 前缀升格为正式绑定。
- 物理分片的远端成员快照、远端成员数量与远端观察记录属于旧设备的时效性证据。导入时不得把它们当成新设备的远端事实参与容量计算、同步计划或删除确认；须等待新设备重新扫描获得观察结果。
- 合并两个迁移归档时，同一个“逻辑收藏夹 + 分片序号”若指向不同远端 ID，必须报出“需要重新绑定”的冲突；不得使用时间戳或字典序静默选择其中一方。

## 删除规则

单个删除、批量删除、收藏库工作夹删除共用一个二级确认弹窗。弹窗必须先选择删除范围，再勾选知情确认：

- **仅从 bilimi 删除**：删除本地收藏夹配置和本地分类关系，保留 B 站收藏夹。
- **同时从 B 站删除**：删除本地配置、分类关系和对应 B 站 bilimi 收藏夹；该 bilimi 收藏夹内由整理收藏加入的视频会随之移除。

两种方式都不会删除视频本体、档案库、转写、札记或普通 B 站收藏夹。检测到仅通过名称识别的未绑定远端收藏夹时，二级弹窗额外要求用户确认：

> 已检测到未绑定的 bilimi 收藏夹。它们仅通过名称识别，未建立本地绑定。请确认这些不是你在 B 站手动创建的同名普通收藏夹再勾选。

### 多分片删除的原子性与恢复

- 一个逻辑收藏夹可能对应多个 B 站物理分片。选择“同时从 B 站删除”时，只有该逻辑收藏夹所有分片都已确认删除或已被实时核验为不存在，才允许删除本地逻辑收藏夹和绑定记录。
- 任一分片删除失败、账户校验失败或状态未知时，保留全部本地逻辑收藏夹、分片绑定和待协调证据；用户可稍后从同一入口重试或重新核验。
- 只要一个逻辑收藏夹包含 `pending-reconcile` 分片，远端删除入口必须拒绝执行，直到该分片完成核验或用户先仅从 bilimi 删除本地配置。这样不会因为删除一个已绑定分片而抹掉另一个“创建结果未知”的远端证据。
- 收藏夹区与收藏库使用相同的范围与原子性语义；两个入口的备册操作必须共享进行中锁，避免快速重复点击造成重复远端写入。

## 收藏夹与整理收藏说明交互

两处均使用同一套说明悬浮层行为：

- 默认只显示标题/状态和箭头，正常鼠标悬停仍显示完整说明。
- 点击标题或箭头后，说明悬浮层固定显示，鼠标移开也不隐藏。
- 固定显示时箭头旋转并朝左；再次点击同一入口后收起，恢复普通悬浮提示。
- 固定显示时不重复弹出第二个悬浮层；同一时间只固定一个说明层，点击另一处时切换固定目标。
- 悬浮层使用固定定位和边界检测，不改变页面布局，不遮挡下方的操作按钮。

收藏夹卡片列表的折叠仍由底部现有按钮独立控制：默认完整展开，按钮显示“折叠”；点击后收起为三排，按钮显示“展开”；再次点击恢复完整列表。说明箭头不控制卡片列表。

## 状态灯与文案

- 全局状态灯不显示“不再提醒”；单个远端草稿卡片保留“不再提醒”，且只作用于该收藏夹。
- 状态标签统一为“已备册、未备册、未绑定”；必要时增加“名称待备册更新/册名不同步”说明，不把名称差异误报为未绑定。
- 状态说明采用“收藏夹 / 待设置 / 整理收藏 / 小咪提醒”分段，重要标签深蓝加粗，“小咪提醒”放最后。

## 验证要求

- 为同名远端扫描、改名状态、迁移绑定恢复、两种删除范围、未绑定知情确认和两个说明悬浮层交互补充回归测试。
- 运行相关 Vitest 测试、`npm test`、构建、`git diff --check`，并检查工作树只包含本轮文件。
- 开发版实际验证悬浮层定位、侧栏收缩、点击/悬停切换、列表三排折叠和删除弹窗操作。
