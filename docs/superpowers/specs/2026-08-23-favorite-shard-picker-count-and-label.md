# 收藏库物理分册选择器文案与统计设计

## 目标

在收藏库逻辑工作夹的多物理分册视图中，让折叠状态保持短小，同时在展开菜单中保留完整远端名称；括号数字显示当前本地实际归属到该物理分册的视频数。

## 设计

- `FavoriteRepositoryService.getLibrarySummary()` 从当前账号权威快照的物理分册 memberships 派生 `localMemberCount`，只统计存在本地视频行且未进入回收站的成员。既有 `remoteMemberCount` 仍表示远端观察/对账口径，不再作为本地下拉的回退值。
- 物理分册选择器使用独立的可访问触发器与 `role=listbox` 菜单：触发器显示 `全部` 或 `分册 N（本地数）`；菜单项显示 `分册 N · 完整远端名称（本地数）`。本地数字缺失显示 `—`，不显示伪造的 `0`。
- 菜单保留 `全部`、分册筛选、键盘方向键/Enter/Escape、外部点击关闭和当前选择焦点；选择分册只调用现有本地页面查询，不触发 B 站读取或写入。

## 不改范围

不改变备册、绑定、删除、同步、DeepSeek、转写、远端成员观察、颜色和其它卡片布局。

## 验收

- Vitest 覆盖摘要本地分册计数与远端 `remoteMemberCount` 解耦。
- Vitest 覆盖折叠按钮短文案、展开菜单完整文案、选择后页面按分册查询以及键盘关闭。
- Electron 仅做只读界面检查并截图，不点击任何 B 站写入按钮。
