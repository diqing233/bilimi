# DeepSeek 保存测试与状态灯设计

## 目标

合并 DeepSeek 的保存和测试操作，并让顶部状态灯只在真实请求成功后显示已连接。

## 交互

- 设置区保留“保存并测试”和“重置 DeepSeek”两个按钮。
- “保存并测试”先保存密钥与偏好，再使用已保存配置发起真实请求。
- 保存失败时停止测试并保留未保存的密钥草稿。
- 保存成功但测试失败时保留配置，显示可重试的具体错误。
- 重置前确认；用户取消时不改变任何设置。

## 状态

- 未启用：灰色“DeepSeek 未启用”。
- 已启用但无密钥：黄色“DeepSeek 待配置”。
- 已保存但本次运行未验证：黄色“DeepSeek 待测试”。
- 保存测试中：蓝色“测试中”。
- 真实请求成功：绿色“DeepSeek 已连接”。
- 测试失败：红色“DeepSeek 连接失败”。

连接结论只保留在当前运行中。修改密钥、模型、服务地址或总开关后回到待测试；普通功能开关不使连接结论失效。其他 DeepSeek 真实请求成功也可更新为已连接。

## 错误处理与验证

- 全局提示区通过现有 `aria-live` 播报成功和失败结果。
- 测试期间禁用保存测试和重置按钮，避免并发配置操作。
- 组件测试覆盖待测试、成功、失败、保存失败和取消重置。
