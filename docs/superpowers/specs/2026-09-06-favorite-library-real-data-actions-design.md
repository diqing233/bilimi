# 收藏库实际数据操作设计

## 目标

让收藏库操作以当前仓库快照和 B 站实际回读证据为准，解除整理/备册状态对移动和删除的额外限制，并保持现有保存、远端写入与刷新链路。

## 方案

### 本地位置

删除 `workspace.status` 对移动入口和主进程批量移动命令的限制。移动仍校验版本、来源和目标逻辑收藏夹，并在同一 repository command 中写入最终 `localDesiredFolderIds`。整理保存使用已有 `commit-local-plan` 事务继续写入最终位置；删除不修改整理队列或分类草稿，因此用户可以先移动/删除，再决定是否保存本轮。

### 视频删除

保留现有本地删除的审计、生命周期和回收站投影，但解除 UI/IPC 对整理状态、备册状态的限制。删除目标从当前 snapshot 的实际本地位置和成员索引解析；没有目标时返回可解释的跳过/无操作结果，不创建绑定或对账记录。

### 视频远端删除

保留 managed-placement removal 的实际观察证据校验。详情和批量入口只在存在远端观察/同步回读证据时进入确认；没有证据只展示“没有实际存入B站bilimi收藏夹”，不调用 remote writer。成功后按既有 repository projection 刷新，不碰普通 B 站来源。

### 工作夹删除

沿用现有 `FavoriteRepositoryManagedFolderService` 的本地预览和远端删除 API，但将本地删除视为始终可执行；远端选项只使用预览中实际存在的远端绑定/回读候选。选择“仅从收藏库删除”提交本地工作夹删除；选择“同时从 B 站删除”调用现有远端确认/执行流程，成功后提交本地投影。未备册或远端不存在时不发送远端删除，但仍允许本地删除。

### 视觉状态

为批量更多菜单和详情同步按钮补充已有按钮系统的 `:hover` 与 `:focus-visible` 颜色，保持尺寸和布局不变。

## 风险与保护

- 不改变普通 B 站收藏夹删除路径。
- 不修改整理草稿、档案、转写、保护记录、规则/草稿配置。
- 不以绑定状态替代远端实际存在证据。
- 所有 mutation 继续使用 revision 校验；完成后使用现有刷新/变更订阅更新列表。

## 验证

- 先为移动、删除、远端证据和工作夹删除添加失败回归测试并确认失败。
- 聚焦运行收藏库界面、批量服务、工作夹服务、仓库 reducer 测试。
- 运行 `npm run build` 和全量 `npm test`。
- 在独立 Electron 开发版手工确认移动、删除、按钮 hover 与工作夹删除；真实 B 站写入/删除只在用户账号环境验收。
