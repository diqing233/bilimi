# 分类准度与归档预览交互改造设计

## 背景

当前整理旧藏时，八大默认收藏夹的关键词分类主要依赖词面包含和字段权重。这个方式容易出现两类问题：

- 多义词误分：`攻略` 可能是游戏攻略、旅行攻略、装修攻略；`剧情` 可能是游戏剧情、影视剧情或短剧剧情。
- 相近词漏分：`科普小常识`、`科普常识`、`知识科普` 语义接近，但当前需要逐个写入关键词才容易命中。

归档预览界面也需要升级。用户希望预览阶段可以直接调整目标收藏夹、看到来源收藏夹、UP 主、标签等分类线索，并通过按钮蓝色状态表达是否进入整理计划。所有调整都只改变本次预览计划，最终仍由“确认执行”统一移动到 B 站收藏夹。

## 目标

- 默认采用积极整理策略，提高命中率。
- 通过实体别名、概念变体、强弱词分级、多义词组合规则、反向约束、置信度和分差减少明显错分。
- 支持用户纠错学习，并提供设置页管理。
- 重构归档预览交互，让每条视频可以在预览中切换目标 bilimi 收藏夹、撤回改动、保留原建议。
- 未匹配区域默认不整理；用户明确选择 `bilimi·暂存` 或其他 bilimi 收藏夹后才进入执行计划。
- 卡片必须显示来源收藏夹、UP 主、标签等分类线索；信息过长时截断并支持悬停查看完整详情。
- 在归档预览中加入 DeepSeek 整理模块，让 DeepSeek 对当前预览数据做全体整理、仅二判或仅整理未分类，并由 bilimi 校验后应用到预览计划。

## 非目标

- 本地基础分类器不依赖 AI 或远程语义模型；DeepSeek 是可选的归档预览二审与整理模块。
- 第一版不从普通 B 站原生收藏行为推断用户偏好。
- 第一版不自动生成 UP 主级强规则，除非用户已有 UP 主规则收藏夹。
- 预览阶段不真实移动视频；所有移动仍由“确认执行”统一执行。

## 分类引擎

### 总体流程

分类流程调整为：

1. 文本归一化。
2. 实体别名识别。
3. 概念变体识别。
4. 用户关键词轻量扩展。
5. 强弱词打分。
6. 多义词组合规则加分。
7. 反向约束降分。
8. 输出置信度、分差、命中诊断和低置信标记。

### 文本归一化

统一以下文本差异：

- 大小写。
- 全角和半角。
- 中文冒号和英文冒号。
- 空格、书名号、常见分隔符。

示例：`崩坏：星穹铁道`、`崩坏星穹铁道`、`崩坏 星穹铁道` 应能归一识别。

### 实体别名库

实体别名库处理同一对象的不同写法或简称。第一版内置高频明确实体，重点覆盖游戏作品：

- 原神：`原神`、`Genshin`。
- 崩坏：星穹铁道：`崩坏：星穹铁道`、`崩坏星穹铁道`、`星穹铁道`、`星铁`、`崩铁`、`HSR`。
- 崩坏3：`崩坏3`、`崩坏三`、`崩三`、`崩坏学园3`。
- 绝区零：`绝区零`、`ZZZ`。
- 明日方舟：`明日方舟`、`方舟`、`舟游`。
- 鸣潮：`鸣潮`。
- 王者荣耀：`王者荣耀`、`王者`。
- 英雄联盟：`英雄联盟`、`LOL`、`联盟`。
- 无畏契约：`无畏契约`、`瓦`、`瓦罗兰特`、`Valorant`。
- 我的世界：`我的世界`、`Minecraft`、`MC`。

实体命中是强信号。比如 `星铁 + 剧情解析` 应归为游戏，而不是因为 `剧情` 进入影视。

### 概念变体库

概念变体库处理同类表达，不等同于实体别名。第一版覆盖以下方向：

- 知识概念：`科普`、`常识`、`冷知识`、`小知识`、`知识点`、`原理`、`讲解`、`教程`、`课程`、`公开课`、`学习`。
- 生活概念：`生活攻略`、`旅行攻略`、`出行路线`、`装修避坑`、`收纳技巧`、`做饭教程`、`健身计划`、`护肤步骤`、`家居改造`。
- 影视概念：`影视剧情`、`番剧剧情`、`电影剧情`、`剧情解析`、`电影解说`、`电视剧解说`、`名场面`、`角色分析`、`演员访谈`、`预告片`。
- 游戏概念：`游戏攻略`、`游戏剧情`、`配队`、`抽卡`、`深渊`、`通关`、`Boss`、`主线`、`支线`、`实况`、`赛事`。
- 创作概念：`摄影教程`、`调色`、`构图`、`绘画教程`、`建模`、`手作`、`设计`、`穿搭`。
- 音乐概念：`翻唱`、`演奏`、`MV`、`现场`、`舞台`、`编曲`、`作曲`。
- 娱乐概念：`整活`、`吐槽`、`reaction`、`综艺`、`脱口秀`、`搞笑`、`鬼畜`。

示例：`科普小常识` 应通过标签短语拆解、核心词组合和概念簇命中知识学习。

### 用户关键词轻量扩展

对明确概念簇做有限扩展。例如用户在知识学习里填写 `科普常识`，系统可轻量匹配：

- `科普常识`
- `科普小常识`
- `常识科普`
- `冷知识`
- `小知识`

扩展只针对明确概念簇，不对所有普通词无限扩展，避免误伤。

### 强弱词分级

强词：

- 具体实体。
- 明确 B 站标签。
- 明确分类组合词，例如 `游戏攻略`、`旅行攻略`、`电影剧情`、`软件教程`。

弱词：

- `攻略`
- `剧情`
- `教程`
- `教学`
- `入门`
- `实战`
- `测评`
- `剪辑`
- `解说`
- `名场面`

弱词可以加分，但不能单独决定分类。

### 多义词组合规则

第一版至少覆盖：

- `游戏实体 + 攻略/剧情/主线/支线` -> 游戏。
- `游戏/电竞/Steam/手游/单机 + 攻略/剧情/解说/实况` -> 游戏。
- `电影/番剧/电视剧/第X集/演员/台词 + 剧情/名场面/解析` -> 影视动漫。
- `旅行/城市/签证/酒店/路线/装修/收纳/护肤/健身 + 攻略/教程/避坑` -> 生活日常。
- `软件/编程/课程/公开课/原理/科普 + 教程/讲解/入门` -> 知识学习。
- `摄影/绘画/建模/设计/调色 + 教程/入门` -> 创意美学。

### 反向约束

反向约束用于降低冲突分类的分数：

- 命中生活语境时，压低游戏对裸 `攻略` 的解释。
- 命中影视语境时，压低游戏对裸 `剧情` 的解释。
- 命中游戏实体时，压低影视对裸 `剧情` 的解释。
- 命中消费、护肤、汽车、美食等语境时，`测评` 不默认归知识。

### 置信度和诊断

分类结果需要输出：

- 目标收藏夹。
- 命中关键词。
- 分数。
- 第一名和第二名分差。
- 置信度等级。
- 是否低置信。
- 诊断信息，供设置页纠错详情展示。

归档预览中只显示低置信提示，高置信不额外占空间。

### 默认关键词调整

默认关键词仍可在编辑页展示，但分类引擎按强弱词规则解释。

需要调整的默认词：

- 游戏专区：将裸 `攻略`、`剧情` 改为 `游戏攻略`、`游戏剧情`。
- 影视动漫：将裸 `剧情` 改为 `影视剧情`、`番剧剧情`、`电影剧情`。
- 生活日常：补充 `生活攻略`、`旅行攻略`、`装修攻略`、`收纳技巧`、`做饭教程`、`护肤教程`、`健身计划`。
- 知识学习：补充 `知识科普`、`科普常识`、`冷知识`、`小知识`、`原理讲解`、`软件教程`、`编程教程`、`公开课`、`课程学习`。
- `教程`、`教学`、`入门`、`实战`、`测评` 保留展示，但分类时按弱词处理。

## 整理策略设置

新增设置区：`整理策略`。

三档策略：

- 积极整理：默认。只要分类器给出非未分类目标，就默认点亮进入整理计划；低置信显示提示。
- 均衡整理：强实体、明确 B 站标签、明显分类词命中时默认点亮；只有弱词或分差太小时不点亮。
- 保守整理：只有高置信才默认点亮；低置信和冲突结果不默认点亮。

现有多收藏夹归档上限继续生效，不合并到本设置。目标选择跟随现有多归档设置：

- 默认单目标。
- 当用户配置允许多归档时，可多目标点亮。

## 纠错学习

### 覆盖范围

纠错学习覆盖：

- 归档预览里改目标收藏夹。
- 未匹配区域手动选择 bilimi 收藏夹。
- 平时整理功能中，用户最终把视频存入 bilimi 收藏夹。
- 若入口没有原建议，则现场用新版分类器跑一次作为原建议；拿不到视频信息时不记录。

不覆盖普通 B 站原生随手收藏行为，避免误判用户意图。

### 记录时机

- 预览阶段只记录草稿。
- 用户点击 `确认执行` 后转为有效。
- 撤回、取消、未执行不污染学习。
- 平时整理场景在用户最终完成存入 bilimi 收藏夹后记录。

### 学习类型

- 强纠错：用户明确从原建议 A 改到 bilimi 收藏夹 B。
- 弱负反馈：用户把蓝色取消为白色“本次不整理”。第一版记录但不直接影响分类。
- aid 级记忆强生效：同一视频下次优先使用用户选择。
- 相似标题/标签第一版只作为弱信号，不直接生成强规则。
- UP 主级规则不自动生成，除非用户专门建了 UP 主规则收藏夹。

### 设置页管理

纠错学习设置包含两个开关，默认都开启：

- 记录纠错学习。
- 纠错学习参与分类。

设置页提供纠错学习列表：

- 支持展开和折叠。
- 摘要显示：视频标题、原建议、用户选择、时间。
- 展开显示：UP 主、标签、来源场景、来源收藏夹、命中关键词、分数、置信度、分差。
- 支持删除单条。
- 支持清空全部。

## 归档预览交互

### 基本原则

- 预览阶段不真实移动视频。
- 所有切换只修改本次整理计划。
- `确认执行` 统一移动到 B 站收藏夹。
- 蓝色按钮带勾选效果，代表已选择存入某个真实 bilimi 收藏夹，并进入确认执行计划。
- 白色按钮代表本次不整理，不进入执行计划。
- `未分类` 不是收藏夹，是预览状态；永远不点亮。
- `bilimi·暂存` 是真实 bilimi 收藏夹，出现在 bilimi 收藏夹下拉菜单中。

### 卡片信息

所有归档预览视频卡片都应显示分类判断所需线索：

- 标题。
- 来源收藏夹，例如 `来源：默认收藏夹`。这是信息字段，不可点击。
- UP 主。
- 识别到的标签。
- 原建议，若用户已改目标。
- 低置信提示，若结果低置信。

信息显示不全时允许截断，但必须通过悬停查看完整详情。标签优先展示前几个，例如 `标签：原神、攻略、剧情 +3`，完整标签进入悬停详情。

`视频来源` 是按钮，点击打开原视频。它替代原来的 `手动分类` 文案，但行为仍是打开视频页面。

### 未匹配区域

未匹配区域包括：

- 算法没有匹配到合适分类的视频。
- 用户主动选择 `未分类` 的视频。

行为：

- 区域视觉更突出。
- 默认所有视频是未分类状态，白色，不进入执行计划。
- 用户没有选择 `bilimi·暂存` 或其他 bilimi 收藏夹时，本次不整理。
- 默认显示核心操作：`视频来源`、`存入 bilimi 收藏夹`、`再次整理`、撤回控件。
- `全部存入暂存` 将当前未匹配区域视频批量选择到真实收藏夹 `bilimi·暂存`。
- `未分类` 不能点亮，也不能作为执行目标。

### 其他收藏夹分组

其他归档预览分组改为可编辑计划视图：

- 保留一键选择/取消当前收藏夹全部视频。
- 一键选择：该分组内视频设为存入当前 bilimi 收藏夹，按钮变蓝。
- 一键取消：只变成本次不整理，按钮变白，但仍留在当前分组，不自动移动到未匹配区域。
- 单条下拉选择 `未分类` 时，移动到未匹配区域，并显示原建议，可撤回。
- 用户改到其他收藏夹后，视频立刻移动到新收藏夹分组；同时保留原建议。
- 默认只显示摘要；点击视频后展开操作区。
- 其他收藏夹区域一次只展开一个视频，点另一个会自动收起前一个。

### 收藏夹按钮和下拉

- 卡片按钮显示收藏夹短名，例如 `游戏专区`。
- 悬停显示完整名，例如 `bilimi·游戏专区`。
- 下拉菜单显示完整 bilimi 收藏夹名称。
- 下拉显示所有启用的 bilimi 收藏夹；没有 B 站 folderId 的也可选，确认执行前走现有备册或同步流程。
- 下拉同时包含 `未分类`，但 `未分类` 不属于收藏夹。

### 多目标模式

目标选择跟随现有多归档设置：

- 单目标模式：选择新收藏夹时替换旧目标。
- 多目标模式：每条视频可点亮多个 bilimi 收藏夹，确认执行时存入多个收藏夹。

多目标视频选择 `未分类` 时弹出自定义轻量确认层，列出当前准备存入的 bilimi 收藏夹，并提供：

- 全部去掉不整理：清空所有目标，移入未匹配区域。
- 只取消当前收藏夹：只取消当前分组目标，若还有其他目标则仍留在对应分组。
- 取消：不变更。

### 撤回

每个视频支持撤回，每个区域或收藏夹分组支持批量撤回。

撤回控件带下拉模式：

- 默认：撤回单条。
- 可切换：撤回当前区域所有改动。

切换下拉选项不执行；点击撤回按钮才执行。

撤回恢复到本次预览刚生成时的原始建议状态。用户改目标、取消点亮、移动到未分类、批量存入暂存都属于本次改动，可撤回。

### 再次整理

将 `再次判断` 改为 `再次整理`。

行为：

- 只作用于单条视频。
- 优先刷新详情、标签和目标收藏夹归属，再跑新版分类器。
- 若没有刷新回调，则使用当前已有信息本地重跑。
- 重新整理后更新该视频当前目标和所在分组。

## DeepSeek 整理模块

### 模块定位

DeepSeek 是归档预览里的独立 AI 整理模块。它在本地规则完成第一轮归类后运行，用当前预览中已经掌握的信息做语义判断：

- DeepSeek 不复用本地分类器打分。
- DeepSeek 不套用本地强弱词、多义词、反向约束和整理策略。
- DeepSeek 不重新扫描 B 站收藏夹，也不重新补拉视频列表。
- DeepSeek 不直接移动 B 站收藏。
- bilimi 负责校验 DeepSeek 输出、更新预览计划、显示位移提示、高亮改动、支持撤回和最终执行。

DeepSeek 未开启、未配置 API Key 或连接不可用时，入口置灰并提示 `未开启 DeepSeek` 或引导去设置。DeepSeek 与现有 DeepSeek 能力使用同一套启用状态、API Key、模型和连接设置。

### 入口和模式

归档预览顶部右侧加入 `DeepSeek 整理` 按钮。按钮带下拉菜单，默认模式为 `全体整理`。

模式：

- 全体整理：默认。对已分类视频做二判，同时整理未分类视频。
- 仅二判：只审查已进入分组、已点亮或已有本地建议目标的视频。
- 仅整理未分类：只处理当前未匹配区域的视频。

点击按钮后才发起 DeepSeek 请求；切换下拉模式不自动运行。

### DeepSeek 输入

DeepSeek 接收事实上下文、可选目标集合和本地第一轮建议作为参考，而不是接收本地规则结论作为约束。

每条视频输入：

- aid。
- 标题。
- UP 主。
- 标签。
- 简介。
- 分区。
- 来源收藏夹。
- 当前所在预览区域。
- 本地第一轮建议目标。
- 本地低置信原因和命中诊断摘要。

收藏夹输入：

- 所有启用的 bilimi 收藏夹。
- 收藏夹完整名称和短名。
- 收藏夹关键词。
- 收藏夹规则类型。
- 收藏夹说明或可用摘要。
- 多归档上限。

任务输入：

- 当前 DeepSeek 模式：全体整理、仅二判或仅整理未分类。
- 输出目标只能是已有启用 bilimi 收藏夹或 `未分类`。
- 不允许 DeepSeek 创建收藏夹。
- 不允许 DeepSeek 直接修改关键词。

整理策略不作为 DeepSeek 判断依据。整理策略属于 bilimi 应用建议时的产品规则，DeepSeek 只回答“根据语义最适合哪里”。

### DeepSeek 输出

DeepSeek 需要返回结构化结果：

- 每条视频的建议目标。
- 是否建议保持原位。
- 判断理由。
- 置信度。
- 是否低置信。
- 是否属于二判调整。
- 关键词优化建议。

关键词优化建议可包含：

- 新增关键词。
- 删除关键词。
- 将关键词降级为弱词。
- 将泛词改成组合词，例如 `攻略` -> `游戏攻略`、`旅行攻略`。
- 新增实体别名。
- 新增概念变体。

DeepSeek 只能提出关键词建议，不能自动改关键词。用户在设置或归档预览的建议列表中逐条采纳、忽略或删除。

### bilimi 应用 DeepSeek 建议

bilimi 收到 DeepSeek 结果后执行校验：

- 目标收藏夹必须存在且启用。
- 目标不能超过多归档上限；超过时按 DeepSeek 置信度截断并提示。
- 返回不存在目标、格式错误或置信度不足时，不应用该条建议。
- `未分类` 不是执行目标，只让视频保持或移动到未匹配区域。

校验通过后，bilimi 使用新的预览移动能力更新计划：

- 视频移动到 DeepSeek 建议的收藏夹分组。
- 对应收藏夹按钮变蓝并带勾选效果。
- 保留原建议。
- DeepSeek 调整过的视频高亮显示。
- 位移提示用红字显示。

红字示例：

- `DeepSeek 整理：未分类 -> bilimi·生活日常`
- `DeepSeek 二判：bilimi·游戏专区 -> bilimi·影视动漫`
- `DeepSeek 保持：bilimi·音乐舞台`

如果 DeepSeek 建议低置信，bilimi 可高亮提示，但不应静默强塞。低置信是否默认点亮由应用建议时的产品规则决定；用户仍可手动改目标。

### 撤回和执行

DeepSeek 整理属于本次预览改动：

- 支持单条撤回。
- 支持当前区域全部撤回。
- 支持撤回 DeepSeek 本轮批量整理。
- 撤回后恢复到 DeepSeek 运行前的预览状态。

DeepSeek 不执行真实移动。只有用户点击 `确认执行` 后，bilimi 才按当前蓝色点亮的执行计划整理 B 站收藏夹。

### DeepSeek 与纠错学习

DeepSeek 建议本身不等同于用户纠错。

纠错学习来源需要区分：

- `user`：用户手动改动，最高可信。
- `deepseek`：DeepSeek 建议，低可信，默认只作为候选诊断。
- `user-confirmed-deepseek`：DeepSeek 建议被用户确认执行，可信度提升。

默认规则：

- DeepSeek 原始建议不直接生成强纠错。
- 用户采纳并确认执行后，可作为 `user-confirmed-deepseek` 参与纠错学习。
- 用户在 DeepSeek 建议基础上再次手动修改并确认执行，以用户最终选择为准。

DeepSeek 设置组里增加 `启用 DeepSeek 辅助判断归类收藏夹` 复选框，默认关闭。只有在 DeepSeek 总开关开启且 API Key 已配置时，该能力才可启用。

这个设置服务于赏、藏、赐等日常归类收藏入口，不更新整理旧藏的归档预览。归档预览里的 `DeepSeek 整理` 按钮仍是整理旧藏的独立批量动作，两者不要混在同一个状态流里。

勾选后展开两个互斥选项，使用单选控件：

- 全部归类都辅助判断：开启辅助判断后默认勾选。先按照本地规则完成分类，再让 DeepSeek 对全部归类做二判。
- 仅低置信时辅助判断：只对本地低置信、分差过小、冲突或多义词明显的结果做 DeepSeek 二判。

不再提供“只提示/自动应用”的二级选项。既然该能力已经和归档预览分开，DeepSeek 辅助判断在日常归类收藏入口中默认直接修正当前建议结果：

- DeepSeek 二判无误时不提示，保持本地结果。
- DeepSeek 二判认为本地结果有误时，bilimi 直接把当前日常归类收藏入口里的建议目标替换为 DeepSeek 目标，并更新转移提示和纠错草稿，不触碰整理旧藏的归档预览。
- 入口需要显示明确提示，例如 `DeepSeek 已修正：bilimi·游戏专区 -> bilimi·生活日常`，并标明 `真实移动会在你确认收藏后执行`。
- 如果该入口有确认或执行步骤，真实 B 站收藏夹移动仍按该入口既有确认或执行机制发生，DeepSeek 不直接越过用户动作移动收藏。
- DeepSeek 二判造成的调整记录为纠错学习草稿；用户完成该入口的最终存入或确认动作后，才转为有效纠错记录。

DeepSeek 关键词建议独立展示，用户可逐条采纳、忽略或删除。日常归类收藏累计的纠错和关键词建议，以及归档预览中 DeepSeek 或本地规则提出但用户当时没有采纳的调整，都应保留在设置页的纠错学习或关键词建议列表中，方便用户以后继续处理。

设置说明文案需要明确该行为：

- `开启后，bilimi 仍会先用本地规则快速判断；DeepSeek 会在后台辅助二判。若 DeepSeek 判断本地分类有误，会直接修正当前入口的建议目标，并显示修正提示。真实收藏移动仍需你完成当前入口的确认动作。`
- `该设置不影响整理旧藏的归档预览；归档预览里的 DeepSeek 整理需要在归档预览页手动触发。`

第一版不提供 DeepSeek 自动增删关键词能力。

### 失败和隐私提示

请求失败、返回格式不合法或部分视频失败时：

- 保留原预览状态。
- 显示失败提示。
- 对部分成功的结果，可以只应用成功项，但必须明确提示失败数量。

DeepSeek 请求会发送标题、UP 主、标签、简介、来源收藏夹、当前建议和 bilimi 收藏夹信息。首次使用或按钮旁应有简短提示，说明这些信息会用于 DeepSeek 整理。

## 数据和状态设计

需要在现有预览数据之上区分：

- 原始建议目标。
- 当前选择目标。
- 当前是否进入执行计划。
- 用户是否修改过。
- 低置信诊断。
- 纠错学习草稿。
- DeepSeek 运行前快照。
- DeepSeek 建议来源、置信度、理由和红字位移提示。
- DeepSeek 关键词建议及其采纳状态。

撤回依赖原始建议快照，不能只依赖当前 target key 集合。

确认执行时，执行计划应只包含当前被蓝色点亮的真实 bilimi 收藏夹目标。`未分类` 和白色未选状态不进入执行计划。

## 测试计划

### 分类测试

- `科普小常识` 命中知识学习。
- `科普常识`、`知识科普`、`冷知识` 均能归入知识学习。
- `东京旅行攻略` 不进入游戏，偏生活日常。
- `装修避坑攻略` 偏生活日常。
- `原神攻略`、`星铁剧情解析`、`崩坏：星穹铁道主线剧情` 进入游戏专区。
- `第十二集剧情反转`、`电影剧情解析`、`番剧名场面` 进入影视动漫。
- `游戏攻略`、`游戏剧情` 替代裸 `攻略/剧情` 后不降低游戏实体命中。
- `测评` 结合数码时偏知识，结合汽车或护肤时不默认归知识。
- 三档整理策略下，低置信结果默认点亮行为不同。

### 归档预览测试

- 未匹配区域默认白色，不进入执行计划。
- 未匹配区域选择 `bilimi·暂存` 后进入执行计划。
- 其他分组一键选择和一键取消行为正确。
- 单条改目标后移动到新分组，并显示原建议。
- 单条选择 `未分类` 后移动到未匹配区域，不进入执行计划。
- 单条撤回恢复原始建议。
- 当前区域全部撤回恢复区域内改动。
- 多目标选择 `未分类` 时弹出确认层，并区分全部清空和只取消当前目标。
- 其他收藏夹区域一次只展开一个视频。
- 卡片显示来源收藏夹、UP 主、标签；信息过长时悬停可看完整详情。

### 纠错学习测试

- 预览中改目标后只产生草稿。
- 确认执行后草稿转为有效记录。
- 撤回或取消不产生有效记录。
- 蓝色取消为白色记录弱负反馈，但第一版不影响分类。
- aid 级纠错下次扫描优先生效。
- 设置页可展开、删除单条、清空全部。
- 关闭“记录纠错学习”后不再产生记录。
- 关闭“纠错学习参与分类”后记录保留但不影响分类。

### DeepSeek 辅助判断测试

- DeepSeek 未开启或未配置 API Key 时，辅助判断设置不可启用并提示未开启。
- `启用 DeepSeek 辅助判断归类收藏夹` 默认关闭。
- 勾选 `启用 DeepSeek 辅助判断归类收藏夹` 后展开 `全部归类都辅助判断` 和 `仅低置信时辅助判断`。
- 开启辅助判断后默认选择 `全部归类都辅助判断`。
- `全部归类都辅助判断` 会在本地分类后对全部归类结果做 DeepSeek 二判。
- `仅低置信时辅助判断` 只对低置信、分差过小、冲突或多义词明显的结果做 DeepSeek 二判。
- DeepSeek 二判无误时不提示且不改变当前日常归类收藏入口的建议目标。
- DeepSeek 辅助判断用于赏、藏、赐等日常归类收藏入口，不更新整理旧藏归档预览。
- DeepSeek 辅助判断认为本地结果有误时，bilimi 直接替换当前日常归类收藏入口的建议目标，显示修正提示，并生成纠错学习草稿。
- 设置说明需要告知用户：DeepSeek 会直接修正当前入口建议目标，但真实移动仍需用户完成当前入口的确认动作，且不影响整理旧藏归档预览。
- 日常归类收藏累计的纠错、关键词建议，以及归档预览中用户暂未采纳的调整建议，会保留在设置页供以后处理。

### DeepSeek 归档预览整理测试

- DeepSeek 未开启或未配置 API Key 时，归档预览按钮置灰并提示未开启。
- `全体整理` 同时处理已分类二判和未分类整理。
- `仅二判` 不处理未匹配区域视频。
- `仅整理未分类` 不处理已有分组视频。
- DeepSeek 不触发重新扫描。
- DeepSeek 返回已有启用收藏夹时，bilimi 将视频移动到对应分组并点亮目标。
- DeepSeek 返回不存在收藏夹时，该条建议被拒绝并提示。
- DeepSeek 调整后显示红字位移提示和高亮。
- DeepSeek 批量改动可单条撤回、区域撤回和整轮撤回。
- DeepSeek 建议不直接生成用户纠错；确认执行后记录为 `user-confirmed-deepseek`。
- DeepSeek 关键词建议可逐条采纳、忽略和删除，且不会自动改关键词。
- DeepSeek 请求失败或返回格式错误时保留原预览状态。
