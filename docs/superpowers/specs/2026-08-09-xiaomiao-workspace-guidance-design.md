# 小咪工作区引导设计

## 目标

让小咪和助手全局提示框在用户进入批阅、札记、掌库、设置，以及打开档案库、收藏库时，准确说明当前入口的能力。全局提示使用中性产品说明；小咪气泡保留角色口吻。

## 范围

- 只补充工作区入口说明与触发时机。
- 不改变点赞、投币、收藏、弹幕、转写、归档、同步或 DeepSeek 的业务流程、权限和设置。
- 实际动作继续使用原有的进度、成功和失败反馈。

## 文案

| 入口 | 全局提示框 | 小咪提示 |
| --- | --- | --- |
| 批阅 | 批阅：可以一键三连、自动分类收藏（需先在掌库完成备册），发送弹幕（建议开启 DeepSeek 生成）。 | 小咪切到批阅啦，可以一键三连、自动分类收藏，还能发送弹幕哦～ |
| 札记 | 札记：通过转写音频输出视频文稿；建议在设置页下载并启用识别率更高的转写模型。启用 DeepSeek 后可总结笔记。 | 小咪切到札记啦，点击转写音频就能输出视频文稿，还可以用 DeepSeek 总结笔记哦～ |
| 档案库 | 档案库：可以查看已转写成功的视频文稿，支持搜索、备注和批量导出。 | 主人，档案库已经打开啦，想看整理好的文稿，随时来找小咪哦～ |
| 掌库 | 掌库：备册后批阅操作可自动分类保存；“整理收藏”可建立本地收藏库，并将整理结果同步到 B 站。 | 小咪切到掌库啦，备册后就可以在 B 站生成 bilimi 收藏夹；以后分类整理视频，安心交给我吧！ |
| 收藏库 | 收藏库：bilimi 本地收藏库，支持批量管理所有已整理的视频。 | 主人，收藏库已经打开啦，快看看小咪整理得怎么样呀！ |
| 设置 | 设置：建议配置 DeepSeek、下载更强的转写模型以提升使用体验；支持宠物设置、数据迁移等功能。 | 小咪切到设置啦，配置 DeepSeek、下载更好的转写模型，都可以大幅提升小咪的能力哦！ |

档案库的功能名称固定为“批量导出”，与现有产品能力一致，不称为“批量下载”。

## 交互与数据流

1. 小咪功能窗口首次打开并默认显示批阅时，助手全局提示框显示批阅说明；小咪只保留既有开场招呼，不追加批阅气泡。
2. 用户主动从一个顶级页签切换到另一个顶级页签时，同时更新全局提示框和小咪气泡。
3. 重复点击当前顶级页签不产生新提示。
4. 札记内打开档案库或宠物快捷入口直达档案库时，档案读取完成后显示档案库专属说明；读取中仍显示既有进度提示。
5. 掌库点击收藏库时，主进程确认窗口打开后显示收藏库专属说明。
6. 状态灯导航、后台任务、恢复视图和内部视图切换不产生入口介绍，避免覆盖实际动作的进度、成功或失败信息。

## 实现边界

工作区入口文案集中在一个无 React 状态的模块中，避免全局提示和小咪提示逐渐分叉。`FloatingAssistantApp` 负责决定当前导航是否为用户可见的入口并发布两条提示；`ControlledFavoriteLedgerPanel` 只在收藏库 IPC 成功后调用由上层提供的完成回调。

## 验收

- 顶级页签手动切换只产生一次匹配的全局提示与小咪提示。
- 首次打开小咪时只有全局批阅说明和开场招呼，没有“切到批阅”气泡。
- 档案库和收藏库只在成功打开后显示各自说明。
- 动作执行、失败、状态灯跳转和重复点当前页不被入口文案覆盖。
