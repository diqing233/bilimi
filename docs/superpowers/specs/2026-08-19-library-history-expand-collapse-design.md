# 收藏库分类调整记录展开折叠设计

## 目标

让收藏库视频详情中的分类调整“查看完整记录”成为明确的展开/折叠控件，保留默认轻量视图，并避免重复读取已经加载的记录。

## 行为设计

- 详情进入或切换视频时，分类调整记录区域保持折叠，只显示最近调整。
- 首次点击“查看完整记录”时，使用现有 IPC 分页参数读取当前视频记录；成功后展开列表并把按钮改为“收起完整记录”。
- 如果当前视频的完整记录已经读取过但区域被收起，再次点击只展开缓存，不重复调用 IPC。
- 展开时显示已加载记录；只有展开且存在 `nextCursor` 时显示“加载更早记录”。
- 点击“收起完整记录”只隐藏列表和分页按钮，保留内存数据；不改写记录或归属事实。
- 首次读取失败时维持折叠状态，保留原按钮以便重试。

## 实现边界

只调整 `FavoriteLibraryApp.tsx` 的分类调整详情状态与按钮渲染，并补充该组件测试；不修改主进程 IPC、数据模型、分页协议、样式体系、最近调整数据或 B 站操作。

## 验证

自动化覆盖初始折叠、首次加载展开、按钮文案与 `aria-expanded`、收起隐藏、缓存复用和分页按钮条件。开发版手工验证同一视频的默认、展开、收起和再次展开状态，并确认记录内容与原有分页一致。
