# 推荐收藏夹状态与本地事务收口设计

## 目标

让推荐收藏夹在整理与非整理期间都能稳定勾选/取消、在详情页独立删除，并在第二轮整理中按稳定 ID恢复双向联动；推荐操作只写当前账号本地规则和工作区，不产生 B 站远端写入。

## 设计

渲染层把“是否正在可编辑整理”限定为向导展开且快照为 `previewing`。只有该条件成立时才调用推荐队列和分类命令；其它状态统一走账号级启用 IPC。推荐首次采用先提交同稳定 ID的账号规则，再刷新工作区；刷新失败作为独立可重试结果，不撤销已成功的本地提交。

状态投影建立三类精确身份：推荐候选 ID、账号规则 ID、远端观察 ID（由 `folderId` 可逆生成）。推荐候选和账号规则只能在精确稳定 ID相同的前提下合并、排除或建立双向联动；工作区分类不得按规则类型、标题或关键词把不同 ID 视为同一推荐。状态、全量确保、单册确保和保存都接收同一账号覆盖集，覆盖集包含账号规则、正式物理分册及待对账 ID。观察草稿只按结构字段和精确 ID去重；历史记录无法证明为纯观察时保留。

推荐取消采用可恢复事务：纯推荐草稿删除、候选采用移除和分类投影移除必须全部成功；中途失败恢复勾选和候选状态，并留下可重试事实。所有异步回写带账号、规则 ID和操作版本，丢弃过期快照，保留滚动容器锚点。

## 不在范围内

不重写普通收藏夹、B 站视频同步、删除确认、备册改名事务或启动小咪调度。推荐链路仅允许 B 站目录 GET；任何 B 站创建、改名、删除、解绑、移动成员和视频同步均由 spy 断言为零。

## 验收

先以失败回归覆盖非整理 toggle、第二轮回填、详情删除、失败回滚、完整覆盖集、历史重复收敛、账号切换、并发旧快照和 B 站零写入；再运行定向/全量测试和构建，最后在真实 Electron 中验收滚动位置、快速点击及窗口输入响应。
