# 收藏库底栏与 DeepSeek 反馈整改设计

## 目标

将收藏库从独立 Electron 窗口改为主窗口内的可收起底栏，并修复旧藏归档预览中 DeepSeek 反馈区域未占满工具卡的问题。

## 范围

本次只调整呈现与入口连接，不改变收藏库仓库、旧藏工作镜子、远端同步或 DeepSeek 请求语义。

### 收藏库底栏

- “收藏库”入口不再打开 `favoriteLibraryWindowController` 或创建独立窗口。
- 收藏库在主窗口渲染树中显示为浏览器工作区的底部抽屉。
- 主窗口水平布局保持“B 站工作区在左，掌库侧边栏在右”。底栏仅占左侧工作区宽度，绝不覆盖、挤压或改变右侧掌库的宽度和高度。
- 打开抽屉时，B 站 `webview` 及其标签区的可用高度缩小；右侧掌库继续占据完整主内容高度。
- 抽屉提供打开、收起和关闭控制，以及可拖动的垂直高度调整。高度受最小可用内容高度和浏览器工作区可用高度约束。
- 收起或关闭抽屉时保留已加载的收藏库状态，下一次打开恢复当前筛选、选择和已调节高度；关闭仅隐藏抽屉，不停止本地或远端收藏库任务。
- 收藏库组件从“独立窗口路由”中抽离为可嵌入内容。现有 repository IPC、订阅、视频打开、来源收藏夹打开、同步和转写操作继续复用，不复制状态机。
- 对外 IPC 入口由“打开收藏库窗口”改为通知主渲染进程打开抽屉；独立窗口专用 preload 与窗口控制器在没有其他消费者后移除或收敛，避免保留第二个入口。

### DeepSeek 反馈面板

- `OldFavoriteArchivePreviewStep` 的运行、失败、重试完成和成功反馈统一使用同一个全宽反馈面板。
- 面板宽度等于 DeepSeek 工具区可用宽度，采用 `box-sizing: border-box` 和可换行文本；进度轨始终占满面板内容宽度。
- 运行中显示批次与视频进度，操作位显示“取消 DeepSeek 整理”。请求取消后按钮显示“正在取消”并禁用；任务结束后不保留取消按钮。
- 有失败批次时显示全宽失败摘要、可展开详情和“重试失败批次”。重试完成后显示成功或仍失败的最终摘要，不能沿用紧凑的单行状态样式。
- 成功完成显示结果摘要和进度，不显示无效的重试或取消操作。
- 下方“改动记录”保持现有全宽虚线分隔及两个等宽撤销/恢复按钮布局。

## 数据与错误处理

- 抽屉仅持有可见性、已收起状态和高度等 UI 状态；收藏库数据仍由 `FavoriteRepositoryService` 持久化并通过现有订阅更新。
- 主窗口账号改变时，已挂载收藏库按现有账户刷新逻辑清空并重新读取，不能显示旧账号数据。
- 抽屉打开或 IPC 通知失败时不影响 B 站页面与掌库；收藏库原有的错误提示保持可见。
- DeepSeek 面板只呈现主进程反馈；取消、重试和请求的权限及任务互斥继续由已有旧藏 DeepSeek service 保证。

## 测试与验收

- 覆盖收藏库入口打开抽屉、不创建独立窗口、关闭/收起与高度边界、右侧掌库未被底栏包含的布局契约。
- 覆盖收藏库在抽屉内读取、订阅刷新与账户切换，并保留既有库操作测试。
- 覆盖 DeepSeek 运行、取消请求、失败可重试、重试完成和成功反馈的 DOM 状态与按钮可用性。
- 增加样式契约，验证反馈面板与进度轨全宽、可换行，且旧紧凑单行样式不再承载复合反馈。
- 运行定向测试、必要的 renderer/main 测试和 `npm run build`。

## 非目标

- 不改变每批 20 条、DeepSeek 输出限制、标签补取或旧藏分段策略。
- 不在整理步骤中增加自动同步到 B 站。
- 不修改右侧掌库的功能、宽度、折叠逻辑或布局。
