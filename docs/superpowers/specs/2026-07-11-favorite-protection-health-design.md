# 收藏归档保护健康状态设计

## 目标

已整理收藏仍保留本地保护记录时，扫描需要核对其历史 Bilimi 归档是否仍然存在，避免用户清空收藏夹后仍被误导为“保持原归档”。

## 判定

- 以保护记录中的 Bilimi 账册 ID 为稳定目标，查找当前对应的 B 站收藏夹并核对视频成员关系。
- 仅当旧记录缺少账册 ID 时，才用历史 B 站收藏夹 ID 兼容兜底。
- 历史目标全部存在为“归档完整”；部分存在为“归档不完整”；全部缺失为“归档已失效”。
- 已删除的账册视为缺失。同一账册删除后重建，即使 B 站收藏夹 ID 改变，只要视频已在新收藏夹中仍视为存在。

## 交互

- 三种状态都继续受保护，扫描不会自动重新分类。
- 扫描概览分别显示完整、不完整、已失效数量。
- 存在异常时说明异常收藏仍受保护，并提供“重新整理异常收藏 N”。
- 用户确认后，仅把异常且属于当前勾选来源的收藏纳入本轮，按当前启用账册重新判断。
- 保留原有“重新整理这些收藏”入口，用于用户主动全面重整当前来源中的全部受保护收藏。

## 验证

覆盖单目标缺失、多目标部分缺失、全部缺失、账册删除、同账册更换 B 站收藏夹 ID，以及未确认时仍保持冻结。
