# DeepSeek 功能独立控制设计

## 目标

将 DeepSeek 的功能开关拆成五个可独立控制且由主进程强制校验的能力，同时统一首次启用、重置、状态灯说明、推荐模型和设置页布局。

## 功能与默认值

- DeepSeek 总开关只决定整体是否可用，不清除子功能选择。
- 五个子功能为：趣味评论、自动总结、宠物对话、批阅辅助、旧藏整理。
- 首次启用或重置后，五项子功能预设为开启；用户后续关闭某项后，关闭再开启总开关时保留选择。
- 批阅辅助独立控制日常分类二判，策略为“全部归类”或“仅不太稳”。
- 旧藏整理只决定归档预览中的 DeepSeek 整理入口是否可用，仍需用户手动执行，整理范围仍由归档预览选择。
- 默认模型为 `deepseek-v4-flash`，默认服务地址为 `https://api.deepseek.com`。
- 重置 DeepSeek 或全部设置时关闭总开关、清空 API 密钥，并恢复上述默认模型、服务地址、五项子功能和“全部归类”策略。

## 设置页布局

- 两列区域保留趣味评论、自动总结、宠物对话、旧藏整理。
- 批阅辅助单独放在两列区域下方第一行，布局为“复选框 + 紧邻的策略下拉菜单”。
- 批阅辅助关闭时下拉菜单禁用并保持清晰的禁用态。
- 推荐模型改为两行，每行独立复制：`（日常便宜）deepseek-v4-flash` 与 `（精准略贵）deepseek-v4-pro`。
- 推荐服务器地址的复制按钮紧跟 `https://api.yunshulink.com/v1`，空间不足时地址和按钮作为整体自然换行，按钮不得漂到容器右侧。

## 权限边界

渲染层负责及时隐藏或禁用入口，主进程负责最终授权。主进程收到 DeepSeek 请求时按请求类型检查对应子开关：

- `review-comment` -> 趣味评论
- `note-poster` -> 自动总结
- `pet-chat` -> 宠物对话
- `favorite-daily-classify-review` -> 批阅辅助
- `favorite-archive-organize` -> 旧藏整理

关闭后不得启动新任务；已经发出的任务允许完成。

## 状态灯悬浮说明

所有连接状态均保留五项功能状态与解释；工作中额外显示任务列表。开启文案为：

- 趣味评论：开启，会生成候选弹幕，可复制发布为评论。
- 自动总结：开启，会在视频转写后生成文稿总结。
- 宠物对话：开启，小咪会调用 DeepSeek 对话。
- 批阅辅助：开启（全部归类/仅不太稳），会用 DeepSeek 复核批阅分类。
- 旧藏整理：开启，可在归档预览中手动执行 DeepSeek 整理。

关闭时使用对应否定说明，避免“关闭但仍可使用”的矛盾表达。

## 验证

- 单元测试覆盖默认值、旧配置迁移、重置、首次启用、保留用户选择、五项独立开关和主进程授权映射。
- 组件测试覆盖批阅辅助下拉菜单、推荐模型复制、服务器地址紧邻复制按钮、状态灯各状态完整说明，以及宠物窗口收到关闭广播后禁止继续提交。
- 运行类型检查/构建和完整测试，确认未影响既有 DeepSeek 任务与设置保存合并逻辑。

## 转写状态文案修正

- 无活动任务且本次启动没有成功记录：灰灯 `暂无转写`。
- 无活动任务但本次启动已有成功记录：绿灯 `暂无转写 · 成功 N`。
- 悬浮说明为：`本次启动已成功转写 N 个视频，文稿已保存到档案库。`
