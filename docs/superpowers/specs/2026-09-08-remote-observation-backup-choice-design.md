# 远端观察备册选择设计

## 目标

停止将 B 站目录中的陌生 bilimi 收藏夹自动持久化为本地 `custom-remote-*` 草稿；只在用户发起备册时展示只读候选，并允许用户明确选择将指定候选生成本地草稿。推荐收藏夹的生成、保存和联动不在本次改动范围内。

## 事实与范围

- B 站目录结果是只读观察，不是本地收藏夹规则。
- 当前规则仍是备册的唯一目标；远端观察不能覆盖规则 ID、`displayName` 或创建标题。
- 当前存在的“纯远端观察草稿”（`local-draft + unbound + 单一远端 ID + 未启用 + 无关键词 + 非 saved-rule`）视为旧版观察投影：从规则快照迁出为只读观察，不作为规则保留或再次持久化。
- 用户从备册弹窗选择生成草稿时，生成的是显式、本地、未保存的草稿，记录精确 `folderId`、远端标题和成员数；它不自动绑定、启用、创建 B 站收藏夹或进入推荐来源。
- 用户不选择生成草稿时，当前备册继续走既有“确认绑定候选 / 确认创建并绑定”流程。
- 已有正式绑定、待创建对账、已删除抑制的精确 ID 不作为陌生观察候选。

## 数据流

1. 收藏夹目录读取以现有本地规则与正式绑定 ID 过滤，输出 `remoteObservations`，每项包含精确 `folderId`、B 站标题和成员数。
2. 状态读取和普通刷新只把正式规则写回偏好；`remoteObservations` 仅留在本次状态结果中，绝不追加到 `ledgers`。
3. 用户点击备册，首次只读取目录并返回目标规则的候选绑定/创建结果与 `remoteObservations`；该只读观察预检先于已绑定收藏夹的改名预检，因此名称待确认也不能遮蔽远端观察提示。
4. 既有确认弹窗展示观察项：每项默认不选。用户可勾选“生成本地草稿”。
5. 点击确认时，先把选中的观察项转换为新的本地草稿并与原有规则一同保存；随后以原来选定的目标规则继续绑定或创建。未选择的观察项不保存。
6. 创建请求的 `title` 必须直接来自被备册目标规则的 `displayName`。例如 `bilimi·梅林FIT` 的创建请求不得采用任一观察项的 `title`。

## UI

沿用“确认绑定 bilimi 收藏夹 / 确认创建并绑定 bilimi 收藏夹”弹窗。在候选绑定区域之后显示：

> 另发现 N 个未保存的 B 站 bilimi 收藏夹。它们不会自动加入本地规则，也不会影响本次备册。可按需生成本地草稿。

每项用复选框显示 `标题（成员数 个视频）`。默认全部未选。

- 不选：确认按钮继续原绑定/创建操作。
- 选中：确认按钮额外保存所选本地草稿；草稿不自动启用或绑定。
- 取消：不保存观察项，也不继续备册。

## 错误与副作用

- 目录读取失败时不产生观察项，也不创建草稿。
- 本地草稿保存失败时不继续 B 站备册，避免用户以为观察已保存。
- B 站创建仍只发生在既有“确认创建并绑定”确认之后；创建响应返回 ID 而正式绑定登记失败时保留既有待确认语义，不能第二次创建。

## 回归验收

1. 普通目录状态读取发现 `bilimi·远端` 时，返回只读观察但 `ledgers` 中没有 `custom-remote-*`。
2. 已正式绑定的精确 ID 不出现在观察项中。
3. 备册弹窗默认不生成观察草稿；确认后仍调用原目标规则的备册。
4. 仅勾选的精确观察 ID 会生成草稿，且不绑定/启用/创建远端夹。
5. 推荐规则生成和保存路径的输出不包含观察草稿，行为与现有测试一致。
6. `bilimi·梅林FIT` 的创建 POST 体始终为 `title=bilimi·梅林FIT`，即使目录中存在 `bilimi小咪的收藏夹`。
