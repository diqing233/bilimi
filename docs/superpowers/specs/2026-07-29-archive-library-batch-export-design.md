# 档案库批量导出设计

## 目标

在“全局档案库 / 所有视频历史”中增加批量导出能力。用户可进入批量模式，选择任意档案或一次选中整个档案库，并继续正常打开档案详情。批量导出复用现有中央导出弹窗和主进程导出服务，不改变已有文件组织方式。

## 入口与批量模式

- 在“所有视频历史”标题区域增加“批量导出”按钮。
- 点击后进入批量模式，初始不选择任何档案。
- 每张档案卡片左侧增加复选框，右侧“详情”按钮继续保留。
- 点击复选框只改变批量选择；点击档案标题或“详情”只打开详情，不隐式改变勾选状态。
- 打开详情及返回列表时，批量模式和已选档案保持不变。
- 退出批量模式时清空选择；完成一次导出后保留批量模式和选择，方便调整导出选项后再次导出。

## 批量操作栏

批量模式下，在档案列表上方显示批量操作栏，提供：

- “全选全部档案”：选择档案库中的全部档案，不受当前搜索、星标或备注筛选影响。
- 已选数量：显示全部已选档案数量。
- 隐藏选择提示：若筛选条件隐藏了部分已选档案，显示“已选 N 项，其中 M 项不在当前筛选结果中”。
- “清除”：清空选择但保持批量模式。
- “取消批量”：退出批量模式并清空选择。
- “导出”：至少选择一项后可用，打开现有中央导出弹窗。

侧边栏宽度有限，批量操作栏必须使用可换行布局。按钮和状态信息在空间不足时自然换到下一行，不允许横向溢出、裁切文字或依赖横向滚动；各按钮仍需保持可点击尺寸和清晰间距。

## 版本与导出内容

- 每个被选档案只导出其最新版本，以档案版本数组中的最新有效版本为准。
- 打开详情并切换历史版本不影响批量导出版本；批量导出仍使用该档案的最新版本。
- 没有有效版本或在导出前失效的档案由现有预览与导出流程计入“跳过”。
- 导出弹窗默认选择“完整档案”。
- 用户仍可切换为“单项内容”，并通过现有下拉菜单统一选择无时间线文稿、带时间线文稿、详细内容提要、精修文稿等内容类型。
- Markdown、Word、包含备注、预览、进度、取消和打开文件夹等能力沿用现有弹窗行为。

## 文件组织与执行

继续使用现有批量导出服务：

- 用户选择父目录后，创建 `bilimi文稿_日期_时间` 形式的时间戳文件夹。
- 所有视频文件平铺在该文件夹中，不建立每个视频的子文件夹，也不生成 ZIP。
- 文件名继续使用“视频标题 + BV号/AV号”，非法字符替换为下划线。
- 同名文件夹或文件使用编号后缀，绝不覆盖已有内容。
- 多个档案顺序导出；单项跳过或失败不阻止后续项目；继续支持进度与取消。

## 状态边界

- 搜索和筛选变化只影响可见列表，不自动增加或移除已选档案。
- “全选全部档案”之后再修改筛选，全部选择仍然保留。
- 档案在批量模式中被外部删除或版本失效时，不在前端静默替换身份；交给现有导出预览重新校验并显示跳过数量。
- 档案库为空时，“批量导出”入口禁用或进入后无法导出，不展示无意义的可用操作。

## 实现边界

- 主要改动位于档案库面板的多选状态、列表卡片和响应式批量操作栏。
- 复用 `VideoNoteBatchExportDialog`，由档案库入口构造每个档案最新版本的 `archiveId/versionId` 选择集合。
- 不修改主进程批量导出目录结构与写文件逻辑，除非测试发现现有服务无法接收档案库产生的合法选择。
- 不把批量选择状态持久化到磁盘；它只在当前档案库面板会话中保留。

## 验证

- 组件测试覆盖进入和退出批量模式、默认零选择、逐项选择、清除与导出按钮状态。
- 测试“全选全部档案”不受搜索、星标和备注筛选影响。
- 测试筛选隐藏已选项时的数量提示，以及筛选变化不会丢失选择。
- 测试批量模式下仍可打开详情，返回后模式与选择保持不变。
- 测试构造的每个选择都使用对应档案最新版本，而非详情当前查看版本。
- 测试导出弹窗默认“完整档案”，并保留“单项内容”下拉选择。
- 布局测试覆盖窄侧边栏下批量操作栏换行，确认没有横向溢出或按钮裁切。
- 运行档案库面板、批量导出弹窗和相关布局测试，并执行项目类型检查。
