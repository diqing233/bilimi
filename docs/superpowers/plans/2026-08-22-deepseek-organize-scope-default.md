# DeepSeek 整理对象默认范围 Implementation Plan

**目标：** 将 DeepSeek 整理弹窗的默认处理范围改为只处理未匹配到合适分类的视频，并同步准确文案与显示顺序。

## 实施步骤

1. 覆盖 R001 的弹窗组件回归测试：断言三项的精确顺序、首项默认选中、第二项没有“推荐”字样，且用户仍可切换“重新检查全部”并提交既有模式。
2. 先运行该测试，确认它因现有默认模式和文案失败。
3. 在 `OldFavoriteArchivePreviewStep` 中只调整选项数组和打开弹窗时的临时默认值；不改变 `DeepSeekArchiveMode`、批次 scope 或回调协议。
4. 运行组件聚焦测试、相关 DeepSeek 整理回归、构建与差异检查；若可安全启动新 Electron 开发版，仅观察弹窗并保存截图。所有 B 站操作、DeepSeek 请求和写入按钮均不点击。
5. 在账本 I001 记录代码、测试和界面验收证据；只在本轮范围完整且没有混入现有恢复草稿修复时提交。
