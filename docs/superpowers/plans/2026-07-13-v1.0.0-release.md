# bilimi v1.0.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a verified Windows x64 `v1.0.0` release with the supplied Xiaomiao icon and a page-by-page README user manual.

**Architecture:** Keep `electron/assets/bilimi-icon-source.png` as the canonical square artwork and derive every runtime and packaged icon through the existing generator. Treat README, package metadata, automated tests, three-form application checks, installer inspection, Git main, and GitHub Release as one release transaction with one final repository commit.

**Tech Stack:** Electron 42, electron-vite, React 19, TypeScript, Vitest, Pillow-based icon generation, electron-builder NSIS, GitHub CLI.
