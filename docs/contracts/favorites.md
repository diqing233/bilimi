# 收藏夹契约

> 面向收藏夹相关功能的实现者、评审者与接手者。本文件把跨页面必须一致的稳定行为集中为可核对的契约；不记录讨论原文、实施过程或单次测试结果。完整产品行为以 [项目功能项目书](../项目功能项目书.md) 第 2、4、5、6、8 节为准；需求原文和逐项证据以 `docs/requirement-ledgers/` 为准。

## 1. 范围与权威来源

- **远端 B 站收藏夹**是账号拥有的远端实体，必须以真实 `folderId` 识别；名称、`bilimi` 前缀、数量、列表次序或同名都不能代替 ID。
- **bilimi 本地工作夹/规则**是用户保存的本地组织意图，以规则 ID 识别。它可以尚未备册，不能被远端观察结果反向替代。
- **远端草稿**是 B 站观察到、但尚未有本地规则的疑似 bilimi 收藏夹。它始终是独立的 `未保存 · 未绑定` 投影，不能自动成为规则、绑定候选或分类目标。
- **本地删除远端草稿**只移除本地投影，不删除 B 站夹；被删除的真实 `folderId` 按账号暂时隐藏于普通状态刷新，并且只在下一次右侧`一键备册`重新观察 B 站清单时解除隐藏和重建草稿。“不再提醒”是独立的持久抑制，不被一键备册解除。
- 账号级收藏仓库、工作区、绑定、成员关系、操作记录与恢复状态由 Electron 主进程持久化并发布权威快照。页面只显示快照、发出命令，不能持有另一份事实。
- 账号切换时，规则、工作区、缓存、任务和视图状态必须按 `accountMid` 隔离；不得以旧账号快照覆盖新账号。

## 2. 分类、预分类与写入目标

| 情形 | 本地预分类 | B 站写入 | 本地确认登记与反馈 |
| --- | --- | --- | --- |
| 已保存、已启用、已备册且已绑定规则命中 | 参与 | 可写入该规则的真实绑定分册，受容量和策略限制 | 以实际目标登记归属；B 站成功后执行同一 `operationId` 的主进程原子登记。 |
| 已保存、已启用、未备册或未绑定规则命中 | 参与并保留为最佳建议 | 不能写入该规则，也不能因此创建、绑定或声称同步 | 明确显示它未备册/未绑定；不得把建议名称写成已同步目标。 |
| 最佳建议不可写，但有匹配的已备册且已绑定规则 | 全部已启用规则仍参与排名 | 写入评分最高的可写匹配规则 | 反馈同时保留预分类建议与实际写入目标。 |
| 最佳建议不可写，且没有可写匹配规则，但 `暂存` 已启用、已备册、已绑定 | 保留最佳建议 | 只写入 `暂存` 的真实分册 | 反馈必须区分“预分类建议：X（未备册/未绑定）”与“已写入：暂存”。 |
| 没有任何可写目标，或读取目标状态失败 | 可显示本地预分类 | 不发起 B 站收藏，也不登记已确认远端归属 | 显示本地预分类/可操作原因；不得伪造成功。 |

预分类资格只取决于“已保存 + 已启用”；远端草稿不参与。远端写入资格只取决于最终目标集合及其新鲜、目标级的绑定/容量/冲突证据，不能由账号内无关规则的缺口全局阻塞。

## 3. 备册与绑定

### 3.1 入口范围

- 右侧 `一键备册` 在点击瞬间锁定当前已勾选的已保存本地规则；它同时可读取 B 站清单并刷新远端草稿投影。为了保存完整本地快照而合并未选规则时，未选规则仍不得进入这次候选确认、二次读取或创建循环。
- 收藏库 `备册当前收藏夹` 和规则详情 `备册` 只作用于当前逻辑工作夹；不得扩大为全量备册或缩小为某一个物理分册。
- 单个入口、全量入口与宠物快捷入口均复用同一主进程状态模型，但各自只报告自己实际锁定的目标范围；宠物/全量入口读取远端清单时必须带上普通状态的两类草稿抑制 ID，不能解除“本地删除后待下一次右侧备册重发现”的临时隐藏。

### 3.2 创建、绑定与草稿边界

| 观察结果 | 正确路径 | 禁止行为 |
| --- | --- | --- |
| 目标已有正式绑定 | 复用已保存的真实远端 ID。 | 再创建同名远端夹。 |
| 发现该本地规则的实际未绑定远端候选 | 显示候选及具体 folder ID，等待用户明确确认绑定。 | 按名称自动绑定、改名或同步视频。 |
| 已在既有双确认删除中收到成功回执的精确旧 ID 仍短暂出现在目录 | 只把该精确 ID 作为删除后最终一致性残留过滤；首次读取和创建前二次读取都不将它列为候选或远端草稿。若没有不同 ID 的同名候选，按无候选路径创建并登记新 ID；新 ID 正式绑定成功后清除旧 ID 删除证据。 | 按名称忽略其他 ID、自动认领同名夹，或在新 ID 尚未正式绑定时清除旧 ID 证据。 |
| 未发现可复用候选 | 现有备册入口直接创建并以本次返回的真实 ID登记正式绑定；本地删除标记遗留的旧 ID不能阻止新 ID登记。登记时以无缓存清单对该精确 ID有界重读；仍不可见则显示`已创建 · 待正式确认`、保留 ID与具体失败原因，下次右侧一键备册只重试该 ID。 | 把“无候选”当成未绑定候选、按同名 ID要求二次选择、再次创建，或将远端草稿纳入本地备册范围。 |
| 发现没有本地规则的疑似 bilimi 远端夹 | 按每个真实 `folderId` 生成独立远端草稿，供用户编辑后保存；同名远端夹也分别保留。 | 自动保存、启用、绑定、改名、移动、同步、删除，或按标题合并远端身份。 |

备册只创建或明确建立绑定，不同步视频、不移动成员、不删除任何 B 站夹。已备册的唯一事实条件是：权威快照中存在对应 `physicalShards`，且每个实际参与的分册均有真实 `folderId` 和 `bindingState=bound`。

### 3.3 整理同步的统一备册预检

- 点击`确认并同步到 B 站`时，冻结前必须做无副作用预检：本轮分类分配所需新增物理分册，以及当前账号所有已保存、已启用但未备册的本地规则，合并到同一个备册确认窗口。
- 有任一缺口时，取消、关闭或未完成备册都保持整理草稿可继续；不得冻结计划、创建/绑定分册或写 B 站。完成既有备册确认后必须重新读取并核验缺口，再进入冻结。
- 没有缺口时不显示额外弹窗，沿用直接冻结和同步。冻结后禁止通过容量分配隐式创建或绑定任何分册。
- 该预检不把远端草稿纳入备册目标；实际存在的精确未绑定候选仍保留既有明确绑定确认，创建前二次读取仍适用。

## 4. 物理分册与身份

- 一个逻辑工作夹可对应 0、1 或多个物理分册；分册身份由账号、逻辑工作夹 ID、远端 `folderId` 和 `shardNumber` 共同确定。
- 同名或缺少可靠历史编号的候选必须让用户按具体远端 ID 选择；默认顺序只能是可调整建议。
- 收藏库选择“全部”时浏览逻辑工作夹全部成员；选择单册只改变本地读取范围，不读取/写入 B 站，也不改变备册范围、绑定或成员。

## 5. 删除、恢复与回收

| 用户动作 | 本地与远端结果 | 不得影响 |
| --- | --- | --- |
| 仅从收藏库删除视频 | 删除本地视频行和本地期望归属。 | B 站收藏、规则、绑定、档案、转写、保护和其他账号数据。 |
| 删除本地收藏夹规则 | 删除规则投影；左侧保留恢复窗口并显示`收藏夹已删除`，直至按回收规则收束。 | 不能把已删除规则显示为`未备册`/`未绑定`，也不能自动删除 B 站夹。 |
| 选择“同时从 B 站删除整个 bilimi 工作夹” | 仅在用户完成现有二次确认及未绑定知情确认后，对预览到的真实远端 ID 执行删除；已正式绑定的逻辑规则旁，如目录还存在同一规范化标题、不同 ID的 bilimi 夹，也必须作为独立未绑定候选列出并按其 ID处理；已勾选、带真实 ID的`未保存 · 未绑定`远端草稿同样如此。 | 不因名称相似扩大删除范围；不自动认领、绑定或删除未预览的 ID；不删除视频档案、转写或无关收藏夹。 |
| 正式分册缺失但规则仍留有历史远端 ID | `physicalShards`缺失时，遗留的规则 ID、标题、数量与`bound`状态均不是已备册事实；页面显示`未备册`。用户明确选择同一 B 站删除路径后，重新读取目录：仍含该**精确 ID**的夹列为独立未正式绑定候选并要求现有未绑定知情确认；目录确认该 ID已缺失时，只在本次确认删除完成时收敛本地旧 ID。 | 不按标题、`·N`分册后缀、数量或次序猜测其它 ID；不自动重新绑定、创建、改名、移动或删除任何未预览的远端夹。 |
| 恢复当前收藏夹 | 恢复删除前的本地规则快照，之后才可再次备册。 | 不创建/绑定 B 站夹，不同步视频。 |
| 单独删除`未保存 · 未绑定`远端草稿 | 只删除本地草稿投影；普通刷新继续隐藏同一真实远端 ID。 | 不删除 B 站夹、不弹远端删除确认；只有下次右侧`一键备册`才可重新发现。 |

所有删除、解绑、备册、确认绑定和对账完成后，掌库、收藏库和当前整理草稿必须从同一新权威快照重投影。失败、取消、部分成功或结果未知必须保留可重试/可对账事实，不能用界面关闭或乐观清理伪造成功。

## 6. 批阅收藏的原子登记

1. 页面确认当前激活标签仍是发起操作时的同一视频，并对最终可写目标完成 B 站请求。
2. 只有 B 站确认成功，页面才带同一 `operationId` 和实际远端 folder ID 调用专用主进程登记入口。
3. 主进程重新校验账号、规则、分册绑定和远端成功证据，并在一个事务中写入视频资料、归属、整理保护和 `entered` 收藏历史，再发布新 revision。
4. 同一 `operationId` 的重试只返回或补齐既有本地结果，不重复 B 站写入、不重复追加历史。

整理收藏的分类审计身份在本地分类首次持久化时创建；同一工作区、同一视频、同一分类来源和同一目标的恢复性补写或 B 站同步只能更新该审计的同步状态。观察远端成员、扫描初始化、空归属到空归属和目标未变化的重复提交均不是分类调整，不得生成或更新“首次分类”/“第 N 次调整”。

用户可见 B 站同步状态只使用`已同步`和`未同步`。本地登记技术故障保留内部可恢复记录，但不能抹去已确认的 B 站事实、删除已有本地资料，或新增第三种对用户不可操作的同步状态。

## 7. 性能与回归底线

- B 站读取、创建、绑定、删除、快照持久化和大列表重算必须分段或排队。进行中状态、取消/关闭入口、鼠标移动、点击、滚动、缩放、最小化和关闭保持响应。
- 远端刷新只由明确动作触发；本地查询、排序、筛选、聚合和详情优先读取当前账号本地仓库。
- 收藏夹改动不得改变成熟且不在当前范围内的转写、档案、DeepSeek、普通 B 站来源关系或已冻结整理计划。
