# 收藏夹批次 A：一键备册与批阅写入目标

> 交接任务包，日期：2026-08-21。它把当前收藏夹批次的稳定产品契约、原始讨论账本、实施计划与待验收范围放在同一个入口。它不是需求账本，不替代原文；也不是实现日志，不应记录无关提交历史。

## 目标

恢复右侧一键备册的直接创建语义，并在创建成功的同一操作完成正式绑定；保持未绑定远端候选的显式确认，并让“同时从 B 站删除”在双知情同意后覆盖已勾选的远端草稿；批阅继续将“本地最佳预分类建议”与“实际可写 B 站目标”分离。

1. [2026-08-20 一键备册确认边界账本](../requirement-ledgers/2026-08-20-one-click-backup-confirmation.md)：R001–R026 的完整用户原文、逐项索引和明确不改边界。

## 本批次确认范围

| 账本项 | 要交付的行为 | 验收重点 |
| --- | --- | --- |
| I001（R001、R002、R005） | 右侧已勾选本地规则的一键备册在无真实候选时直接创建并绑定；B 站发现仍独立生成草稿。 | 空候选不出现“待确认创建”阻塞；发现的远端草稿不进入本地备册范围。 |
| I002（R003、R004） | 未保存、未绑定远端草稿不参与一键备册；仅保留既有的“同时从 B 站删除”且双知情确认后的删除路径。 | 不放宽、改文案或自动执行删除；自动化和 UI 只验收确认前路径。 |
| I004（R007） | 已保存且启用的规则可以本地预分类，不受未备册/未绑定限制；远端草稿仍不分类。 | 预分类本身不创建、绑定、移动或删除 B 站收藏夹。 |
| I008（R011） | 全部启用规则参与本地建议；B 站只写实际已备册、已绑定的最终目标，不再被无关全局缺口阻断。 | 本地建议、远端请求和已确认归属使用各自正确的目标集合。 |
| I009（R012） | 没有匹配可写目标时，已备册且已绑定的`暂存`是唯一回退写入目标。 | 反馈同时写明未备册建议和实际`暂存`写入；`暂存`不可写则零远端写入。 |
| I010（R013） | “最佳匹配”提示与紧邻分类提示使用同一正文文本规格。 | 只调整该提示的文字度量，不改颜色、间距、分类或同步行为。 |
| I011（R017、R018、R020） | 本地删除远端草稿后，普通刷新继续隐藏；仅下次右侧一键备册重新发现。 | 删除不请求 B 站；手动“不再提醒”仍是独立且不会被备册解除的长期抑制。 |
| I015（R024） | 带本地删除标记的规则在无候选时创建新远端夹后，必须在同一次备册登记该新 ID为正式绑定。 | 旧 ID不得导致新 ID的正式登记被跳过；登记失败保留真实新 ID和原因，不重复创建。 |
| I016（R025） | 已勾选的`未保存 · 未绑定`远端草稿在“同时从 B 站删除”时列入未绑定候选清单，并在双知情同意后按真实 ID删除。 | “仅删除右侧”仍只删除本地投影；不改知情同意文案、不自动选择或删除草稿。 |

## 明确排除与受保护流程

- 不改收藏库单个“备册当前收藏夹”入口的产品语义。
- 不改远端草稿的保存/显示规则，不自动绑定、改名、移动或同步草稿。
- 不改现有未绑定远端候选的删除同意文案和双确认路径；本批次不执行实际 B 站删除。
- 不改 DeepSeek、转写、普通 B 站来源关系、已冻结整理计划或无关 UI 行。
- 不执行未授权的真实 B 站创建、绑定、收藏、删除或同步；真实界面验收仅覆盖安全的读取、取消与展示路径。

## 目标决策表

| 本地最佳建议 | 其他匹配且可写的规则 | 可写`暂存` | B 站动作 | 用户反馈 |
| --- | --- | --- | --- | --- |
| 已备册、已绑定 | 任意 | 任意 | 写入该最终匹配目标。 | 维持正常成功语义。 |
| 未备册/未绑定 | 有 | 任意 | 写入评分最高的可写匹配目标。 | `预分类建议：X（未备册/未绑定）` + 实际写入目标。 |
| 未备册/未绑定 | 无 | 有 | 只写入`暂存`。 | `预分类建议：X（未备册/未绑定）` + `已写入：暂存`。 |
| 未备册/未绑定 | 无 | 无 | 不写 B 站，也不登记确认远端归属。 | 保留本地预分类和可操作的备册/绑定原因。 |
