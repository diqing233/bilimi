## 更新提示位置清单

当前讨论中涉及的更新/状态提示位置：

- 全局固定提示区：位于右侧面板顶部红线到蓝线之间，蓝线始终和 B 站左侧横线对齐。这里统一展示全局更新信息提示。
- 全局提示区内容：不是把字体放大，而是利用更大的区域容纳多类状态；一部分展示当前页面的新内容提示，一部分展示正在进行和已完成的操作提示。
- 持续操作状态：转写音频、转写队列、旧藏整理、DeepSeek 总结生成等持续任务，需要在全局提示区展示进行中、完成、失败或可重试状态。
- 设置页提示位置迁移：设置中刚刚讨论的提示不再固定在设置页下拉菜单下面，而是移动到全局固定提示区。
- 设置页 DeepSeek 连接状态提示：只显示在 DeepSeek 对应内容区内，不作为顶部按钮或下拉入口。
- 归档预览说明提示：归档预览标题下方说明“增删收藏夹或修改标签后，回到归档预览会自动更新”。
- 归档预览 DeepSeek 辅助整理状态提示：操作结果类提示不放在 DeepSeek 辅助整理块内部，应上浮到顶部全局提示区，例如“已撤销本次改动”。
- 归档预览撤销/恢复说明提示：固定说明可以位于撤销/恢复控制区内，用短文案说明 Ctrl+Z、Ctrl+Shift+Z 等快捷键和按钮作用；实际撤销/恢复结果反馈上浮到顶部全局提示区。
- 进度任务状态提示：转写音频、转写队列、旧藏确认整理进度条使用“文字状态 + 细进度轨道”，展示运行、完成、失败或空闲状态。
- DeepSeek 总结生成状态提示：札记和档案库详情中生成总结时，需要在切页回来后仍显示生成中、完成或失败。

待统一原则：

- 固定区提示用于全局、当前页面新内容和持续任务状态。
- 内容区提示用于某个功能块自己的结果反馈。
- 任务型提示需要保留运行、完成、失败、可重试等状态，不依赖鼠标光标表达。
- 全局提示区给大空间是为了容纳信息密度和持续状态，不是为了放大字体。

## 全局提示区文字版草稿

整体结构：

```text
┌──────────────────────────────────────────────────────────────┐
│ 右侧顶部任务按钮区                                             │
│                         [批阅] [札记] [档案] [设置]             │
│                         ↑ 四个按钮整体上移，对齐左侧任务栏高度  │
├──────────────────────────────────────────────────────────────┤ ← 红线
│ 全局提示区                                                     │
│ ┌ 当前页面更新 ───────────────────────────────┐ ┌ 持续任务 ───┐ │
│ │ 设置已保存 / 已切换到诊断 / 档案库已更新      │ │ 转写中 42%  │ │
│ │ DeepSeek 已连接 / 归档预览已自动刷新          │ │ 总结生成中  │ │
│ └────────────────────────────────────────────┘ └────────────┘ │
│ 字体保持正常大小；空间用于容纳多条状态，不用于放大文字。          │
├──────────────────────────────────────────────────────────────┤ ← 蓝线，始终对齐左侧 B 站横线
│ 当前页面内容                                                     │
│ 例如设置页：                                                     │
│ 设置                                   [恢复默认布局] [重置设置] │
│ 设置项  [诊断 ▼]                                               │
│ 可滚动设置内容...                                                │
└──────────────────────────────────────────────────────────────┘
```

全局提示区内部信息分工：

- 左侧/主区域展示当前页面的新内容和即时反馈，例如设置保存、页面切换、档案库刷新、DeepSeek 连接成功。
- 右侧/辅助区域展示持续任务状态，例如转写音频中、转写队列进度、DeepSeek 总结生成中、旧藏整理中。
- 任务完成后在同一区域短暂展示完成或失败提示，失败提示需要能引导重试。
- 当没有持续任务时，右侧区域可以收起或显示最近完成状态，避免空大块。
- 多个持续任务同时存在时，优先展示正在进行的任务；完成/失败信息作为次级条目展示。

多任务拥挤态规则：

```text
┌────────────────────────────────────────────┐
│ 即时反馈：设置已保存 / 已点赞 / 档案库已更新 │
│ ● DeepSeek  ● 转写音频  ● 整理旧藏          │
└────────────────────────────────────────────┘
```

- 全局提示区本体最多展示两行字，这是硬性限制。
- 第一行固定展示即时反馈，例如设置操作、点赞、收藏、投币、评论、档案库刷新等短反馈。
- 归档预览中的撤销/恢复结果也进入第一行即时反馈，例如“已撤销本次改动”“已恢复到上一步”。
- 第二行固定展示一排状态灯，不再把持续任务堆成多条文字。
- 状态灯第 1 个为 DeepSeek 状态：显示是否连接、DeepSeek 总结/整理是否进行中、进度或失败。
- 状态灯第 2 个为转写音频状态：显示是否转写中、进度、队列数量或失败。
- 状态灯第 3 个为整理状态：显示是否备册、旧藏整理是否进行中、整理进度、完成或失败。
- 状态灯使用短标签和颜色/小图标表达状态，完整详情放悬浮或点击展开面板。
- 第一行即时反馈过长时使用短文案和省略号，完整内容放悬浮或展开列表。
- 任务优先级：失败需处理 > 正在进行 > 刚完成 > 等待中 > 历史完成。
- 失败状态不应被折叠到不可见位置；对应状态灯需要进入失败色，并在第一行短暂展示失败摘要。
- 当前页面相关任务优先于其他页面任务；例如用户在札记页时，札记转写优先于旧藏整理。
- 完成提示短暂停留在第一行，然后对应状态灯回到空闲或最近完成状态。
- 展开列表只作为查看详情，不改变顶部固定区域高度，避免挤压下方页面内容。
- 第二行三个状态灯宽度固定或按比例均分，不能因为文案变化导致布局跳动。
- 后台任务完成不能强制切换当前页面；例如用户在批阅页时，转写成功后仍停留在批阅页。
- 转写完成、总结完成等后台结果只更新第一行即时反馈和第二行状态灯；用户主动点击状态灯或对应页面入口后，才进入结果页面查看。

状态灯颜色规则：

- 每个状态项前面都有一个颜色豆。
- 红灯：错误或必须处理的阻断状态，例如未备册、转写失败、整理失败。
- 黄灯：可继续但需要注意的状态，例如 DeepSeek 未连接、等待用户配置、队列等待过久。
- 绿灯：正常可用或已完成状态，例如 DeepSeek 已连接、备册成功、整理完成。
- 蓝灯：正常进行中的持续任务，例如转写中、DeepSeek 总结生成中、旧藏整理中；可使用轻微呼吸效果表达“正在进行”。
- 灰灯：空闲、暂无任务或未开始。
- “未备册”显示红灯，并通过悬浮提示解释原因和下一步。
- “DeepSeek 未连接”显示黄灯。
- “DeepSeek 已连接 + 备册成功”显示绿灯。
- “转写中”显示蓝灯；如果排队但未开始，可显示蓝色描边或灰蓝灯并标注队列数量。
- DeepSeek 状态灯悬浮说明包含当前连接状态和评论生成策略，例如“已开启，会生成三条有趣视频评论”。
