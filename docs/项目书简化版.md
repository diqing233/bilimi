# bilimi 项目书简化版（过渡稿）

本文件是过渡整理稿，不是独立规范。当前唯一权威项目书为 [项目功能项目书](项目功能项目书.md)；后续冲突只修订原项目书，不在此文件新增规则。

## 1. 产品总则

bilimi 以本地数据为中心，提供 B 站浏览、视频收藏、收藏夹管理、旧藏整理、札记、音频转写、档案和 DeepSeek 辅助能力。B 站页面、账号级本地收藏夹规则、整理工作区、扫描结果、收藏库视频、札记、转写和档案分别保存各自事实，任何页面都以当前账号的主进程权威快照显示。

1. 本地浏览、收藏库、札记、档案和设置在网络、登录、B 站页面、DeepSeek 或媒体工具异常时仍可使用；异常只影响对应能力，并显示中文的失败、取消或待核对原因。
2. 真实 B 站写入包括点赞、投币、弹幕/评论、收藏、创建/备册、绑定、改名、同步和远端删除。每次写入都显示进行中、成功、失败或结果待核对；未知结果不能显示为成功。
3. `保存`、`仅保存到收藏库`、`取消推荐`、`从收藏库删除`、`备册`和`同步到 B 站`是不同动作，不能互相代替。
4. 一个业务状态只有一个权威来源。渲染器只显示快照和发送命令，不维护会覆盖主进程事实的第二套规则、成员、推荐或删除状态。
5. 扫描、推荐、预览、人工分类和 DeepSeek 调整在确认执行前都可继续修改；冻结并开始 B 站执行后，计划和分类不能静默改变。
6. 磁盘、网络、远端目录、大列表和媒体任务采用有界异步队列。鼠标移动、点击、键盘、滚动、窗口拖动/缩放、最小化、恢复、关闭和取消入口始终可响应。

### 2.2 启动与窗口响应

主窗口创建、首帧提交和渲染器交互就绪优先于磁盘、网络、B 站首页、小咪和诊断初始化。B 站首页 guest WebView 在主窗口就绪后独立挂载和加载，`dom-ready`、`did-stop-loading`或`did-fail-load`任一真实事件收束后才释放小咪自动唤醒资格；看门狗只记录诊断，不用超时伪造加载完成。

小咪创建、renderer 初始化、显示、点击穿透、拖动边界、白条/DWM 修补和鼠标恢复均为可取消的后台阶段。小咪必须先以隐藏、透明、点击穿透状态完成轻量初始化并显示，再执行非关键原生修补；显示前不启动鼠标恢复轮询。后台阶段遇到真实输入立即让路、延后或取消，不得阻塞主窗口首帧和网页操作。

连续鼠标移动、按下/抬起、滚动、键盘、拖动、缩放、最小化、恢复和关闭都属于前台响应指标。自动首次显示小咪须经过首页真实收束和连续安静窗口；用户显式唤醒可优先创建必要窗口，但非必要修补仍让路。窗口路由按主窗口、小咪、悬浮菜单和独立助手分离加载模块，不因显示小咪而同步解析主窗口的 B 站、收藏、转写或 DeepSeek。

### 2.3 网页标签

- 首页标签始终存在且不可关闭；普通标签在应用内打开视频或 B 站链接后出现，可切换、刷新和关闭。
- 当前激活标签改变时重新识别标题、UP、链接、BV/AV视频和精确分 P；未识别、未登录、无权限、结构异常或仍加载时，依赖当前视频的动作不可用并显示“待识别”或具体原因。
- 关闭网页标签不删除收藏、札记、档案或转写。视频全屏按设置临时隐藏小咪，退出后只恢复进入全屏前确实可见的小咪。

## 3. 右侧助手与批阅

`批阅`、`札记`、`掌库`、`设置`四个页签互斥显示；切换、收起和独立助手窗口失焦不丢失网页上下文、任务、选择或本地状态。

### 3.1 批阅动作

| 动作 | 可用条件和界面 | 点击结果 | B 站与失败边界 |
| --- | --- | --- | --- |
| `轻赏`（点赞） | 已登录且当前标签为可识别视频。 | 对当前视频点赞并反馈进行中和结果。 | 页面实际状态是最终事实；未登录、页面不匹配、权限不足或接口失败不伪造成功。 |
| `归库`（收藏） | 当前视频可识别且存在目标规则；受每视频最多 1/2/3 个 bilimi 收藏夹设置限制。 | 显示本地预分类建议并执行可写目标。 | 只有已备册、已绑定且有真实远端 ID 的规则可写 B 站；未备册/未绑定只能保留本地建议并提示原因。 |
| `厚赏`（投币/三连） | 当前视频和账号允许投币。标题第一行右侧显示并列小项`一枚 · 两枚`，为标题预留约 104px；第二行说明占满剩余宽度。 | 小项只保存参数；点击大卡才按参数投 1 枚、补投 1 枚或投 2 枚。 | 小项静止时透明、选中只显示蓝色文字；悬停/键盘焦点才显示细边框。参数不写 B 站、不调用 DeepSeek、不影响队列。 |
| `表`（弹幕/短评） | 当前页面可输入内容。标题第一行右侧显示并列`随机 · 选择`，第二行说明占满宽度。 | 小项只保存发送方式；点击大卡才随机直接发送，或生成 3 条候选供选择/复制后发送。 | 候选生成和复制不写 B 站；直接发送才写 B 站。未配置 DeepSeek 或未启用趣味评论时提示配置。 |
| DeepSeek 批阅二判 | 已启用且存在可二判的分类建议。 | 按设置复核全部或“不太稳”的建议，原因进入本地处理记录。 | 请求失败保留原分类和重试入口，不抹掉本地结果。 |

所有批阅写入 B 站前都重新验证当前标签仍是发起操作时的同一视频。批阅、整理收藏和收藏库共用同一账号规则与视频归属；批阅失败不能删除札记、档案、转写、已有收藏关系或整理草稿。

### 3.2 批阅收藏后的本地登记

B 站收藏成功后，主进程使用同一 `operationId` 一次性登记视频基础资料、收藏位置、整理保护和`entered`历史事件，并发布新的本地 revision。B 站未确认成功时不写“已同步”；本地登记失败保留可恢复记录，不重复调用 B 站。相同 `operationId` 重试只补齐缺失记录，不重复历史、归属或远端写入。账号、目标规则、物理分册和远端 folder ID 任一校验失败时不提交部分本地登记，但保留真实远端结果供对账。

## 4. 札记、转写与档案

### 4.1 札记和转写队列

| 功能 | 最终效果 |
| --- | --- |
| `转写音频`、`单 P / 多 P` | 当前视频可识别且媒体工具可用时显示；默认`单 P`。模式是并列小切换项，不使用下拉。切换只改变模式，不入队。 |
| 单 P 入队 | 点击主区域转写当前精确 P；没有合法`?p=`时按 P1。任务保存账号、AID、BVID、CID、P 序号、P 标题、单 P 时长、来源 URL 和当次模型/总结设置。 |
| 多 P 选择 | 只在用户点击多 P 主区域后临时读取当前视频 P 清单。面板显示标题、P 序号、P 标题和时长，初始不勾选；提供`全选`/`取消全选`、已选数量、`取消`和`加入转写队列`。只有确认加入才创建任务。 |
| 多 P 行状态 | 已在队列、处理中或总结中的 P 不可重复勾选；已归档 P 显示`重新转写`，只有用户明确点击才新增版本。没有可加入 P 或未选 P 时提交按钮置灰。 |
| 队列 | 全应用只有一个队列。点击队列视频标题才打开精确来源；多 P 使用准确`?p=N`。行空白只切换当前任务，不跳转视频。 |
| 取消、重试 | 排队任务可立即取消；运行中显示“正在取消…”并以后台最终状态收束。失败/取消可按原账号、视频、CID、P、来源和模型重试，不按标题猜测视频。 |
| 并行总结 | 单个本地转写串行；某 P 文稿归档后，DeepSeek 总结可与下一项本地转写并行。总结取消只取消总结，保留文稿；转写取消不影响其他 P 的总结。 |

缺少视频身份、P 清单、CID、来源 URL 或权限时不创建任务，显示具体原因和`重试`/`返回`。应用重启后，可恢复的转写草稿进入档案；未完成队列按恢复规则清理或等待用户重新加入，不能假称仍在后台运行。

### 4.2 文稿、档案和导出

- 文稿页签提供`无时间线文稿`、`带时间线文稿`和`DeepSeek 总结`；无结果或仍处理中时显示真实状态，不显示旧内容。复制全文、精修文稿或总结均有成功/剪贴板失败反馈，复制不改档案。
- 档案库按账号查询标题、UP、BV/AV、版本数、星标和更新时间；多 P 另显示 P 序号、P 标题和时长。不同 CID 是不同档案，同一账号、AID、CID 的再次转写才新增版本。详情显示来源、版本、文稿、总结、星标和备注。
- `打开视频来源`打开准确 URL；缺少 CID 的旧档案保持可读，不猜测分 P。不能删除最后一个版本；删除视频档案需确认且不删除 B 站收藏、收藏库归属或其他视频。
- 星标按版本保存；备注失焦保存，“已备注”只命中有备注的档案。读取完整分类/处理记录按需加载、可分页，不预取全库。
- `开始导出`打开系统目录选择。建议目录名为`bilimi文稿_YYYY-MM-DD_HHmm`，使用本地日期和时分；目录存在时追加` (2)`、` (3)`。取消不创建目录、不写文件、不改变队列或档案。导出按既有 Markdown/Word 选项写入并显示成功、跳过、失败、取消和打开文件夹结果。

## 5. 掌库：普通收藏夹、备册、绑定与删除

### 5.1 规则和远端身份

上方掌库展示用户保存的普通规则。每条规则包含名称、规则类型、关键词、启用状态、本地成员、优先级和远端关系；可新建、编辑、保存、勾选、取消、查看详情和删除。远端 B 站收藏夹以真实 `folder ID` 区分；名称、前缀、数量、排序和是否含“bilimi”都不能代替身份。

数量口径始终分开：`远端成员数`来自已确认 B 站观察或对账；`本地已分配数`来自当前本地归属；`本轮计划数`来自整理草稿。无远端实体或远端数量未知显示`—`，不能把未知显示为 0；0 和非 0 都不改变身份。

| 状态 | 显示与操作 | 禁止或副作用 |
| --- | --- | --- |
| 未保存草稿 | 显示“草稿”，可编辑、保存、取消/丢弃。 | 不进入正式导航、扫描来源、备册、绑定或 B 站写入。 |
| 已保存未备册 | 显示`未备册`，可本地分类、参与整理、编辑、删除和点击`备册`。 | 不是远端来源，不能直接同步或归库到 B 站。 |
| 备册中 | 显示`备册中`、当前步骤和失败原因；不能重复点击。 | 取消/失败不删除规则，不把未知远端结果当不存在。 |
| 已创建待确认 | 创建响应有精确 ID，但目录重读尚未观察到该 ID。 | 只对同一精确 ID重试确认，不按名称认领、不创建第二个夹。 |
| 已备册 | 显示真实远端名称、绑定分册、本地成员数和`已备册`。 | 只有明确同步命令才写视频，不再次创建同名远端夹。 |
| 未绑定/失败/未知 | 显示状态、规则 ID、已知远端线索和最近结果；可从既有`备册`入口重试。 | 不因同名、前缀或观察结果自动绑定、同步或删除。 |
| 删除中/部分成功/待核对 | 保留原身份、成功子项和失败原因，可重试或对账。 | 不提前从所有投影移除，不把本地删除扩大为远端删除。 |

B 站实际存在但没有本地规则的远端收藏夹可以作为“未保存·未绑定”观察结果显示真实名称、精确 ID和成员数，但观察本身不创建正式本地规则、不建立绑定、不移动视频、不改名、不删除。保存后才进入普通规则流程。

### 5.2 备册和同步

`备册`只在用户明确点击时执行。`备册当前收藏夹`只锁定当前逻辑工作夹；`备册工作夹`只锁定菜单中用户勾选的逻辑工作夹。两者都先预检，再对用户选定的精确远端目标确认、创建或绑定；成功后刷新同一账号的掌库、收藏库和整理工作区快照。备册只建立/更新本地规则与物理分册，不上传视频、不移动成员、不清空成员。

已绑定规则的多个物理分册按分册号稳定排序，显示全部真实远端 ID、绑定数量、远端名称和分册详情；没有正式绑定分册不得显示`已备册`。目录读取失败、登录失效或结果未知时保留本地正式绑定事实，显示待重试，不降级为错误的未备册。

`确认并同步到 B 站`先完成本次目标规则的备册/绑定和权威刷新，确认目标可写后才进入同步进度。同步按冻结计划逐项执行，显示当前项、总数、成功、跳过、失败和待核对；可暂停、继续和结束剩余计划，已确认的 B 站成果和检查点保留。推荐采用、普通规则保存和本地整理不隐式触发备册或同步。

### 5.3 删除、恢复和远端对账

本地规则删除、收藏库视频删除、删除本地 bilimi 归属和删除 B 站远端收藏夹是不同范围：

- 删除本地规则只移除本地规则、工作夹投影和本地关系，不删除 B 站、视频档案、转写或札记；详情页和删除模式复用同一确认流程。
- 收藏库删除视频只移除本地视频行，保留来源、规则、档案、转写和 B 站收藏。
- 删除 B 站远端收藏夹必须展示精确 `folder ID`、名称、成员数和影响范围，用户完成现有知情确认后才执行。响应超时、页面导航、Cookie 变化或请求中断均进入结果待核对；只有同一精确 ID的目录核验确认不存在，才报告远端删除成功。
- 远端成功后按精确 ID完成本地绑定/观察收尾、刷新缓存并广播一次权威快照；失败、未知、取消或未确认的 ID全部保留。不同 ID即使同名也独立。
- 规则恢复只恢复本地规则快照，不创建、绑定、备册、同步或恢复 B 站成员；恢复成功后才重新显示备册入口。

## 6. 整理收藏

### 6.1 工作区生命周期

`整理收藏`首次进入时读取账号级工作区标记。不存在未结束轮次时直接进入扫描概览；存在扫描、标签、DeepSeek、预览、冻结、同步、暂停或待核对轮次时，后台完成安全检查后统一显示`恢复草稿`、`重新扫描`、`放弃本轮整理`。

- `恢复草稿`按当前权威检查点恢复扫描、预览、分类或同步进度；结果待核对必须先对账。
- `重新扫描`只在用户明确选择后从头建立扫描；不自动合并新分支。
- `放弃本轮整理`只结束本地本轮草稿和恢复标记，不回滚已保存收藏库成果或已确认 B 站操作。
- 关闭整理前安全暂停扫描、标签、DeepSeek 和同步并持久化检查点；失败时继续显示向导和具体错误。异常退出重开时不能假称远端仍在运行。
- 工作镜像确实无法校验时显示`工作镜像损坏`和`重建工作镜像并重新扫描`；可从有效 journal 修复的空字段不能误报为损坏。

### 6.2 扫描、来源和批次

扫描概览只显示本轮扫描事实，不显示本地掌库状态、备册或绑定。基础分页先确定视频身份、标题、UP、封面、收藏时间和失效状态；标签只能由独立标签接口确认，基础分页偶然带出的标签不视为确认。

来源表保留 B 站收藏夹名称、成员数、来源关系、顶部`全选（N）`和`总数`。`N`是收藏夹数量而非视频数，可以为 0。`待整理`、`已保护`、`失效视频`三种视图保留；`（来源计数·重复计数）`中前者是已选来源关系数之和，后者是与顶部去重视频数的差额，顶部待整理数才是实际整理视频数。选择来源不创建规则、绑定或同步。

设置提供`500`、`1000`、`2000（推荐）`、自定义 `500–5000`和`无限制（实验）`。设置只影响下一轮分批；当前草稿的分段、标签、分类、推荐和冻结计划不重切。单批不显示切批器；多批首次进入默认`本轮总览`，用户选批后普通刷新不改回。当前批和本轮总览分别显示`扫描进度`、`标签补取`和对应 scope 的已处理/总数，不把当前批数字带入整轮。

### 6.3 标签补取和采用

基础扫描全部完成后才开始标签补取。标签状态同时显示已知标签、获取中、已确认无标签、待补取和失败数量；未补取不能伪装为无标签。`暂停补取标签`安全收束在途读取并保存检查点；`继续补取标签`同时恢复待补取和失败项。`采用当前标签`在存在新标签版本且未冻结时可用，负责收束读取、按完整本轮范围重算分类并刷新推荐、预览和准备度；自然完成且无待补取/失败时按钮保留但置灰，不制造虚假的采用动作。

采用失败保留标签、推荐、人工分类和旧权威快照，并显示`采用当前标签未完成：本轮分类重算失败，请在当前草稿重试采用。`。采用成功后的标签截止版本不会被迟到结果改写；只有用户明确继续补取才进入下一次采用循环。收藏库选中视频创建整理工作区时，已有非空历史标签和明确确认的空标签可直接作为本轮已确认标签。

### 6.4 推荐收藏夹最终规则

推荐收藏夹是当前扫描数据的下方投影，不依赖上方收藏夹、账号规则、B 站远端目录或删除记录。推荐只保留两类：`专属 UP 追更`和`高频标签`；其他自动生成收藏夹不显示、不新建。推荐候选的出现、数量和内容只由当前扫描事实决定。

系统在扫描、分页、标签、规则保存、规则编辑、取消勾选、删除、恢复或批次变化后提前重算候选与普通规则的匹配。名称、规则类型和规范化关键词集合完全一致且只有一条匹配时建立联动；名称或规则任一改变立即断链，恢复一致后在新的计算结果中重新联动。点击推荐只读取已准备好的匹配，不扫描视频、不遍历全规则、不访问远端目录。

采用推荐只有三种结果：

1. 有唯一匹配：复用该普通规则并勾选；
2. 无匹配：按普通新建收藏夹的方式生成名称、类型和关键词，保存本地规则并勾选；
3. 有多个匹配：关闭本次采用并提示“存在重复收藏夹，请先处理重复项。”，不任意选择、不创建第三条。

采用成功后上方规则和下方候选同时显示本轮已勾选；失败两边回到上一个权威快照。下方取消只取消本轮参与，不删除普通规则；再次点击按最新预计算结果复用或新建。上方改名、改类型或改关键词后下方立即取消联动，点击下方推荐会按新建普通规则处理。删除上方普通规则后下方候选取消勾选；只要扫描事实仍满足条件，下一次扫描仍会出现未勾选候选。推荐不拥有墓碑、黑名单、远端绑定、认领、恢复或独立删除生命周期。

带有旧推荐来源标记的已保存记录按普通规则展示，保留真实本地成员和远端绑定，不因来源标记自动生成推荐或与异名候选联动。历史 `梅林FIT` 规则即使绑定远端 `4065678011`、标题为`bilimi小咪的收藏夹`，也只按其实际名称和规则语义处理，不与名称不同的候选联动，不生成“小咪”推荐。

### 6.5 分类、预览和 DeepSeek

推荐勾选的普通规则参与本地分类、归档预览、统计和执行准备；未勾选或未匹配候选不成为目标。分类、预览、历史和归档使用普通规则事实，不能把推荐候选标识当作规则标识。上方规则勾选与下方候选勾选在同一权威快照中更新，失败不产生半成品规则、删除记录、绑定或 B 站写入。

DeepSeek 只接收当前扫描视频和已有规则，用于分类、二判、关键词建议、总结和趣味评论；不能创建收藏夹、备册、绑定、改名、删除、移动或写入 B 站。未配置、请求失败、取消或输出无效时保留本地数据和人工调整入口。

### 6.6 本地保存、预览和确认执行

`保存本批到收藏库`和`保存本轮到收藏库`只写本地规则、视频成员、处理记录和归档关系，不写 B 站；保存前等待推荐选择和分类队列收束，并使用主进程最新快照。多批中，已完成扫描/标签且 DeepSeek 未运行的当前批可单独保存；整轮同步必须等待完整本轮收束和用户确认。

归档预览显示每条视频的目标规则、成员数、保护状态、跳过原因和未匹配项。人工调整、撤销/恢复和历史游标恢复使用持久化分类事实，不用当前分类器悄悄覆盖历史位置。冻结 B 站计划后保存跨分段去重、容量规划、物理分册和逐项检查点；确认执行前再次校验登录、绑定、容量和精确目标。

## 7. 收藏库

收藏库按账号提供左侧范围导航、中间视频列表和右侧详情。支持搜索、分页、排序、来源/归属筛选、当前页选择、批量操作、备注、札记、档案、复制、移动、同步和删除。查询、聚合和详情优先使用本地仓库；远端刷新只由明确动作触发。

### 7.1 列表与详情

- 视频列表显示标题、UP、BV/AV、收藏时间、来源、归属、同步状态和处理状态；分页和筛选不产生重复视频或错误账号数据。
- 详情显示来源收藏夹、B 站成员数、本地归属、目标规则、`同步位置`、归属一致性、最近调整、档案/转写/备注入口。`归属一致`、`归属不一致`和`尚未扫描B站归属`独立于`已同步`/`未同步`。
- “最近调整”读取最近分类/人工动作时间；普通扫描、标签补取、刷新资料和单纯同步回执不制造新的分类历史。完整记录按需展开和分页。
- `复制至`可增加本地 bilimi 归属；`移动至`只改变 bilimi 本地归属，普通 B 站来源始终保留。未备册目标可以只保存本地归属，不能产生 B 站写入。
- `笔记档案详情`打开精确视频档案和版本；收藏库任何删除不删除档案、转写、札记或备注。

### 7.2 单项、批量和反馈

`同步到 B 站`只对已绑定、可核验远端目标可用；按成功、失败、未知刷新列表和详情，不重复已确认写入。`从收藏库 bilimi 收藏夹删除`只移除本地归属；`从 B 站 bilimi 收藏夹删除`没有可核验精确远端归属时禁用并说明原因。

批量入口只在有选择时显示，先分析每项的来源、目标、绑定、容量、权限和跳过原因。确认窗口说明操作类型、范围、远端副作用和不可恢复性；取消不改变选择或数据。执行中显示进行中、完成、跳过、失败和未知计数；一项失败不回滚无关成功项。收藏库标题栏中部使用唯一操作反馈槽，不在多个位置重复相同结果。

账号切换、窗口重开、规则保存、备册/绑定、删除、导入/迁移和整理变化只失效受影响缓存；不让旧账号快照覆盖新账号，不把远端收藏夹缓存恢复成本地实体。大量视频、多个分册或长记录时列表虚拟化和有界刷新不能阻塞鼠标、滚动、缩放、最小化、恢复或关闭。

## 8. DeepSeek、设置和本地数据

DeepSeek 总开关、趣味评论、札记总结、批阅二判、整理辅助和小咪聊天可分别启用。连接测试和保存只显示可用/失败状态，不回显 API 密钥；密钥由主进程保存。实际调用统一进入全局 DeepSeek 工作态，显示具体任务内容；完成、失败或取消后及时收束，不锁住其他本地工作。

设置包括 B 站代理/直连、DeepSeek 地址/模型/密钥/开关、每视频 bilimi 目标上限、整理批次、转写线程/模型、全屏隐藏小咪、助手宽度/动效和小咪快捷键。设置变更只影响允许的后续任务；已入队转写保存入队时模型和总结设置，当前整理草稿不因批次设置变化而重切。

所有本地规则、视频归属、整理工作区、札记、转写、档案、星标、备注、处理记录和偏好按账号 UID 隔离。导出/导入/迁移先校验版本、范围和账号并提供预览、备份和回滚；不导出 Cookie、登录会话、DeepSeek 密钥、设备密钥、临时音频、执行 token 或进程状态。清理本地数据明确范围和不可恢复性，不修改 B 站服务器数据。

## 9. 小咪

小咪是可拖动的桌面伴随入口，支持唤醒主窗口、打开助手、触发`赞 / 赐 / 表 / 转`快捷动作和显示空闲、工作、提示、成功、错误状态。启动默认开启；用户关闭后持久保持关闭，显式唤醒立即显示并保存开启。网页全屏可按设置临时收起，不能借临时收起改写启动偏好。

小咪位置和助手展开方向按屏幕工作区计算，避免越界；透明区域可点击穿透，交互区域支持拖动和点击。主窗口、B 站页面、收藏、转写、DeepSeek、登录、Cookie 和任何远端写入不依赖小咪。小咪加载、修补和鼠标恢复失败只记录诊断，不阻塞主窗口。

## 10. 最终质量结果

最终版本在开发版、生产预览版和 Windows 安装版验证：冷启动、网页标签、四个助手页签、批阅、札记、单 P/多 P 转写、档案导出、普通规则新建/编辑/保存/勾选/删除、备册、绑定、同步、远端删除、整理扫描/标签/分批、推荐上下联动、取消后复用、改名断链、删除后重现、DeepSeek 失败降级、收藏库批量操作、重启恢复和小咪窗口。

所有长操作都有准确的进行中、成功、失败、取消或待核对状态；失败可重试或对账。真实 B 站副作用只由明确用户动作触发。鼠标移动、点击、键盘、滚动、窗口缩放、拖动、最小化、恢复和关闭在启动、扫描、备册、同步、删除、转写和小咪后台任务期间持续响应。
