# bilimi 项目功能项目书

> 本文是 bilimi 的单一产品行为基准。它按用户能看到的页面、按钮和操作编排，规定功能的用途、可用条件、不同情况下的结果、数据边界与不得破坏的旧行为。
>
> 设计基准：**历史上已确认的设计 + 曾经真实正常的版本 + 已验证的用户流程**。当前代码、单元测试或某一次界面截图都不能单独推翻已确认设计；证据冲突时必须在本文标记“待核对/与设计不一致待修复”，不得把猜测写成规则。
>
> 初始审计基线：`main` 的已提交 `8baa0c11`；该历史基线的七项失败已在后续 `main` 提交中修复。本书当前自动化核验基于 `977d24e1` 及本次收藏库菜单竞态修复：2026-08-16 的完整 `npm test` 为 `234` 个测试文件、`3809` 项测试全部通过。本书只描述产品行为，不执行任何 B 站操作、数据迁移或应用数据写入。

## 怎样使用这份项目书

- **开发前**：先找到将要改动的页面和按钮，逐条读“不会影响”和“不同情况下”的规则；再判断关联页面是否需要一并回归。
- **开发后**：只更新本书对应章节的“当前核验状态”与证据，不能另起一套产品规则。用户原话仍记录在当轮 `docs/requirement-ledgers/` 账本中。
- **出现冲突时**：历史已确认设计优先于当前错误实现。无法确定时写“待核对”，先查历史提交、旧测试和真实流程，不反复要求用户重述已经确认过的行为。
- **验收状态**：`已确认` 表示设计事实有来源；`已自动验证` 表示相关自动化通过；`待 Electron 验收` 表示不能拿单元测试替代真实窗口操作；`与设计不一致待修复` 表示当前实现或基线测试不能证明该规则成立。

## 全局不变原则

1. **浏览和本地资料优先可用。** B 站登录、网络、页面结构、DeepSeek 或媒体工具出错，只影响相应远端能力；不应让本地收藏库、札记、档案或设置整体不可用。
2. **真实 B 站写入必须可感知。** 点赞、投币、收藏、弹幕/评论、创建或同步 B 站收藏夹、取消 B 站收藏等操作，必须有进行中、成功、失败或待核对反馈；页面实际结果是最终事实。
3. **本地与远端要分清。** “保存”“仅保存到收藏库”“取消推荐”“从收藏库删除”和“同步到 B 站”不是同一动作，不能因实现方便互相替代。
4. **草稿与已执行方案要分清。** 整理收藏的扫描、推荐、预览、人工调整和 DeepSeek 调整在确认前都是可继续修改的草稿；冻结并开始真实 B 站执行后，分类方案不可再静默改变。
5. **一个业务状态只允许一个权威来源。** 账号级收藏仓库和整理工作区由 Electron 主进程持久化；页面只能显示快照并发送命令，不能另存一份会与其他页面脱节的真相。
6. **失败不伪造成功。** 请求失败、结果未知、保存尚未完成或用户取消时，必须保留真实可重试/可对账状态；不能先关闭对话框、取消勾选或清空草稿再声称成功。
7. **不以测试数量替代场景验收。** 涉及鼠标、滚动、窗口尺寸、最小化、关闭、网页注入或 B 站副作用的修改，必须在真实 Electron 开发版验收；没有该证据时只能标“待 Electron 验收”。

## 1. 应用窗口与 B 站浏览

**设计依据：** `README.md` 的“整体界面/主浏览器页面”；`src/renderer/src/App.tsx`、`features/browser/BiliWebview.tsx`；`docs/superpowers/specs/2026-07-29-whole-app-responsive-interaction-design.md`。

### 1.1 首次启动、主窗口与全局反馈

| 控件或状态 | 作用与正常结果 | 不同情况下 | 不会影响 |
| --- | --- | --- | --- |
| 首次启动前权限检查 | 说明桌面能力和外部服务边界；用户确认后记录已完成引导，后续进入主界面。 | 长时间“启动中”时应可完全退出重开；仍失败时使用设置中的诊断。 | 不应要求用户把 B 站密码写入设置。 |
| 主窗口 | 同时承载网页标签栏、中央 B 站浏览区和右侧助手。 | 窄窗口应压缩布局但不能让网页横向溢出、按钮互相遮挡或隐藏主要状态。 | 助手开关不能销毁网页标签、当前页面或本地数据。 |
| 全局提示与状态灯 | 显示最近一次跨页反馈；`DeepSeek`、`转写音频`、`整理`状态灯能跳到相应功能区。 | 长耗时操作必须显示进度或进行中；失败提示应指出登录、网络、页面、工具或配置原因。 | 某一个后台任务的错误不应阻塞其他页签。 |
| 最小化、恢复、关闭 | 按设置处理窗口关闭行为；恢复后保留可恢复的窗口和助手状态。 | 整理/转写运行时关闭不应丢弃已经确认的检查点；真实远端执行按冻结计划和恢复规则处理。 | 不能把“关闭窗口”误做成删除草稿、清空本地数据或取消已确认远端操作。 |

### 1.2 网页标签栏

| 按钮/操作 | 何时显示或可用 | 点击或操作后的结果 | 失败与边界 |
| --- | --- | --- | --- |
| 首页标签 | 始终存在。 | 切回 B 站首页。 | 不能关闭。 |
| 普通网页标签 | 在应用内打开视频或其他 B 站链接后显示。 | 点击切换当前页面；助手跟随更新标题、UP、链接、BV/AV视频上下文。 | 非视频页或仍加载时，助手显示待识别，不得把旧视频上下文当成新页面。 |
| 关闭标签 | 非首页标签在选中或悬停时显示关闭入口。 | 关闭该标签并切换到相邻可用标签。 | 不能关闭首页；关闭标签不能删除任何收藏、札记或档案。 |
| 刷新 | 始终针对当前激活网页标签。 | 只刷新当前 WebView 页面。 | 不能刷新所有标签或清空助手本地状态。 |
| 视频网页全屏 | B 站页面进入/退出全屏时触发。 | 若设置开启“网页全屏时隐藏小咪”，小咪随全屏隐藏并在退出后恢复。 | 不应关闭助手、终止转写或改变收藏草稿。 |

**页面不可用时：** 网络中断、未登录/登录过期、视频无权限、B 站页面结构变化或网页仍加载，都应限制依赖该页面的动作并显示原因；用户仍可浏览其他标签、查看本地档案和设置。

## 2. 右侧助手与批阅

**设计依据：** `README.md` 的“助手工作区/批阅页面”；`src/renderer/src/features/assistant/AssistantSidebar.tsx`、`FloatingAssistantApp.tsx`、`MemorialPanel.tsx`；`docs/superpowers/specs/2026-07-31-review-to-favorite-library-organization-design.md`。

### 2.1 助手页签与侧边栏

| 控件 | 规则 |
| --- | --- |
| `批阅`、`札记`、`掌库`、`设置`页签 | 四个页签互斥显示；切换不应丢失仍在进行的转写、整理、窗口状态或已保存页面选择。 |
| 侧边栏展开/收起 | 主窗口侧边栏收起只释放页面空间；重新展开应显示原页签与可恢复状态。独立助手窗口的失焦行为按当前窗口模式执行。 |
| 页面上下文 | 当前网页是可识别 B 站视频时显示标题、UP、链接和视频标识；否则明确“待识别”。任何批阅或转写动作都必须重新核对当前激活标签，避免切标签后对旧视频执行。 |

### 2.2 批阅页面

| 按钮/功能 | 何时可用 | 点击后的应有结果 | 数据与 B 站边界 / 失败时 |
| --- | --- | --- | --- |
| `轻赏`（点赞） | 当前是已登录、可识别的视频页。 | 请求对当前视频点赞，并反馈进行中和结果。 | 写入真实 B 站点赞；页面点赞状态是最终依据。无登录、页面不匹配、权限不足或接口失败时不伪造成功。 |
| `归库`（收藏） | 有可用目标收藏夹，且当前视频可识别。 | 根据掌库规则给出/执行收藏目标；受“每视频最多 1/2/3 个 bilimi 收藏夹”设置限制。 | 未备册或未绑定目标不能被冒充为远端可写；提示先备册/绑定或仅保留预分类。写入 B 站后仍需把本地记录如实标为成功、失败或待核对。 |
| `厚赏`（投币或三连） | 当前视频与账号允许投币。 | 按设置投 1 枚、补投 1 枚或投 2 枚，并反馈实际完成量。 | 真实 B 站副作用；已经投过、视频类型不支持或账号限制时显示页面/接口原因。 |
| `表`（弹幕或短评） | 当前视频页面可输入相应内容。 | 按设置随机直接发送，或生成 3 条候选供选择/复制后发送。 | 直接发送会写入 B 站；候选生成/复制本身不写入。DeepSeek 未配置或趣味评论未启用时只提示配置，不应调用服务。 |
| DeepSeek 批阅二判 | 已启用 DeepSeek、当前视频有可二判的归类建议。 | 按设置复核全部或只复核“不太稳”的建议；二判结果影响本轮目标时须把原因写入本地处理记录。 | 连接、密钥或请求失败时保留本地建议并显示失败；不能因为二判失败抹掉原分类。 |

### 2.3 批阅结果的受保护边界

- 批阅写入 B 站前，必须验证当前标签仍是发起操作时的同一视频。
- 归库和 DeepSeek 二判不能越过收藏夹备册/绑定状态；未能远端写入时可保留本地预分类，但必须明确不是已同步。
- 批阅、整理收藏和收藏库共用同一账号收藏仓库；它们不能各自维护互相矛盾的视频归属。
- 批阅失败不能删除札记、档案、转写、已有收藏关系或整理草稿。

## 3. 札记、转写与档案库

**设计依据：** `README.md` 的“札记页面/档案库页面”；`features/notes/VideoNotesPanel.tsx`、`VideoNoteArchivePanel.tsx`、`VideoNotesQueuePanel.tsx`；`docs/superpowers/specs/2026-07-27-favorite-library-performance-detail-and-transcription-design.md`、`2026-07-29-note-actions-download-timeline-design.md`。

### 3.1 札记页面与转写队列

| 按钮/功能 | 何时显示或可用 | 正常结果 | 失败、取消与边界 |
| --- | --- | --- | --- |
| `转写音频` | 当前网页能识别视频；本地转写能力可用。 | 下载/准备音频，进入唯一转写队列，按下载、准备、转写、合并、总结、归档等阶段显示进度；结果自动归档。 | 下载、媒体工具、模型、空间、网络或页面失败时保留错误和重试入口。不能因转写失败删除已有档案版本。 |
| `整理札记` / `重新整理` | 当前已有可处理文本或档案。 | 对现有文本执行相应本地整理，不重复下载音频。 | 没有文稿时提示先转写；不能把空结果标为完成。 |
| 队列展开/切换 | 有当前、排队、完成、失败或取消任务时。 | 查看任务数量、当前视频、进度和阶段；选择其他任务查看。 | 队列是全应用唯一队列，收藏库和札记不得各自创建第二套任务状态。 |
| 取消排队任务 | 任务尚未运行。 | 立即取消，并保留已有档案和重试/重新入队能力。 | 不删除视频、收藏关系或已有文稿。 |
| 取消运行中转写 | 任务正在运行。 | 显示“正在取消…”，终止工作进程后以后台最终状态为准。 | 完成与取消竞态以后台最终状态为准，不能显示两个互相矛盾的结果。 |
| 重试 | 已失败或取消且允许重试。 | 以当前视频、当前账号和所选模型重新入队。 | 不能按标题误匹配其他视频；任务身份是账号 + 视频 + 分P。 |
| 转写线程/模型选择 | 设置页中存在可用模型与线程选项。 | 新任务保存当次模型；队列可混合模型，连续任务复用运行时。 | 未安装模型先说明下载与验证；当前/队列正在使用的模型不能被误删。 |

### 3.2 文稿、总结和复制

| 控件 | 规则 |
| --- | --- |
| `无时间线文稿`、`带时间线文稿`、`DeepSeek 总结`页签 | 有对应结果时显示；再次点击已选页签可以收起。无文稿或仍转写时明确说明，不显示过期内容。 |
| 复制全文与更多复制菜单 | 可复制无时间线、带时间线、精修文稿或总结内容；成功与剪贴板失败均有反馈。复制不改档案内容。 |
| `生成总结` / `重新总结` | 已有文稿且 DeepSeek 可用时可点。运行时显示生成中和全局状态；完成后归档到该视频版本。 | 未启用、密钥不可读、连接失败或没有文稿时各自给出不同原因。取消总结只取消总结，保留文稿和精修检查点。 |
| 时间线跳转 | 时间线片段或对应操作存在时，可在主浏览器打开/聚焦同一视频并定位时间。 | 不能为此关闭其他网页标签或改变收藏归属。 |

### 3.3 档案库

| 控件/区域 | 应有行为 |
| --- | --- |
| `档案库`入口 / `返回札记` | 从札记进入全局档案库；返回只切换工作视图，不清空队列、选择或档案。 |
| 搜索、星标、已备注筛选 | 对整个本地档案集合查询，不只过滤当前可见页；无匹配时显示“没有匹配的档案”。 |
| 档案列表与详情 | 显示标题、UP、BV/AV、版本数、星标和最近更新时间；详情显示来源、版本、文稿、总结、星标和备注。切换视频后清理上一视频的临时展开状态。 |
| `打开视频来源` | 在主浏览器内部打开或聚焦原视频来源。 | 不应修改档案、收藏或 B 站收藏关系。 |
| 历史版本选择/删除版本 | 可查看同一视频不同转写版本；不能通过版本菜单删除最后一个版本。 | 删除单个版本前确认；不应删除其他视频档案。 |
| 星标 | 按具体版本本地保存，用于筛选。 | 不写 B 站。 |
| 本地备注 | 输入后失焦保存；“已备注”筛选只命中有备注记录。 | 保存失败必须保留文本或明确失败，不能静默丢失。 |
| 删除视频档案 | 需确认；删除该视频全部档案版本。 | 不可在应用内撤销；不应删除 B 站收藏、收藏库归属或其他视频。 |

**重启恢复：** 转写中异常退出时，能恢复的草稿优先写入档案；未完成队列按恢复规则清理或等待用户重新加入。不能假称原任务仍在后台运行。

## 4. 掌库：收藏夹规则、备册与绑定

**设计依据：** `README.md` 的“掌库页面”；`features/assistant/FavoriteLedgerOverview.tsx`、`ControlledFavoriteLedgerPanel.tsx`；`docs/superpowers/specs/2026-08-04-favorite-lifecycle-unification-design.md`、`2026-08-05-favorite-library-ledger-binding-status-design.md`、`2026-08-10-favorite-binding-and-hover-design.md`；2026-08-13 至 2026-08-16 收藏夹删除相关账本。

### 4.1 收藏夹规则列表

| 按钮/控件 | 何时显示或可用 | 应有行为 | 不会影响 |
| --- | --- | --- | --- |
| 收藏夹参与勾选 | 常规掌库状态可切换；整理中的草稿状态按本轮参与规则显示。 | 勾选决定本地分类/整理参与范围；取消勾选不自动删除已经存在的工作夹。 | 不能直接取消 B 站收藏、删除收藏库视频或清空档案。 |
| 点击收藏夹名称 | 有对应规则时。 | 打开详情/编辑区域，显示真实保存、备册、绑定和失败状态。 | 整理中的顶部卡片展示可以为草稿简化状态；详情内仍必须显示真实状态。 |
| `新建` | 常规掌库状态。 | 建立本地草稿收藏夹，填写名称、类型、关键词/UP/标签/DeepSeek 约束。 | 新建草稿不自动创建 B 站收藏夹。 |
| `保存` | 编辑内容合法且有待保存改动。 | 只写入本地收藏夹规则。 | 保存不是备册，不应产生 B 站远端文件夹。 |
| `备册` | 已保存且被选中的可备册规则。 | 为对应规则创建或绑定 B 站 bilimi 工作夹；已有绑定不得重复创建。 | 不能改变普通 B 站收藏夹成员关系；容量不足时不能半成功后假称已备册。 |
| 删除模式 | 用户显式进入后显示选择、全选/取消全选与确认流程。 | 普通工作夹遵循原有删除语义；默认收藏夹在删除模式可被单选和参与全选，退出删除模式后恢复普通整理保护。 | 不应把整理期默认收藏夹保护错误复用为删除期禁用。 |

### 4.2 收藏夹类型与分类规则

| 类型 | 本地匹配作用 | DeepSeek 与远端边界 |
| --- | --- | --- |
| 关键词收藏夹 | 用标题、简介等关键词本地匹配。 | 可有额外 DeepSeek 约束，但该约束不参与纯本地匹配。 |
| 专属 UP 追更收藏夹 | 命中指定 UP 时优先归类。 | 无法识别 UP 时不得伪造命中。 |
| 标签收藏夹 | 用 B 站标签本地匹配。 | 标签尚未补取完成时应明确等待/可采用状态。 |
| DeepSeek 约束收藏夹 | 只由 DeepSeek 根据自然语言约束辅助判断。 | DeepSeek 未启用时不自动命中；不能把未执行 AI 的结果伪装成本地高置信匹配。 |

默认分类允许改名和调整关键词。除暂存外的默认分类关键词全部清空会降低本地识别能力，更多视频会进入待分类；此风险必须在界面或操作反馈中可见。

### 4.3 备册、绑定与删除的状态表

| 实际状态 | 用户能做什么 | 操作结果 | 明确禁止 |
| --- | --- | --- | --- |
| 未保存草稿 | 编辑、保存或直接丢弃草稿。 | 保存后成为本地规则；丢弃只移除本地草稿。 | 不调用 B 站删除或把草稿显示为已备册。 |
| 已保存、未备册 | 本地分类和整理草稿可用；可选中后备册。 | 备册才创建/绑定 B 站 bilimi 工作夹。 | 不因“未备册”而认为该规则不存在。 |
| 已备册且已绑定 | 可用于 B 站归库、同步和后续整理。 | 远端状态须经实际结果或对账确认。 | 不能重复创建同名远端夹或忽略容量限制。 |
| 未绑定 / 绑定失败 / 待对账 | 显示真实原因、重试或对账入口。 | 保留本地规则和已知远端线索。 | 不能把未知远端结果标为成功，也不能删除本地规则来掩盖失败。 |

### 4.4 删除的严格边界

- `从收藏库删除`、掌库右侧删除、删除模式、显式“从 B 站删除”是不同功能，不能共用一个含糊的“删除”。
- 当前整理草稿的**推荐关联**工作夹删除遵循：已保存且未备册时删除本地 bilimi 工作夹规则，成功后取消推荐勾选；已备册或未绑定时仅取消推荐勾选；普通非推荐工作夹继续走原有删除语义。
- 推荐取消、详情删除和批量删除必须先解析到同一个真实保存规则 ID。不能因候选短 ID 与真实 ID 不同而打开伪草稿、删不到实体或误删同名规则。
- 删除本地规则或取消推荐不能删除收藏库、B 站收藏夹、视频成员、档案、转写和处理记录，除非用户进入对应的专门确认操作。

## 5. 整理收藏：扫描、草稿、推荐、预览与执行

**设计依据：** `docs/old-favorites-acceptance.md`、`README.md` 的“整理旧藏入口”；`electron/main/oldFavoriteWorkspaceCoordinator.ts`、`features/assistant/ControlledFavoriteLedgerPanel.tsx`、`OldFavoriteScanOverviewStep.tsx`、`OldFavoriteRecommendationStep.tsx`、`OldFavoriteArchivePreviewStep.tsx`、`OldFavoriteConfirmationStep.tsx`；2026-07-19、2026-08-01、2026-08-02 旧藏设计稿及 2026-08-14 至 2026-08-16 账本。

### 5.1 开始、关闭、重开与结束

| 按钮/场景 | 应有结果 | 不会影响 |
| --- | --- | --- |
| `整理收藏` / `整理旧藏`开始入口 | 立即进入“扫描概览：扫描中”，由当前账号工作区建立或恢复快照。 | 不能自动写 B 站、修改普通收藏夹或把旧页面本地状态当作权威工作区。 |
| 已有未完成草稿后打开 | 按当前事实与当前规则恢复草稿，保留人工分类；当规则变化影响系统分类时重新计算受影响的系统分类。 | 不重新扫描 B 站、不执行远端同步、不丢掉手动分类；不能把“关闭后重开草稿”变成“合并本轮新分支”。 |
| 关闭整理 | 只隐藏并保留当前草稿，之后再次点整理应恢复同一草稿继续调整。 | 不清空草稿、不把新增收藏纳入本轮、不执行 `merge-latest` 替代原草稿。 |
| 确认结束整理 | 提供保留草稿或删除草稿结束本轮的明确选择。 | 确认结束后再次开始才允许走受保护的增量扫描；不能影响已保存/已同步成果。 |
| 全部重新整理 | 用户明确选择时解除已有成功分类的增量保护，并启动全量扫描。 | 不能由普通重开、切换批次、DeepSeek 失败或恢复操作隐式触发。 |

### 5.2 扫描概览与批次

| 控件/状态 | 规则 |
| --- | --- |
| 扫描概览 | 扫描所有视频收藏的基本信息；扫描完成后补取标签。概览必须同时显示普通来源收藏夹与数量为 0 的 bilimi 工作夹。 |
| 来源选择 | 扫描稳定后开放；默认扫描到的来源可参与整理，用户可取消不想整理的非 bilimi 来源。 |
| 单批次 | 待整理不超过批次阈值时不额外制造批次概念；页面仍按同一四步流程工作。 |
| 多批次选择器 | 超过阈值时只渲染当前批次，提供当前批次与本轮总览切换；切换不得暂停仍在运行的标签补取、丢失选择或改变执行范围。 |
| 本轮总览 | 汇总本轮已就绪批次的扫描、标签、推荐和分类信息；后台非当前批次就绪后也必须按规则刷新，不只能等到整轮结束。 |
| 暂停/恢复 | 应用实际恢复或用户请求暂停时按工作区检查点处理；单纯切换批次不是暂停请求。 |

### 5.3 标签补取与“采用当前标签”

| 场景/控件 | 设计行为 |
| --- | --- |
| 标签补取进行中 | 显示当前批次/整体进度和可用程度；其他批次可继续补取，已就绪批次可按规则先整理。 |
| `采用当前标签`显示 | 当前批次已有可采用标签且尚未采用时显示；不能仅以“整轮是否全部结束”决定。 |
| 点击`采用当前标签` | 标记当前批次已采用；以已更新的标签索引重建推荐候选；重新计算当前批次系统分类；刷新当前批次、本轮总览和归档预览；保留人工分类及已勾选推荐；按钮消失。 |
| 其他批次仍在补取 | 不阻止当前批次采用；其他批次继续运行。切到本轮总览应能如实显示已就绪与待汇总内容。 |
| 命令失败 | 不标记已采用、不吞掉错误；保留重试能力和可读错误信息。 |

### 5.4 推荐收藏夹

| 控件/场景 | 设计行为 |
| --- | --- |
| 推荐生成 | 根据已扫描 UP 主和达到规则阈值的高频标签生成；推荐是当前整理草稿的一部分，不是已自动创建的远端收藏夹。 |
| 勾选推荐 | 对应上方已保存/草稿收藏夹的“本轮参与整理”状态同步为勾选；勾选后的目标参与预览和确认执行。 |
| 取消推荐 | 对应上方参与状态同步取消。未备册的本地草稿/规则按本地草稿规则移除；已备册或未绑定但存在实际远端收藏夹时仅取消本轮勾选。 |
| 上方勾选改变 | 必须同步回对应推荐项；两处不是两套独立选择状态。 |
| 新建/保存推荐工作夹 | 保存后使用真实已保存 ID，不能继续以临时候选 ID 操作详情或删除。保存尚未完成时，删除/取消必须等待权威保存结果。 |
| 推荐删除失败 | 不先清空上方卡片或下方勾选；保留失败提示和一致的可重试状态。 |

### 5.5 归档预览与人工调整

| 功能 | 设计行为 | 边界 |
| --- | --- | --- |
| 当前批次 / 本轮总览 | 当前批次只看该批内容；本轮总览看本轮各批可汇总结果。切换视图不改变分类、勾选或执行范围。 | 不得把当前批次独有结果静默丢弃。 |
| 分类卡片与把握程度 | 显示目标收藏夹、视频、来源、标签及“比较稳/不太稳”等用户可读把握信息；数值细节可在悬浮信息中显示。 | 未匹配/待分类区域必须可见，即使数量为 0 的规则本身仍需在相应位置保留。 |
| `转移` / 批量转移 | 用户可人工改变视频目标；记录为人工调整，优先级高于系统和 DeepSeek。 | 不能更改普通来源收藏夹的原始成员关系。 |
| 撤销 / 恢复 | 在草稿预览中按最近改动逐步撤销或恢复；新调整出现后恢复栈按规则失效。 | 已开始真实 B 站执行的结果不属于草稿撤销范围。 |
| 预览重算 | 编辑/新增上方 bilimi 收藏夹、采用标签、改变推荐或人工转移后，预览按同一工作区状态重算。 | 不能在各页保留过期的独立缓存。 |

### 5.6 DeepSeek 辅助整理

| 按钮/场景 | 设计行为 |
| --- | --- |
| `DeepSeek 整理`入口 | 只在当前草稿可安全整理、DeepSeek 已配置且当前范围存在可处理视频时可用；按钮打开本次范围选择，而不是把临时选择永久写成全局设置。 |
| 整理范围 | 默认“整理不确定项和【未分类】（推荐）”；可选只整理未匹配项或重新检查全部。用户这一次的临时选择不应改变下次默认值。 |
| 批次范围 | 从当前批次页打开时默认当前批次；从本轮总览打开时默认本轮所有批次；单批次不额外显示批次范围。 |
| 开始、取消、进度 | 确认后才请求 DeepSeek；取消不写 B 站，保留原分类/可恢复检查点；进行中显示可读进度与停止入口。 |
| 规则变化后的草稿 | 规则变化不能使 DeepSeek 永久不可点。整理入口先恢复当前草稿、按当前规则重算系统分类并保留手动分类，DeepSeek 只处理恢复后的工作区。 |
| 失败 | 显示中文可操作原因，不把内部 `stale` 或底层错误直接当用户说明；本地分类和草稿仍可继续。 |

### 5.7 确认执行、保存与 B 站同步

| 按钮/状态 | 应有行为 | 远端与恢复边界 |
| --- | --- | --- |
| `保存到收藏库` | 冻结当前本地方案，提交本地成员关系和处理记录；之后仍可回到前面调整并再次保存。 | 不创建、删除或移动 B 站收藏夹。 |
| `保存并同步到 B 站` | 先冻结跨批次去重、容量预检和必要备册后的方案，再逐项执行。 | 工作夹超过容量、未绑定、登录失效或未知结果要分别显示；未知结果先对账，禁止盲目重试。 |
| 执行中的`暂停同步` / `继续同步` | 只在真实逐项 B 站写入阶段显示；暂停等待当前请求完成并持久化进度，继续只执行未完成项。 | 不重复已确认写入，不取消收藏库已保存结果，不影响 DeepSeek 或扫描。 |
| `结束本轮整理` | 等待当前远端请求完成，保留已保存/已同步成果，放弃剩余远端计划并关闭草稿。 | 不回滚真实 B 站已执行动作，不删除收藏库。 |
| 执行失败或冷却 | 显示失败原因、重试/对账/结束等真实可用操作。 | 不能把 B 站失败归为 DeepSeek 失败，也不能清空冻结计划掩盖结果。 |

## 6. 收藏库：三栏浏览、归属与批量操作

### 6.2 视频详情与处理记录

| 控件/区域 | 设计行为 |
| --- | --- |
| `打开视频` | 在主浏览器打开或聚焦选择的视频；有多个来源时允许选择来源。 |
| `刷新资料` | 更新该视频本地镜像资料，不等同于修改 B 站收藏关系。加载、缺失和失败分别显示。 |
| `更多信息` / `收起详情` | 更多信息展开完整简介和标签；收起位于详情按钮行最右，切换视频时重置上一视频临时展开。 |
| 来源与时间 | 显示首次来源、首次进入、首次真实处理、当前归属、分类方式和分类时间；旧数据没有记录时写“未记录”，不猜测。 |
| `查看完整处理记录` | 默认展示最近一条，点击后按时间倒序分页显示此前每一次处理。记录可包含进入、批阅、整理收藏、手动移动、扫描观察、远端同步、采用本地/远端归属、转写和档案登记。 |
| 完整处理记录的性质 | 是审计历史，不是技术日志，也不是撤销栈。列表不预取全库历史；打开单个详情读最近记录，展开后再分页读取。 |

### 6.3 归属、同步与删除

| 按钮/操作 | 结果 | 明确边界 |
| --- | --- | --- |
| `复制至` | 将所选视频加入目标 bilimi 工作夹，保留原本地与 B 站收藏关系。 | 不移出普通来源收藏夹。 |
| `移动至` | 仅改变当前 bilimi 工作夹的本地逻辑归属，再加入目标。 | 普通 B 站来源始终复制式，不支持把它们当作可移动来源。 |
| `同步到 B 站` | 将本地意图按受控计划写入 B 站并显示结果。 | 结果未知先对账；不能因重试重复已确认操作。 |
| `采用 B 站位置` | 仅在本地归属与实际 B 站位置有真实冲突时作为明确选项出现。 | 不能作为默认主操作覆盖用户本地意图。 |
| `从收藏库删除` | 只移除本地收藏库行和期望归属。 | 保留 B 站收藏、转写、档案、保护和审计记录。 |
| `取消 B 站收藏` | 经确认后请求移除所选视频的 B 站收藏关系。 | 不应删除本地档案、转写或其他无关收藏关系；失败必须显示真实结果。 |
| 批量操作 | 先说明可执行项和跳过原因；混合来源、虚拟范围或不支持项不能静默跳过。 | 不能将普通来源的限制隐藏为“成功”。 |

## 7. DeepSeek：全局设置、调用与故障隔离

**设计依据：** `docs/superpowers/specs/2026-07-03-deepseek-defaults-design.md`、`2026-07-11-deepseek-save-test-status-design.md`、`2026-07-12-deepseek-feature-controls-design.md`、`2026-08-02-old-favorite-deepseek-responsiveness-design.md`；`electron/main/deepseekService.ts`、`deepseekFeatureAccess.ts`、`features/assistant/deepSeekTaskSignal.ts`。

| 功能/控件 | 设计行为 |
| --- | --- |
| DeepSeek 总开关 | 从关闭变为开启时，一次性启用趣味评论、自动总结和小咪聊天三个子功能；之后用户可独立关闭任一子项，除非总开关再次关闭后重新开启才重置该次默认。旧偏好缺失子项时按兼容规则继承。 |
| 连接测试/保存 | 保存后只显示保存/可用/失败状态，不能回显 API 密钥。密钥不可读、URL/模型无效或连接失败必须区分提示。 |
| 功能开关 | 趣味评论、札记总结、批阅二判、整理收藏辅助整理、小咪聊天按各自开关与前置条件独立控制。 |
| 调用中的全局状态 | DeepSeek 状态灯显示进行中、完成或错误，可跳到设置；一个功能的请求不应锁住其他本地工作。 |
| 重试和取消 | 临时失败按安全重试规则处理；用户取消时停止对应请求并保留已确认的本地结果/检查点。 |
| 数据边界 | 发送给 DeepSeek 的内容必须由当前功能说明，例如整理收藏可发送标题、UP、标签、简介、来源、当前建议与 bilimi 册目信息；不得发送不相关凭据或隐私数据。 |

## 10. 每次开发前必须保护的流程

下列流程只要被改动路径触及，就必须在实施计划中逐项列为“受保护回归”，不能以“相关测试通过”笼统带过。

1. 网页标签的新建、切换、关闭、刷新，以及助手不会对旧视频执行动作。
2. 批阅的点赞、投币、归库、评论候选/发送及 DeepSeek 二判的真实 B 站副作用边界。
3. 转写队列的开始、进度、取消、失败、重试、完成、重启后草稿归档与档案保留。
4. 档案库的搜索、版本、星标、备注、删除确认和回到视频来源。
5. 收藏夹保存与备册的差别；未保存、未备册、已备册、未绑定/待对账状态的真实显示。
6. 关闭整理后重开同一草稿；确认结束后才进入增量扫描；全部重新整理只能显式触发。
7. 多批次标签补取、切换批次、采用当前标签、当前批次/本轮总览与归档预览的一致刷新。
8. 推荐收藏夹与上方工作夹的双向勾选、真实 ID 解析、未备册删除、已备册/未绑定仅取消推荐，以及失败时不出现半截状态。
9. 整理预览中的人工调整、DeepSeek、撤销/恢复、保存到收藏库、冻结同步、暂停/继续、未知结果对账和结束本轮。
10. 收藏库的复制、移动、同步、仅本地删除、取消 B 站收藏和批量操作边界。
11. DeepSeek 配置、功能开关、错误隔离、取消与凭据不回显。
12. 设置保存、账号隔离、本地清理/迁移、窗口尺寸、最小化/关闭和小咪交互。
