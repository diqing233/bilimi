# bilimi 项目功能项目书

> 本文是 bilimi 的单一产品行为基准。它按用户能看到的页面、按钮和操作编排，规定功能的用途、可用条件、不同情况下的结果、数据边界与不得破坏的旧行为。
>
> 本文只写最终需要具备的功能与设计细节。

## 全局不变原则

1. **浏览和本地资料优先可用。** B 站登录、网络、页面结构、DeepSeek 或媒体工具出错，只影响相应远端能力；不应让本地收藏库、札记、档案或设置整体不可用。
2. **真实 B 站写入必须可感知。** 点赞、投币、收藏、弹幕/评论、创建或同步 B 站收藏夹、取消 B 站收藏等操作，必须有进行中、成功、失败或待核对反馈；页面实际结果是最终事实。
3. **本地与远端要分清。** “保存”“仅保存到收藏库”“取消推荐”“从收藏库删除”和“同步到 B 站”不是同一动作，不能因实现方便互相替代。
4. **草稿与已执行方案要分清。** 整理收藏的扫描、推荐、预览、人工调整和 DeepSeek 调整在确认前都是可继续修改的草稿；冻结并开始真实 B 站执行后，分类方案不可再静默改变。
5. **一个业务状态只允许一个权威来源。** 账号级收藏仓库和整理工作区由 Electron 主进程持久化；页面只能显示快照并发送命令，不能另存一份会与其他页面脱节的真相。
6. **失败不伪造成功。** 请求失败、结果未知、保存尚未完成或用户取消时，必须保留真实可重试/可对账状态；不能先关闭对话框、取消勾选或清空草稿再声称成功。

## 1. 应用窗口与 B 站浏览

### 1.1 首次启动、主窗口与全局反馈

| 控件或状态 | 作用与正常结果 | 不同情况下 | 不会影响 |
| --- | --- | --- | --- |
| 首次启动前权限检查 | 说明桌面能力和外部服务边界；用户确认后记录已完成引导，后续进入主界面。 | 长时间“启动中”时应可完全退出重开；仍失败时使用设置中的诊断。 | 不应要求用户把 B 站密码写入设置。 |
| 主窗口 | 同时承载网页标签栏、中央 B 站浏览区和右侧助手。 | 窄窗口应压缩布局但不能让网页横向溢出、按钮互相遮挡或隐藏主要状态。 | 助手开关不能销毁网页标签、当前页面或本地数据。 |
| 全局提示与状态灯 | 显示最近一次跨页反馈；`DeepSeek`、`转写音频`、`整理`状态灯能跳到相应功能区。 | 长耗时操作必须显示进度或进行中；失败提示应指出登录、网络、页面、工具或配置原因。 | 某一个后台任务的错误不应阻塞其他页签。 |
| 最小化、恢复、关闭 | 按设置处理窗口关闭行为；恢复后保留可恢复的窗口和助手状态。 | 整理/转写运行时关闭不应丢弃已经确认的检查点；真实远端执行按冻结计划和恢复规则处理。 | 不能把“关闭窗口”误做成删除草稿、清空本地数据或取消已确认远端操作。 |

### 1.2 网页标签栏

| 按钮/操作 | 何时显示或可用 | 点击或操作后的结果 | 失败与边界 |
| --- | --- | --- | --- |
| 首页标签 | 始终存在。 | 切回 B 站首页。 | 不能关闭。 |
| 普通网页标签 | 在应用内打开视频或其他 B 站链接后显示。 | 点击切换当前页面；助手跟随更新标题、UP、链接、BV/AV视频上下文。 | 非视频页或仍加载时，助手显示待识别，不得把旧视频上下文当成新页面。 |
| 关闭标签 | 非首页标签在选中或悬停时显示关闭入口。 | 关闭该标签并切换到相邻可用标签。 | 不能关闭首页；关闭标签不能删除任何收藏、札记或档案。 |
| 刷新 | 始终针对当前激活网页标签。 | 只刷新当前 WebView 页面。 | 不能刷新所有标签或清空助手本地状态。 |
| 视频网页全屏 | B 站页面进入/退出全屏时触发。 | 若设置开启“网页全屏时隐藏小咪”，小咪随全屏隐藏并在退出后恢复。 | 不应关闭助手、终止转写或改变收藏草稿。 |

**页面不可用时：** 网络中断、未登录/登录过期、视频无权限、B 站页面结构变化或网页仍加载，都应限制依赖该页面的动作并显示原因；用户仍可浏览其他标签、查看本地档案和设置。

## 2. 右侧助手与批阅

### 2.1 助手页签与侧边栏

| 控件 | 规则 |
| --- | --- |
| `批阅`、`札记`、`掌库`、`设置`页签 | 四个页签互斥显示；切换不应丢失仍在进行的转写、整理、窗口状态或已保存页面选择。 |
| 侧边栏展开/收起 | 主窗口侧边栏收起只释放页面空间；重新展开应显示原页签与可恢复状态。独立助手窗口的失焦行为按当前窗口模式执行。 |
| 页面上下文 | 当前网页是可识别 B 站视频时显示标题、UP、链接和视频标识；否则明确“待识别”。任何批阅或转写动作都必须重新核对当前激活标签，避免切标签后对旧视频执行。 |

### 2.2 批阅页面

| 按钮/功能 | 何时可用 | 点击后的应有结果 | 数据与 B 站边界 / 失败时 |
| --- | --- | --- | --- |
| `轻赏`（点赞） | 当前是已登录、可识别的视频页。 | 请求对当前视频点赞，并反馈进行中和结果。 | 写入真实 B 站点赞；页面点赞状态是最终依据。无登录、页面不匹配、权限不足或接口失败时不伪造成功。 |
| `归库`（收藏） | 有可用目标收藏夹，且当前视频可识别。 | 根据掌库规则给出/执行收藏目标；受“每视频最多 1/2/3 个 bilimi 收藏夹”设置限制。 | 未备册或未绑定目标不能被冒充为远端可写；提示先备册/绑定或仅保留预分类。写入 B 站后仍需把本地记录如实标为成功、失败或待核对。 |
| `厚赏`（投币或三连） | 当前视频与账号允许投币。 | 按设置投 1 枚、补投 1 枚或投 2 枚，并反馈实际完成量。 | 真实 B 站副作用；已经投过、视频类型不支持或账号限制时显示页面/接口原因。 |
| `表`（弹幕或短评） | 当前视频页面可输入相应内容。 | 按设置随机直接发送，或生成 3 条候选供选择/复制后发送。 | 直接发送会写入 B 站；候选生成/复制本身不写入。DeepSeek 未配置或趣味评论未启用时只提示配置，不应调用服务。 |
| DeepSeek 批阅二判 | 已启用 DeepSeek、当前视频有可二判的归类建议。 | 按设置复核全部或只复核“不太稳”的建议；二判结果影响本轮目标时须把原因写入本地处理记录。 | 连接、密钥或请求失败时保留本地建议并显示失败；不能因为二判失败抹掉原分类。 |

### 2.3 批阅结果的受保护边界

- 批阅写入 B 站前，必须验证当前标签仍是发起操作时的同一视频。
- 归库和 DeepSeek 二判不能越过收藏夹备册/绑定状态；未能远端写入时可保留本地预分类，但必须明确不是已同步。
- 批阅、整理收藏和收藏库共用同一账号收藏仓库；它们不能各自维护互相矛盾的视频归属。
- 批阅入口读到的目标必须使用第 4.1 节同一身份与数量口径：已保存未备册规则只能成为本地预分类目标，待绑定/待对账不是远端可写目标。
- 批阅失败不能删除札记、档案、转写、已有收藏关系或整理草稿。

## 3. 札记、转写与档案库

### 3.1 札记页面与转写队列

| 按钮/功能 | 何时显示或可用 | 正常结果 | 失败、取消与边界 |
| --- | --- | --- | --- |
| `转写音频` | 当前网页能识别视频；本地转写能力可用。 | 下载/准备音频，进入唯一转写队列，按下载、准备、转写、合并、总结、归档等阶段显示进度；结果自动归档。 | 下载、媒体工具、模型、空间、网络或页面失败时保留错误和重试入口。不能因转写失败删除已有档案版本。 |
| `整理札记` / `重新整理` | 当前已有可处理文本或档案。 | 对现有文本执行相应本地整理，不重复下载音频。 | 没有文稿时提示先转写；不能把空结果标为完成。 |
| 队列展开/切换 | 有当前、排队、完成、失败或取消任务时。 | 查看任务数量、当前视频、进度和阶段；选择其他任务查看。 | 队列是全应用唯一队列，收藏库和札记不得各自创建第二套任务状态。 |
| 取消排队任务 | 任务尚未运行。 | 立即取消，并保留已有档案和重试/重新入队能力。 | 不删除视频、收藏关系或已有文稿。 |
| 取消运行中转写 | 任务正在运行。 | 显示“正在取消…”，终止工作进程后以后台最终状态为准。 | 完成与取消竞态以后台最终状态为准，不能显示两个互相矛盾的结果。 |
| 重试 | 已失败或取消且允许重试。 | 以当前视频、当前账号和所选模型重新入队。 | 不能按标题误匹配其他视频；任务身份是账号 + 视频 + 分P。 |
| 转写线程/模型选择 | 设置页中存在可用模型与线程选项。 | 新任务保存当次模型；队列可混合模型，连续任务复用运行时。 | 未安装模型先说明下载与验证；当前/队列正在使用的模型不能被误删。 |

### 3.2 文稿、总结和复制

| 控件 | 规则 |
| --- | --- |
| `无时间线文稿`、`带时间线文稿`、`DeepSeek 总结`页签 | 有对应结果时显示；再次点击已选页签可以收起。无文稿或仍转写时明确说明，不显示过期内容。 |
| 复制全文与更多复制菜单 | 可复制无时间线、带时间线、精修文稿或总结内容；成功与剪贴板失败均有反馈。复制不改档案内容。 |
| `生成总结` / `重新总结` | 已有文稿且 DeepSeek 可用时可点。运行时显示生成中和全局状态；完成后归档到该视频版本。 | 未启用、密钥不可读、连接失败或没有文稿时各自给出不同原因。取消总结只取消总结，保留文稿和精修检查点。 |
| 时间线跳转 | 时间线片段或对应操作存在时，可在主浏览器打开/聚焦同一视频并定位时间。 | 不能为此关闭其他网页标签或改变收藏归属。 |

### 3.3 档案库

| 控件/区域 | 应有行为 |
| --- | --- |
| `档案库`入口 / `返回札记` | 从札记进入全局档案库；返回只切换工作视图，不清空队列、选择或档案。 |
| 搜索、星标、已备注筛选 | 对整个本地档案集合查询，不只过滤当前可见页；无匹配时显示“没有匹配的档案”。 |
| 档案列表与详情 | 显示标题、UP、BV/AV、版本数、星标和最近更新时间；详情显示来源、版本、文稿、总结、星标和备注。切换视频后清理上一视频的临时展开状态。 |
| `打开视频来源` | 在主浏览器内部打开或聚焦原视频来源。 | 不应修改档案、收藏或 B 站收藏关系。 |
| 历史版本选择/删除版本 | 可查看同一视频不同转写版本；不能通过版本菜单删除最后一个版本。 | 删除单个版本前确认；不应删除其他视频档案。 |
| 星标 | 按具体版本本地保存，用于筛选。 | 不写 B 站。 |
| 本地备注 | 输入后失焦保存；“已备注”筛选只命中有备注记录。 | 保存失败必须保留文本或明确失败，不能静默丢失。 |
| 删除视频档案 | 需确认；删除该视频全部档案版本。 | 不可在应用内撤销；不应删除 B 站收藏、收藏库归属或其他视频。 |

**重启恢复：** 转写中异常退出时，能恢复的草稿优先写入档案；未完成队列按恢复规则清理或等待用户重新加入。不能假称原任务仍在后台运行。

## 4. 掌库：收藏夹身份、规则、备册与绑定

掌库管理的是“用户希望如何组织视频”的本地事实；B 站收藏夹是用户拥有的远端收藏夹，bilimi 工作区是本地规则、草稿、整理归属和仓库数据。B 站收藏夹、bilimi 本地工作区、扫描来源、推荐候选、收藏库视频行和整理草稿是不同层级的投影，不能把远端收藏夹再复制成第二份 bilimi 收藏夹列表。任何页面都必须用真实规则 ID、远端 folder ID 和主进程快照读写，不能以名称、候选短 ID、数量为零或远端 ID 暂缺来猜测身份。

### 4.1 身份、状态、数量与权威来源

**数量先说明口径，再显示数字。** `远端成员数`是一次已确认 B 站观察或对账得到的实际成员数；`本地已分配数`是收藏库当前本地归属到该逻辑规则的视频数；`本轮计划数`是当前整理草稿已选择、尚未冻结执行的数量；`—`表示该状态没有远端实体或远端数量未知。数字是事实的度量，**0 和非 0 均不改变身份**，未知不能显示为 0。

**展示层次与行为资格必须分开。** “用户收藏夹（B 站）”展示当前账号的全部远端收藏夹，包括名称含 `bilimi`、历史物理工作夹和已经绑定到 bilimi 规则的收藏夹；“bilimi 工作区”只展示本地草稿、规则和本地已整理/入库归属。一个已绑定的远端夹仍属于用户收藏夹，只在其用户收藏夹行显示简短状态；本地规则通过真实规则 ID 与远端 folder ID 关联，不能复制成第二个远端实体。扫描概览不展示本地工作区表，只在用户收藏夹行按关系状态决定来源资格；本地规则、已入库数量、备册和绑定操作在掌库管理与收藏库中查看。

| 身份 / 生命周期状态 | 数量与显示 | 可做的本地操作 | B 站与明确禁止 |
| --- | --- | --- | --- |
| B 站收藏夹（用户远端来源，包含名称含 `bilimi` 的夹） | 全部显示在“用户收藏夹（B 站）”；显示远端成员数，0 或非 0 均保留。没有本地关系时不显示 bilimi 状态；有正式关系时只显示短状态`已备册`或`未绑定`。本轮计划数只在当前扫描/整理范围内另行显示。 | 没有 bilimi 关系的远端夹可作为扫描来源、浏览来源和收藏库来源；已备册或未绑定的夹默认只可浏览/对账，扫描资格按第 5.2 节单独判定。 | 夹名、前缀、数量或“看起来像 bilimi”不产生 bilimi 身份；用户收藏夹行不能隐式创建规则、绑定或同步。 |
| 未保存草稿 | 显示“草稿”；不显示远端成员数。本地输入尚未成为其他页面可引用的规则。 | 编辑、保存、取消/丢弃草稿。 | 不备册、不绑定、不写 B 站；不能出现在扫描来源或正式收藏库导航中。 |
| 已保存、未备册的 bilimi 本地工作夹 | 在掌库管理与收藏库显示短状态`未备册`；可在收藏库查看本地已分配数，远端成员数为 `—`。 | 本地分类、推荐参与、预览、编辑、删除本地规则、点击`备册`。 | 不是普通用户来源；不能作为扫描来源、不能假装有远端实体、不能直接同步/归库到 B 站。 |
| 备册创建/绑定进行中 | 显示短状态`备册中`；操作详情显示当前步骤和失败原因。 | 查看进行中、按可取消规则取消等待、完成后刷新所有受影响投影。 | 不允许重复点备册；取消/失败不能删除本地规则或把未知远端结果标为不存在。 |
| 已备册且已绑定的 bilimi 本地工作夹 | 在掌库管理与收藏库显示短状态`已备册`、关联 B 站收藏夹的真实名称和本地已分配数；关联远端夹仍在“用户收藏夹（B 站）”主列表中。 | 编辑本地规则、整理目标选择、查看关联远端位置、按权限发起同步/归库和对账。 | 只有明确的`同步到 B 站`命令才写远端；已有绑定不能再次创建同名远端夹。 |
| 未绑定、备册失败或待对账的本地关系 | 在掌库管理与收藏库显示短状态`未绑定`；详情显示具体失败原因、规则 ID、已知远端 folder ID/名称线索和可用的重试、绑定或对账操作。 | 重试、选择/确认绑定、对账、保留本地分类或取消本轮参与；对应远端夹默认不可作为扫描来源。 | 不把同名、前缀相似或扫描观察自动升格为已绑定；不能因为用户选择同步就隐式绑定。 |
| 删除中、部分成功、删除失败或远端结果未知 | 保留原身份、正在处理/失败原因和成功子项；不提前从所有投影移除。 | 重试、对账、返回详情或按明确确认结束。 | 不吞掉部分成功，不对未知远端结果盲重试，不把本地删除扩大为远端删除。 |

**删除与重新备册后的刷新。** 本地规则删除、解绑、备册、确认绑定或对账一旦返回权威结果，掌库、收藏库、扫描概览的用户收藏夹行和当前整理草稿必须同时失效并从新快照重投影。重新备册成功后短状态立即变为`已备册`；失败或结果未知时保留真实短状态与详情原因，不能继续显示旧关系，也不能伪造恢复成功。

**绑定与同步必须分开。** 用户只能从本地规则详情、收藏库详情或用户收藏夹的`未绑定`状态进入`确认绑定`；确认页必须同时显示本地规则 ID、B 站远端 folder ID、当前账号、容量、将改变的本地状态和潜在 B 站副作用。`确认绑定`成功后才进入已绑定/可同步状态；`同步到 B 站`不能承担隐式绑定职责。

### 4.6 跨页面、账号与恢复边界

- 批阅、整理收藏、掌库和收藏库共用同一账号级收藏仓库和真实规则 ID；B 站远端收藏夹与 bilimi 本地工作区是不同实体类型，页面只能显示快照、提交命令并等待结果，不能分别缓存“已参与/已删除/已绑定”的真相。
- 扫描概览按第 5.2 节只显示用户收藏夹远端来源与扫描资格；本地工作区规则、数量和关系详情在掌库与收藏库中查看。推荐、上方卡片、详情和收藏库导航必须与本节身份状态同步；当前整理草稿不能覆盖详情内真实的未备册、失败、待绑定或待对账状态。
- 账号切换时，规则、物理分片、绑定、收藏库、窗口偏好、扫描工作区和在途任务按 `accountMid` 隔离；不得引用、恢复或写入另一账号实体。
- 关闭掌库/收藏库窗口仅关闭视图，保留可恢复的当前账号选择、查询、编辑检查点和在途操作真实状态；恢复时以主进程快照对账，不能拿旧 React 内存覆盖持久化结果。
- 本地数据清理、导入、迁移或账号恢复必须先显示影响范围。它们只能操作本地选择范围，不能自动删除 B 站收藏、远端工作夹、登录或其他账号数据。

## 5. 整理收藏：扫描、草稿、推荐、预览与执行

### 5.1 开始、关闭、重开与结束

### 5.2 扫描概览分区、来源选择与扫描生命周期

扫描概览是“本轮工作区目前知道什么”和“接下来能安全做什么”的事实面板，不是普通收藏夹列表的另一份缓存。它先扫描视频收藏的基本信息，再按第 5.3 节补取标签；页面只展示当前批/本轮进度、用户收藏夹（B 站）和来源选择，不展示 bilimi 本地工作区区域、本地数量或关系详情。所有 B 站收藏夹都属于“用户收藏夹（B 站）”，不能以名称、`bilimi` 前缀、数量为 0 或远端 ID 是否暂缺来猜测身份。展示位置不等于扫描资格：远端夹是否可勾选来源必须由真实关系状态单独决定。

| 区域 / 控件 | 显示与可用条件 | 点击后的状态与结果 | 持久化、失败与不得破坏的边界 |
| --- | --- | --- | --- |
| `用户收藏夹（B 站）`区域 | 列出当前账号全部 B 站远端收藏夹，包括名称含 `bilimi`、历史物理工作夹以及已绑定目标。无本地关系的夹不显示 bilimi 状态；有正式关系时只显示短状态`已备册`或`未绑定`，不显示本地数量、远端关系 ID、失败细节或流程串。 | 无本地关系的远端夹可勾选/取消勾选，改变本轮扫描范围；显示`已备册`或`未绑定`的夹默认不可勾选，需到掌库或收藏库处理本地规则、绑定或对账。 | 远端夹都归用户收藏夹；名称不创建 bilimi 身份，不因展示而自动绑定、同步、删除或移动。 |
| 来源选择汇总 | 只统计用户收藏夹区中无本地关系且允许扫描的远端夹；显示`已备册`或`未绑定`的夹不计入可选择来源。 | 改来源后按当前工作区重新计算待扫描范围和概览数字。 | 不迁移普通来源数据，不改本地工作区身份，不清空已保存的人工分类。 |
| `暂停扫描` | 仅在扫描实际运行中显示且可用。 | 请求安全暂停；正在进行的一次读取以后台最终状态收束，再保存可恢复检查点。 | 不结束本轮、不清空已扫描视频、不取消标签补取、DeepSeek 或同步。 |
| `继续扫描` | 仅在扫描已暂停或存在**可恢复**扫描失败时显示；有冷却时显示倒计时并禁用。 | 从同一账号、同一工作区的已保存扫描检查点继续，不重新建立已扫描部分。 | 不能与“从头重新扫描”混同；失败时保留具体失败原因和可用恢复入口。 |
| `从头重新扫描` | 只作为用户明确选择的重新开始操作显示，不拿它代替普通恢复。 | 显式重建本轮扫描过程并从开头扫描。 | 不因切换批次、关闭再打开、标签失败或 DeepSeek 失败而隐式触发；不自动写 B 站。 |
| `本次直连后继续扫描` / `本次直连后重新扫描` | 网络/代理路径失败且直连是已支持的本次恢复路径时显示；冷却中禁用。 | 只在本次恢复动作使用直连，然后分别从检查点继续或显式从头重扫。 | 不静默改写用户保存的连接设置；网络失败不能伪造成扫描完成。 |
| `检测并继续扫描` | B 站 412 风控恢复需要先检测时显示；冷却中禁用并说明剩余时间。 | 先做恢复检测，检测通过才按检查点继续扫描。 | 检测失败/仍受限时保留 412 原因、冷却和重试条件，不盲目重复请求。 |
| `重建工作镜像并重新扫描` | 工作镜像损坏、无法安全恢复时显示。 | 清楚说明将重建本地工作镜像，然后显式重新扫描。 | 不能伪称旧检查点可恢复；不删除收藏库、档案、普通来源或已确认的远端结果。 |
| `结束整理` | 本轮草稿存在且用户决定结束时可用；远端执行阶段的规则另见第 5.8 节。 | 走第 5.1 节的明确保留草稿/删除草稿选择。 | 不能把暂停、切换批次或错误恢复当成结束整理。 |

### 5.3 标签补取与“采用当前标签”的可逆循环

标签区必须同时显示当前批次和本轮的进度、历史已知标签、本轮获取标签、已确认无标签和读取失败数。未完成标签只限制依赖它们的系统判断，不能阻断已经就绪批的本地整理或总览（见第 5.4 节）。

| 标签状态 / 控件 | 显示与禁用条件 | 点击后的状态与结果 | 持久化、失败与不会影响 |
| --- | --- | --- | --- |
| `暂停补取标签` | 全局标签补取实际处于 `running` 且仍有未采用批的待办时显示且可用。 | 请求安全暂停；当前在途读取按后台最终状态落库，之后不再启动下一条补取，并保存检查点。 | 保存各批已取得的标签、失败信息和采用版本；不删除已读标签，不暂停扫描、DeepSeek 或同步。 |
| `继续扫描标签` | 当前批刚完成采用、全局标签补取已因此暂停，且存在其他**未采用**批的已保存待办时显示。一般手动暂停且当前批尚未采用时显示`继续补取标签`。所有批都已采用或没有未采用批待办时隐藏。 | 只从未采用批的检查点恢复补取；已采用当前批保留采用版本，不重新入队、不重读。新批出现标签或变化标签后，在该批显示`采用当前标签`。 | 不重切批、不丢人工分类或已勾选推荐；不因恢复读取而重复采用或重读已采用当前批；不写 B 站。 |
| `重新补取失败标签` | 当前批存在标签读取失败且不在 `running` 时显示；无失败时隐藏。 | 仅把失败标签放回读取队列，成功、无标签和历史标签保持原状。 | 若继续失败，保留失败数、原因和可重试入口；不能把未知结果标为无标签。 |
| `采用当前标签` | 当前批的标签索引版本高于最近一次采用版本，存在尚未采用的新标签或变化标签，且本批未冻结执行时显示；没有标签增量、已采用版本与当前版本相同或本批已定稿时隐藏。 | 先记录当前标签索引版本为已采用，再以当前标签索引重建推荐、重新执行当前批系统分类、刷新当前批/本轮总览/归档预览，并安全暂停全局标签补取。当前在途的一条请求可自然落库，但之后不得启动下一条补取。 | 只重算系统结果；保留人工分类和已勾选推荐；不写 B 站。命令失败时不更新已采用版本或暂停状态，保留错误和重试能力。 |
| `已采用当前标签。` | 最近一次采用版本与当前标签索引版本相同，或继续扫描后没有新增/变化标签时显示。若仍有未采用批待办，同时显示`继续扫描标签`；没有待办时不显示继续入口。 | 用户可继续扫描未采用批；只有某批出现新标签或变化标签后，才在该批重新显示`采用当前标签`。 | 返回扫描概览、切换批次或重复打开页面不能单独制造可采用结果。 |
| 其他批标签任务 | 非当前批仍在补取、暂停或失败时在本轮进度中如实标记。当前批采用成功会把全部未采用批的补取安全暂停；切换批次或进入本轮总览本身不改变该暂停状态。 | 只由`继续扫描标签`从未采用批检查点恢复；其新结果按所属批刷新。 | 不能用全局 `running` 遮住当前已采用或其他 ready/saved 批的可见结果；不得因继续而重读已采用当前批。 |

**状态序列：** 手动控制为 `running` → `暂停补取标签` → `paused` → `继续补取标签` → `running`。当前批采用为 `awaiting-adoption(version=N)` → `采用当前标签` → `accepted(version=N)` + 全局`paused`；若存在未采用批待办，显示`继续扫描标签`，恢复为`running`后只处理这些批的检查点；已采用批不重读。没有未采用批待办时维持`accepted`而不显示继续入口。未采用批发现新/变化标签时进入 `awaiting-adoption(version>N)`。失败标签可在未运行时走 `重新补取失败标签`，其成功或再次失败只更新对应标签，不改写其他标签的真实状态。

### 5.4 单批/多批、本轮总览与“整理收藏批次”设置联动

| 区域 / 控件 | 显示与可用条件 | 正常结果 | 持久化、联动与边界 |
| --- | --- | --- | --- |
| 设置中的`整理收藏批次` | 设置页始终提供：`500`、`1000`、`2000（推荐）`、`自定义 500–5000`、`无限制（实验）`。 | 保存为助手偏好，决定**下一轮整理**每批最多加载的详细视频数。 | 默认/推荐值为 2000；设置变更不重新切分当前草稿，不改当前批标签进度、人工分类、推荐选择或已冻结计划，也不写 B 站。 |
| 新建工作区时分批 | 下一轮创建工作区时，以当时保存的批次设置和待整理数量产生批。 | 待整理数不超过阈值为单批；超过阈值为多批。 | 分批结果属于该工作区的持久化事实；之后改设置只能影响未来新轮。无限制是实验选项，不能被当成默认或静默选中。 |
| 单批 | 只有一批时不渲染多批选择器、不额外制造切批概念。 | 页面仍能使用扫描、标签、推荐、预览和确认的完整流程。 | 单批不应因缺少选择器失去本轮事实、进度或错误说明。 |
| 多批选择器 | 有多于一批时显示当前批次和`本轮总览`入口。 | 只改变观察/操作的当前批；切换后显示该批真实扫描、标签、推荐和分类状态。 | 切换不暂停后台标签补取，不丢来源选择、人工分类或已勾选推荐，不改变执行范围，不是暂停/结束/从头重扫。 |
| `本轮总览`：尚无已就绪批 | 没有批处于 `ready` 或 `saved` 时显示真实“补取中/待汇总”进度。 | 等待各批按自身状态推进。 | 不能把未就绪的推测标签、推荐或分类当作已完成汇总。 |
| `本轮总览`：已有已就绪批 | 任意至少一批为 `ready` 或 `saved` 时，立即显示这些批的推荐、分类和统计，同时逐批标注其余批“补取中/待汇总”。 | 后台任一批变为 ready/saved 时刷新该部分汇总；切换总览/当前批不改变数据。 | 聚合**只**包含 ready/saved 批，必须明确是部分本轮结果；其他批全局标签仍为 `running` 不能遮住已就绪数据，也不能假称整轮已完成。 |

### 5.5 推荐取消、上方收藏夹投影与归档预览

推荐区、扫描概览上方的收藏夹卡片、详情/删除入口和持久化收藏夹规则必须解析到同一个真实规则 ID。它们只是同一工作区事实的不同投影，页面不得各自保存一份会脱节的“已推荐/已删除”状态。

| 控件 / 场景 | 显示与操作规则 | 权威状态、失败与明确边界 |
| --- | --- | --- |
| 推荐生成 | 根据已扫描 UP 主和达到规则阈值的高频标签生成；推荐属于当前整理草稿，不等于已自动创建远端收藏夹。 | 推荐候选与上方卡片均从工作区权威快照投影；生成本身不写 B 站。 |
| 勾选推荐 / 上方卡片勾选 | 两处任何一方改变时，另一方同步为同一规则的“本轮参与整理”状态；已勾选目标参与预览和确认执行。 | 不得用候选短 ID 代替真实保存 ID；保存尚未完成时显示进行中，不能让第二个入口对未知实体操作。 |
| 取消未备册的本地候选推荐 | 该候选由本轮推荐生成，尚未备册且无绑定、无实际远端实体时可点击取消。 | 必须先等待权威本地取消推荐与删除成功；成功后下方推荐候选保留为未勾选，上方由该候选投影的本地收藏夹卡片移除。失败时两处维持原状并显示可重试错误。不得留下“幽灵卡片”，也不得对已不存在的 ID 再发第二次删除。 |
| 取消已备册、已绑定或有实际远端实体的推荐 | 该推荐对应真实远端/绑定实体时可点击取消。 | 只取消本轮推荐勾选；真实收藏夹上方卡片保留。取消推荐本身不删除远端实体，也不把未对账状态伪造成删除成功。 |
| 详情删除 / 删除模式删除未备册候选 | 该项是可删除的本轮推荐本地候选时显示并允许选择。 | 与下方取消推荐共用同一笔权威本地事务；成功后下方候选、上方卡片、详情和删除模式同时刷新。 | 不能因入口不同留下一处旧投影；不删除 B 站远端收藏夹。 |
| 新建 / 保存推荐工作夹 | 保存成功后，推荐、上方卡片、详情和后续取消统一改用权威保存结果中的真实 ID。 | 保存失败或尚未完成时不提前移除/新增投影；不能打开伪草稿、误删同名规则或吞掉错误。 |
| 归档预览联动 | 推荐勾选、上方卡片编辑/新增、采用标签和人工转移后，预览按同一工作区状态重算。 | 不从独立页面缓存取旧结果；不删除收藏库视频、档案、转写或普通来源成员关系。 |

### 5.6 归档预览与人工调整

| 功能 | 设计行为 | 边界 |
| --- | --- | --- |
| 当前批次 / 本轮总览 | 当前批次只看该批内容；本轮总览看本轮各批可汇总结果。切换视图不改变分类、勾选或执行范围。 | 不得把当前批次独有结果静默丢弃。 |

### 5.7 DeepSeek 辅助整理

| 按钮/场景 | 设计行为 |
| --- | --- |
| `DeepSeek 整理`入口 | 只在当前草稿可安全整理、DeepSeek 已配置且当前范围存在可处理视频时可用；按钮打开本次范围选择，而不是把临时选择永久写成全局设置。 |
| 整理范围 | 默认“整理不确定项和【未分类】（推荐）”；可选只整理未匹配项或重新检查全部。用户这一次的临时选择不应改变下次默认值。 |
| 批次范围 | 从当前批次页打开时默认当前批次；从本轮总览打开时默认本轮所有批次；单批次不额外显示批次范围。 |
| 开始、取消、进度 | 确认后才请求 DeepSeek；取消不写 B 站，保留原分类/可恢复检查点；进行中显示可读进度与停止入口。 |
| 规则变化后的草稿 | 规则变化不能使 DeepSeek 永久不可点。整理入口先恢复当前草稿、按当前规则重算系统分类并保留手动分类，DeepSeek 只处理恢复后的工作区。 |
| 失败 | 显示中文可操作原因，不把内部 `stale` 或底层错误直接当用户说明；本地分类和草稿仍可继续。 |

### 5.8 确认执行、保存与 B 站同步

| 按钮/状态 | 应有行为 | 远端与恢复边界 |
| --- | --- | --- |
| `保存到收藏库` | 冻结当前本地方案，提交本地成员关系和处理记录；之后仍可回到前面调整并再次保存。 | 不创建、删除或移动 B 站收藏夹。 |
| `保存并同步到 B 站` | 先冻结跨批次去重、容量预检和**已完成确认绑定**的目标，再逐项执行；存在未绑定目标时先停止在关系确认步骤，不把绑定隐含在同步中。 | 工作夹超过容量、绑定未完成、登录失效或未知结果要分别显示；未知结果先对账，禁止盲目重试。 |
| 执行中的`暂停同步` / `继续同步` | 只在真实逐项 B 站写入阶段显示；暂停等待当前请求完成并持久化进度，继续只执行未完成项。 | 不重复已确认写入，不取消收藏库已保存结果，不影响 DeepSeek 或扫描。 |
| `结束本轮整理` | 等待当前远端请求完成，保留已保存/已同步成果，放弃剩余远端计划并关闭草稿。 | 不回滚真实 B 站已执行动作，不删除收藏库。 |
| 执行失败或冷却 | 显示失败原因、重试/对账/结束等真实可用操作。 | 不能把 B 站失败归为 DeepSeek 失败，也不能清空冻结计划掩盖结果。 |

## 6. 收藏库：身份、三栏浏览、归属与批量操作

### 6.1 窗口、左侧导航与范围状态

| 区域 / 控件 | 显示与可用条件 | 正常结果 | 失败、数据与性能边界 |
| --- | --- | --- | --- |

### 6.6 收藏库性能、账号和数据恢复保护

- 查询、排序、筛选、聚合数字和详情读取优先走当前账号本地仓库；远端刷新只由明确动作触发，并且不能阻塞已有本地浏览。
- 账号切换、窗口重开、本地清理、导入/迁移、规则保存、备册/绑定和整理草稿变化均应精确失效受影响缓存；不全库重渲染、不使用旧账号快照覆盖新账号，也不把远端用户夹缓存恢复成本地 bilimi 工作区实体。
- 大量视频、多个物理分片或长处理记录时，鼠标、滚动、窗口缩放、最小化和关闭必须保持响应。

## 7. DeepSeek：全局设置、调用与故障隔离

| 功能/控件 | 设计行为 |
| --- | --- |
| DeepSeek 总开关 | 从关闭变为开启时，一次性启用趣味评论、自动总结和小咪聊天三个子功能；之后用户可独立关闭任一子项，除非总开关再次关闭后重新开启才重置该次默认。旧偏好缺失子项时按兼容规则继承。 |
| 连接测试/保存 | 保存后只显示保存/可用/失败状态，不能回显 API 密钥。密钥不可读、URL/模型无效或连接失败必须区分提示。 |

| 重试和取消 | 临时失败按安全重试规则处理；用户取消时停止对应请求并保留已确认的本地结果/检查点。 |
| 数据边界 | 发送给 DeepSeek 的内容必须由当前功能说明，例如整理收藏可发送标题、UP、标签、简介、来源、当前建议与 bilimi 册目信息；不得发送不相关凭据或隐私数据。 |

| 收藏策略 | 每视频最多 1/2/3 个 bilimi 目标等策略影响批阅与整理预览。 | 改策略不应隐式重写已经冻结或已执行的旧轮计划。 |
| 整理收藏批次 | 选择 500、1000、2000（推荐）、自定义 500–5000 或无限制（实验）；见第 5.4 节。 | 保存后只影响下一轮新建工作区每批最多加载的详细视频数；当前草稿不重切分、不重算，既有标签进度、人工分类、推荐选择和冻结计划不变。 |
| 转写线程与模型 | 可选择 1/2/4/无限制等线程策略和已验证模型；说明性能、硬件、下载/许可证和当前设备限制。 | 变更影响新任务；队列中任务使用入队时保存的模型，不能被静默改写。 |
| 网页全屏时隐藏小咪 | 打开时网页视频全屏隐藏小咪，退出全屏恢复。 | 不关闭小咪功能或主窗口。 |
| 助手宽度、动效与界面偏好 | 用户调整后按账号/偏好规则持久化，重启恢复；窄窗口仍保持主要控件可用。 | 不应反复触发昂贵数据刷新或造成网页树重渲染。 |
| 小咪悬浮快捷键 | 默认顺序为 `赞 / 赐 / 表 / 转`，最多四项；用户可独立增删。 | 旧的已废弃快捷项须按兼容规则清理，不生成不可用按钮。 |

### 8.2 本地数据与账号边界

| 操作 | 应有行为 | 明确禁止 |
| --- | --- | --- |
| 启动与功能诊断 | 检查网络、本地媒体工具、存储、当前页面和关键功能依赖，给出中文可操作结果。 | 不应因诊断发起真实收藏、扫描或写入。 |
| 账号切换 | 账号级收藏库、工作区、缓存、任务和偏好按 `accountMid` 隔离。 | 禁止读取、恢复或写入另一账号的工作区和收藏。 |
| 掌库 / 收藏库视图恢复 | 当前账号的用户收藏夹范围、本地 bilimi 工作区范围、查询、排序、筛选、页码、滚动、选择、详情和菜单开关按第 4.6、6.1 节分别保存/恢复；恢复后用主进程快照校正。 | 不把视图偏好当作规则、绑定或远端状态；不能拿旧窗口内存覆盖新持久化事实，也不能把远端夹恢复成另一条本地工作区记录。 |
| 清理本地数据 | 显示清理范围和不可恢复性；用户确认后只清理选择的本地数据。 | 不得因“清理本地数据”自动删除 B 站收藏、账号登录或远端文件夹。 |
| 数据迁移/导入恢复 | 兼容旧本地数据时先检查范围和版本；导入预览不触发远端动作。 | 不导出设备绑定的敏感远端实体 ID，不用迁移覆盖另一账号。 |

## 9. 小咪桌面伴随窗口

| 操作/状态 | 设计行为 |
| --- | --- |
| 显示与隐藏 | 小咪可独立显示于桌面；与主窗口、助手共享状态。网页全屏隐藏设置生效时按第 8 节处理。 |
| 点击小咪 | 可唤醒主窗口或打开助手，并给出与当前功能区相符的提示。 |
| 拖动 | 仅主鼠标按钮开始拖动；拖动不能误触唤醒、关闭或右键菜单。指针捕获取消时安全结束拖动。 |
| 右键与快捷菜单 | 显示小咪菜单与快捷入口；失焦或按规则点击外部后关闭。 |
| 悬浮说明 | 悬停当前快捷操作时给出简短、与实际功能一致的说明；点击反馈优先于闲置问候。 |
| 连续点击/情绪状态 | 快速重复点击、靠近关闭动作等交互按已设计情绪反馈呈现，但不能阻塞主窗口恢复和正常菜单操作。 |
| 大小调整 | 只改变小咪显示尺寸，不改变主窗口、助手或数据设置；控制按钮不应被小咪主体遮挡。 |
| 透明窗口点击穿透 | 非控件透明区域允许按平台规则点击穿透；鼠标在小咪控件上时保持可操作。 |
