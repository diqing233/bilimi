# bilimi 1.2.1

## Highlights

- Xiaomiao now uses a fixed transparent host again. Opening a speech bubble or pet chat does not resize the native window, so the pet no longer shifts when it is near the top edge of a display.
- Transparent space remains click-through after opening the main application, while the existing drag behavior, click reaction, quick actions, and pet chat remain available.
- This release includes the current favorite-library interaction fixes, localized feedback improvements, and the verified Windows transcription runtime updates from the 1.2 line.

## Upgrade Notes

Install `bilimi.Setup.1.2.1.exe` over an existing installation after closing bilimi. Normal upgrades preserve local preferences, archives, and downloaded transcription models. The installer remains unsigned; obtain it only from this repository's GitHub Release.

## Verification

- Automated suite: 261 test files and 4745 tests.
- Production build: `npm run build`.
- Windows installer: `npm run dist:win`.
