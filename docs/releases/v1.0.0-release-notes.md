# bilimi 1.0.0

bilimi `1.0.0` 是首个稳定版本：在一个 Windows 桌面应用里完成 B 站浏览、批阅、视频札记、档案管理、收藏夹掌库、本地音频转写和小咪桌面伴随交互。

## 本次发布

- 更新全套应用图标：窗口、任务栏、托盘、可执行文件、安装器和快捷方式统一使用新的挥手小咪图标。
- 图标生成链路保留完整方形构图，并提供 16、24、32、48、64、128、256 像素 Windows ICO 适配。
- 正式版本号升级为 `1.0.0`。
- Windows 安装包文件名固定为 `bilimi.Setup.1.0.0.exe`。
- README 重写为完整中文用户手册，逐页说明主浏览器、批阅、札记、档案库、掌库、设置和小咪窗口。
- 完成开发版、生产预览版、真实安装版启动与关键只读路径验收。
- 确认安装包包含 yt-dlp、ffmpeg、ffprobe、whisper.cpp 和 `ggml-small.bin`，普通用户无需自行安装转写工具。

## 下载

下载 `bilimi.Setup.1.0.0.exe` 并运行安装。当前安装包未进行 Windows 代码签名，SmartScreen 可能显示“未知发布者”；请确认文件来自本仓库 Releases 页面。

## 已知限制

- B 站自动化受页面结构、登录状态、账号权限、网络和风控影响。
- DeepSeek 功能需要用户自行配置兼容服务和 API key，并可能产生费用。
- 安装包因内置本地转写运行时和模型而体积较大。
- 发布验收没有自动执行会改变真实 B 站账号状态的点赞、投币、收藏或发送评论操作。
