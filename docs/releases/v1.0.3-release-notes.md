# bilimi 1.0.3

bilimi `1.0.3` 完成旧藏整理最后一轮安全与效率优化。

## 本次发布

- 最终确认后仍可查看扫描概览、推荐收藏夹和归档预览，但不能再改变本轮方案。
- 运行中可以主动暂停；当前请求返回后停止发出新请求，继续时从下一条开始并先安全冷却。
- 主动暂停与 B 站风控分离。遇到 `-509`、`-352`、HTTP `412`、captcha、verify、risk 或中文风控提示时立即安全停止，不提供原地继续。
- 前 50 条保持保守节流，第 51 条起加速，但始终严格串行。
- 同一视频的多个追加目标合并为一次请求；不会删除、移动或取消任何原收藏。
- 暂停不会提交整批断点；只有全部成功才提交，结束暂停轮次后必须重新扫描对账。

## 下载

下载 `bilimi.Setup.1.0.3.exe` 并运行。安装包未进行 Windows 代码签名，SmartScreen 可能显示“未知发布者”；请确认文件来自本仓库 Releases 页面。

## 安全边界

发布验收不会自动执行任何会改变真实 B 站账号状态的点赞、投币、评论、收藏追加、删除、移动、取消收藏或归档确认。相关逻辑仅通过 mock 自动化测试验证。
