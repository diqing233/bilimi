Command:

```text

```

First attempt: failed during `npm ci` with `EPERM` while replacing `node_modules/@esbuild/win32-x64/esbuild.exe`.

Root cause: a previously launched project `electron-vite dev` process, its esbuild service, and project Electron child processes still held the binary open. After terminating only processes whose command or executable path pointed into this repository, an exclusive file-open check succeeded.

Second complete attempt: exit code 0. It rebuilt the app, reused validated media tools, packaged `dist/win-unpacked`, built the NSIS installer, and generated the block map.

## Checklist Items Not Automatically Executed

The following checks were intentionally not performed automatically because they mutate external account state, require private credentials, require a long local workload, or require a clean user profile:

- Bilibili login from a clean session and login-expiry recovery.
- Like, coin/triple, favorite, danmaku, or comment submission.
- Creating, deleting, or synchronizing real Bilibili favorite folders.
- Executing an old-favorite organization plan against the account.
- Writing or replacing a real DeepSeek API key; the existing saved-key state was only read and diagnosed.
- A complete audio download/transcription, cancellation, retry, and restart-recovery cycle.
- Clean Windows-user first launch, first login, first key save, and first transcription.
- The suggested 3-5 minute release-baseline screen recording.
- Subjective long-duration performance comparison during video playback and transcription.

These items remain manual release risks. They are not represented as passing. No external account mutation was needed to verify the icon, version, package resources, preload bridge, navigation, page availability, or installed diagnostics required for this packaging change.

## Release Decision

The build, preview, Windows package, installation, application launch, packaged resource paths, icon pipeline, internal video-tab flow, assistant pages, floating window, and installed diagnostics were verified. The release is technically ready for publication with the manual-risk exceptions listed above disclosed in this record.
