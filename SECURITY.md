# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting A Vulnerability

Please do not open a public issue for secrets, credential leaks, account-safety problems, or private Bilibili session data.

Report the issue privately to the maintainer with:

- Affected bilimi version.
- Reproduction steps.
- Relevant logs with API keys, cookies, tokens, account IDs, local paths, and other private data removed.
